# 雨夜寻味：渡船反馈与交互物辨识

## 船坞节点

旧版 `havenAvailable` 会在温叔尚未受邀、或归灯庭雨灯未点亮时直接排除渡船交互，场景却一直摆着船标。地图与地面青圈又只检查雾河系缆，导致船坞看似可用，按交互键却没有回应。

六条渡船入口现在共用 `ferryStatus`。船坞和归灯庭仍按原剧情开通：取得龙骨拓片、修复水车院系缆、邀请温叔、点亮庭灯。未满足条件也能查看渡船，屏幕直接说明下一步；陪伴模式另有详细路线解释。普通雾河渡船只需要系缆。战斗期间仍需先摆脱追兵。

已开航线显示青色光标／地面圈和地图实心舟；待开航线显示灰色光标与空心舟。渡船牌有双面舟形图案，船坞与庭院的牌子放在落点旁边，避免挡住刚下船的角色。地下升降台由原副本系统显示，不误标为渡船。

521–800px 高的桌面窗口把刻文提示放在交互按钮上方；720p 实测两者相隔 18px，航线要求不再被按钮遮住。窄屏触控保留原布局。

## 原“纸条”用途核对

`kind: note` 实际混合了文本、任务线索与机关。保留 33 个原 ID、存档类型与交互规则，以显示元数据区分用途。普通文本为白光，任务名册／拓片／守灯簿为紫光；机关用暖色高标记，完成后为青色。读过的文本保留弱标记，可重读。

纸笺、路牌与碑刻有双面纹路；名册展开在书架上，拓片挂在框架上。摆渡遗签移到庵堂前侧的支架，避免埋在柱子后。悠亚背后的归水灯改为有顶灯台，标记高度 4.2 米，远处能先发现，靠近后再操作。水闸轮会显示开启后的角度，听水盆有水纹，旧钟有钟身与垂绳；庭院三声顺序正确／重置时，模型标记同步变化。

## 验证与复现

新增 `scripts/tests/night-rain-landmarks.test.mjs` 覆盖锁定节点反馈、正常邀请／点灯开船、六航线资源与存档、战斗限制、33 节点完整用途、放灯的一次性完成、重读与三声重置。全套雨夜规则共 144 项。

`scripts/verify-night-rain-landmarks.cjs` 使用静音安装版 Chrome、TTS stub 和虚拟指针锁定。33 节点目录从通过加载校验的旧档布置合法站位；这是逐物视觉验收，不声称从新游戏连续走到全部位置。桌面与 390px 窄屏从悠亚所在区域约 24 米外走近灯台，通过真实 E 键放灯，完成过场并回到原世界；船坞验证三种航线状态、往返、刷新续玩和地图图标。地下文本另从房间内可走的角度查看。

所有截图同时记录 `render_game_to_text`、DOM、画布大小及像素 sanity，收集页面与控制台错误，交付前逐张打开目检。规则测试另以普通移动／战斗输入覆盖既有主线、两岸、庭院暗线和副本流程。手机验收是 Chrome 窄屏模拟，造型是程序低模。

本轮 144/144 雨夜规则、源码 ESLint、完整 `check` 后顺序 `build` 均通过，未跳过构建 ESLint。全目录和流程生产验收 50 张、720p 补测两张及静音通用客户端一张，共 53 张采用截图均逐张目检，页面／控制台错误为空。最终布局补丁后重新通过完整门禁，并在生产版本复跑船坞三状态、双向、刷新续玩和地图。以后不设置场景／截图筛选时，验证器会额外保留两张 720p 截图，共 52 张。

```powershell
node --test scripts/tests/night-rain*.test.mjs
pnpm run check
pnpm run build
$env:NIGHT_RAIN_BASE_URL = 'http://127.0.0.1:3981'
$env:NIGHT_RAIN_QA_DIR = 'tmp/night-landmarks-production'
node scripts/verify-night-rain-landmarks.cjs
```

调试时可用 `NIGHT_RAIN_SCENES` 选择节点 ID 或 `catalog`／`river`／`ferry` 场景，`NIGHT_RAIN_CAPTURES` 只筛选截图；正式验收不设置筛选。浏览器脚本默认依赖本机已安装的 Playwright，可用 `PLAYWRIGHT_MODULE` 指定模块路径。
