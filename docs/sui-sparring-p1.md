## 战斗改进

P0 的弹反主要是气势扣减和双方共同停顿，敌人的连招仍照常继续。P1 将敌人的受击、震退、破架和恢复作为真实战斗状态处理。

下表时间和伤害以标准模式为例。反击与破架追击具有独立提示，后续挥剑动作优先于此前的弹反姿势。

| 情况 | 实际效果 |
| --- | --- |
| 正面攻击已有防守的敌人 | 敌人招架，积累少量架势压力，消耗玩家体力 |
| 抓住收招或硬直进攻 | 造成有效气血伤害，并有短受击停顿；轻打不能无限重置收招时间 |
| 连段中间弹反 | 敌人震退约 160 ms，暂停连招进度，增加架势压力并恢复玩家体力 |
| 弹反单击或接完连段 | 约 520 ms 硬直，随后留下明确反击机会 |
| 架势压力到 100 | 当前招式被取消，敌人破架约 1.6 秒，可进行一次强追击 |
| 第一击反击 | 普通反击为 10 点气血伤害，破架追击为 19 点；一般有效攻击为 4 点 |
| 无节制挥剑和闪避 | 体力耗尽后不能继续有效攻击/闪避，普通防守也可能失衡 |
| 弹回飞铃 | 飞铃变为金色并返程；撞回敌人后造成 10 点气血、25 架势压力与约 300 ms 硬直 |
| 弹反突进 | 截停馆主的实际位移，取消后续回锋并开放反击 |

标准模式下攻击消耗 12 点体力，闪避消耗 28 点，普通格挡消耗 20 点；精准弹反恢复 22 点。敌人会在攻击承诺前及连击间重新面向玩家，最后一段起手会锁定方向，因此及时闪到身后仍有价值，但不能永久站在背后白打。普通移动不能穿过敌人，闪避可穿身。

生命与体力统一在左上角玩家状态区，战斗及暂停时保留粗绿条与 `当前 / 100` 数值；体力低于闪避/挥剑消耗时分别使用琥珀色/红色，按键显示各自动作耗力。敌方气血统一使用红条，和玩家体力区分。失败提示位于体力条下，独立于弹反等战斗提示，区分体力不足、收招与闪避冷却；持续按住挥剑时，耗尽反馈有节流，回气成功出手后会清除对应提示。

飞铃、施法、钟域、突进、双侧旋转和腾空有独立画面表现。小屏跃击期间镜头预留头顶空间，落点一直可见；跃起时不让招式文字挡住角色。

初步对照使用了“持续挥剑并冷却就闪避”和“根据招式时机闪避绕背”两种无弹反策略，在三个种子下都未通过第一关；利用弹反、破架与反击的策略可以连续过三关。这是防止旧问题回归的脚本对照，不代表所有打法或真人胜率。

## 整备与进度

- 三档难度：舒缓、标准、挑战。起手速度与弹反窗口不同；可在当前关开战前调整，战报分别记录各场难度。
- 四种可选护符：回气符、稳心结、追风绳、破阵佩，对应体力恢复、格挡消耗、闪避及首击、攻击架势压力。本章最多携带一种，首关通过后锁定。
- 右上角“操作”保留六项改键；“声音”提供音量和弹反试听；“整备”提供难度、护符、主播布局和挑战链接。
- 主播布局在桌面预留左侧或右侧 20% 区域，画布及 HUD 一起重新排布；小屏恢复完整画面。
- 新存档键为 `sui-sparring-v2`。迁移 P0 的音量、改键、尝试/胜场等记录，首章从第一关开始，不把 P0 单 Boss 胜利算作首章通关。
- 已过关和结局都有检查点。中途失败或刷新从当前 Boss 战前继续，前面的胜利保留；暂停冻结战斗、体力与视觉计时。

## 挑战与战报

挑战链接包含内容版本、种子、三场难度计划和护符。相同版本与条件下，开场教学顺序和后续招式选择可复现；动作和站位不同会产生不同的战斗结果。从链接进入后修改整备，刷新会继续当前进度。

首章结局可复制挑战链接和下载 1200x840 PNG 战报。图中列出三位 Boss、实际尝试次数、弹反、破架、反击和约定达成情况。“获胜场次用时”只合计三次成功尝试的战斗时间，不混称为包含失败、暂停和聊天的总耗时。没有在线排行榜，也没有将本地记录标为防作弊成绩。
