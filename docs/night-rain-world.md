# 雨夜寻味：雨灯、药瓶与旧城回环

2026-09-26。沿用小型低多边形旧城，扩成能认路、能预见目的地、探索后能缩短返程的立体关卡。参考魂系的空间组织原则，不复制现成地图，也不以地图面积代替关卡质量。

## 路网与节奏

主线仍是旅馆 → 中庭 → 暗巷 → 高阶 → 屋脊 → 夜市。中庭是初次补给与战斗教学的安全落脚处；高处看得见金塔、夜市和运河；夜市侧的门只能绕到背后打开。原有铃兰回廊从高阶中段折返中庭，金塔望台则提供短支路与钱袋奖励。

西侧新增独立探索环：暗巷先看见关闭的水门；从望台横过悬钟桥，抵达残钟雨寺。寺院的刻露瓶把药瓶容量从三瓶加到四瓶，守钟客迫使玩家为补给提升付出战斗成本。随后沿百灯石阶降回地面，到莲池旧灯，从内侧打开闭水门返回最初的暗巷。桥、屋脊与台阶都有连续地表，没有隐藏传送。寺院的叠檐、桥钟、沿阶灯列与莲池分别承担远景定位、入口识别、下降引导和到达标志。

东侧摆渡避雨庵和莲池只留熄灭旧灯与铭文，没有复活或补给功能。小地图以中庭为唯一补给中心，两扇近路承担缩短返程的作用。门内侧立柱安装黄铜绞盘、止回爪和升降链条，门外只看得到封闭背板；开启后格栅升起，通道中央保持净空。

同一寻路器、同一角色碰撞半径测得：

| 返程 | 门未开 | 门已开 | 用途 |
| --- | ---: | ---: | --- |
| 西桥中段到莲池旧灯 | 约 54.4 米 | 约 13.9 米 | 探寺回到暗巷后，无需再走高阶与悬钟桥 |
| 中庭雨灯到运河门闩 | 约 98.3 米 | 约 23.8 米 | 主线回补后直接重返运河 |

距离为当前简化寻路折线长度，非真实玩家跑图时间。两门各自持久化，打开一门不解锁另一门。新增两名普通敌人，休息会重生；首领死亡永久保留。

## 雨灯与存档

仅中庭一处雨灯。首次 E／手柄 Y 只点火并记录复活点、立即存档，不回血、不补药、不刷新敌人；第二次及以后交互免费休息，恢复生命、体力与药瓶并重生普通敌人。敌人追击时不能休息。付费按钮独立标注“强化装备”，未点灯前不能强化。右下角只在写入成功后显示“已记录”。

死亡仍需主动选择“回到雨灯”，回到已点亮的中庭灯旁（未点亮则回旅馆）；钱留在死亡处，门、已拿奖励、瓶数提升和已击败首领不会回滚。雨灯基座有碰撞，复活点及精灵引导点位于灯旁，不站进模型里。旧版存档保留生命、剩余药量与敌人死亡状态，补入新区域字段和两名新敌人；旧档恰好站在原本无碰撞的中庭灯里时，仅向旁边挪出，不免费回血。

这是浏览器 localStorage 存档，非账号云同步。刷新保留当前战斗，不借刷新重置首领或恢复药瓶。

## 有限恢复

左下角常驻椰露药瓶图标和当前／上限数量，键盘 R、手柄 X 或触屏恢复按钮喝药。基础三瓶，一瓶恢复 60 生命；金铃护符提高为 80，刻露瓶只提升容量到四瓶。雨灯休息和死亡复活补满。

喝药需要约 1.12 秒，0.72 秒时恢复；期间受击可打断，已消耗药瓶不会退还。满血或空瓶不能浪费药量。角色收起伞、抬瓶、瓶口对准嘴、再放下，和战斗动作使用相同模拟时间。

## 文案与地图

普通模式保留瓶数、必要交互、拾取与存档反馈；主动读铭文才给谜语。宝宝模式的小精灵才解释瓶子作用、路线与机关。地图只标主要区域、已遇见的雨灯和门状态；普通模式不提前标出未拾取奖励，不堆满纸条与宝箱名称。当前归灯在 HUD、地图和死亡界面一致显示。

精灵在转角等待玩家绕过栏杆后再走，寻路对台阶边缘留余量；既不移动玩家，也不穿过关闭的门。

- `scripts/verify-night-rain-world.cjs`：实际键盘交互、受击喝药、西寺环路、保存刷新、首领造成死亡、中庭复活、桌面和手机 HUD／地图。
- `scripts/verify-night-rain-journey.cjs`：原主线、两个旧支路、精灵带路、两种叙事模式、首领、结尾继续探索和存档回归。
- `scripts/verify-night-rain-defense.cjs`：轻按弹反、长按防御、破防、键鼠／虚拟手柄／触屏和翻滚关键帧。

全部浏览器测试必须隐藏、静音，以测试专用 Pointer Lock 和 Gamepad API 模拟输入，不捕获桌面鼠标，不刷新用户打开的页面。像素检查只排除黑屏，还必须逐图检查构图与模型。没有据此声称实体手柄或所有设备性能已经实测。

旧版 v2 存档如果记录在莲池／摆渡，归灯迁移到中庭，当前位置、生命、药量、击杀与进度保留。吃完夜宵可选择“继续探索旧城”，保持原世界；晚餐只结算一次，刷新仍可继续，休息不会复活已击败首领。

敌人的抬手、重心后收、蓄力、释放、接触、随势和收招由模拟时钟驱动，暂停与顿帧一起冻结。棍客双手过顶、刀客扭腰蓄斩、铁伞突刺／重砸／危横扫各自有完整动作；接触在出手后 0.08 秒，与伤害使用同一常量。
