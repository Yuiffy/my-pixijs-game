# 雨夜寻味 · 第三关「天镜归航」

入口在第二关那伽沉殿后方：放出归水灯后，向东沿旧引水渠开启渠闸。继续使用同一个世界和旅人存档，所有旧地区均可回访。

## 路线与发现

主路为归水旧渠 → 苇光隘口 → 落霞盐阶 → 折光桥 → 镜湖外庭 → 环星观测院 → 拾星长阶 → 天镜归航台。水渠解释了雾河的水源，倾斜的芦苇指向山口，暖灯串联主路。

观测院的金色星环位于真实世界坐标 `(-40, 64, -697)`。它先从雾河沉殿露出，进入岩壁间短暂消失，离开隘口后再度显露。盐池的旧测星仪重复星环的轮廓，折光桥逐渐对正观测院；回到归航台可回望盐阶、悬廊与旧渠。没有放置远景替身或另一个星环。

旧地区的青蓝雨夜按行走距离过渡到盐原的玫瑰灰、暮紫天空和暖金光。雨量同时渐弱；反向行走与雨灯行旅也使用相同的连续变化。盐晶地面独立于旧城砖铺，岩台、盐池、桥墩、桥拱和观测院柱廊提供区域轮廓。

西侧可选路线为晒盐短堤 → 玫瑰盐池 → 废台外阶 → 旧测星台 → 测星悬廊 → 盐风归阶。行囊提供夜市钱，废台的星盐结晶永久增加 **20 最大体力**。从测星台这一侧开启盐风归门后，支路成为双向回环。

第三关共有 16 块连续可行走地形、3 道持久门、8 个敌人、3 处归灯和 13 个交互地点。盐风归灯位于主路初段，镜湖归灯用于首领重试，归航星灯用于关卡结束后的行旅。

## 双镜与首领

霞色折光镜在盐阶东端，月色折光镜在镜湖外庭东端。亲手转动后保留光路；两镜齐备才能开启观测院。与任何镜子交互都能看到明确的 `0 / 2`、`1 / 2`、`2 / 2` 进度。

羽啾的模型依据 `public/images/livers/chu2u.jpg`：米白短发、青蓝眼、金色星形发饰、浅蓝白服装。图鉴与场景共享配色和身份。

- **宇宙观测**：锁定玩家释放时的地面位置，给出 1.5 秒金圈警告，再落星。离开旧位置可以避开；第二阶段扩大落点。
- **烂梗三连**：三枚可弹反星弹依次瞄准并迟发，间隔 1.05 秒。持续横移，第三发后利用长收招近身反击。
- **星杖归位**：可弹反的近身迟落扫击，收招提供反击窗口。

首领身后的长阶通往归航台。送灯后得到 300 夜市钱并播放同一场景内的镜头演出：先仰望到达的星环，再转向走过的路线。演出支持立即跳过、刷新后继续与减少动态效果；退出后仍可自由探索。再次交互和读档均不会重复发放奖励。没有远程视频加载依赖，本轮生成积分消费 **0 / 1000**。
