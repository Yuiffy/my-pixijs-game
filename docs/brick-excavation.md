# 维阿发掘局

## 玩法来源

本游戏借鉴《新弹丸论破 V3》赌场小游戏 Treasure Hunter! Monolith 的连色挖掘规则，不使用原作图像或角色。

- [公开求解器的盘面逻辑](https://github.com/westpipe/treasurefinder/blob/main/Assets/Scripts/MapLayout.cs)：其模拟盘面为 22 × 11、四色；四向相连且至少有两块的同色组才可消除。孤立单砖被标为不可消除；外围存活格去重后按 1 → 2 → 3 → 4 → 1 变换一次。
- [公开求解器的计分逻辑](https://github.com/westpipe/treasurefinder/blob/main/Assets/Scripts/Scorer.cs)：消除砖块得分，覆盖宝物的所有砖块清空后获得宝物奖励。
- [求解器的使用说明](https://github.com/westpipe/treasurefinder/blob/main/README.md)：记录先挖掘、发现宝物、再针对宝物求解的流程，也提醒某些盘面可能无解。

上述代码是玩家制作的求解器，不是游戏官方源码。它清楚给出数字色阶的循环，但不能据此断定原作各数字对应哪一种颜色；本作下述颜色名称是自身的视觉设计。

## 本作规则

- 每局生成一块 10 × 10、四色的棋盘；只能敲击与四向同色邻居相连、至少有两块的砖群，整片同色砖一起清除。孤立单砖不可敲，砖块不下落，也不会自动连锁。
- 被清除区域四向相邻的每块存活砖按“朱红 → 青绿 → 琥珀 → 紫晶 → 朱红”推进一个色阶；同一锤即使从多面接触它，也只变色一次。棋盘旁常显循环图示；鼠标悬停或键盘聚焦时预览将清除的砖群和外围下一色，不揭示埋藏物位置。
- 每局按种子从岁己、栞栞、悠亚、米米和饼干岁中选出四或五件宝物，藏在互不重叠的小区域。五种宝物依次占 12、7、7、8、8 格，包围尺寸为 3 × 3 至 4 × 4；宝物呈折角、凹口等连通的非矩形轮廓。敲开其实际占据的格子，逐步发现它，清空该件所有占格后才算完整出土；轮廓外的空位不计入出土条件。
- 初始有 22 锤、两次洗牌。每次合法敲击通常消耗一锤，一次清除至少六块砖则返还该锤。洗牌将所有仍在场的砖各自换成随机新颜色，保留空格、宝物进度、分数与锤数，也可撤销；洗牌后仍有邻砖的宝物格至少能组成一个同色连片。
- 地图生成时预留一条在锤数内找齐宝物的合法路线，因此初盘存在解；玩家选择其他敲击顺序后，仍可能把宝物砖挖成四周全空的孤砖。改色不能让这种砖重新拥有邻居，所以它会直接判负。无同色连片但仍有可用洗牌时可继续；找齐宝物即获胜，锤数或洗牌机会耗尽且无路可走时结束。
- 每块清除的砖得 5 分，每件完整出土的宝物另得 120–180 分。获胜评级按剩余锤数评为 S/A/B/C；可以撤销、按相同种子重试或开始新的一局。

本作保留孤砖造成死棋的取舍空间，不设倒计时，改用可重试的步数挑战。两次洗牌为颜色死局提供补救，但不补回已敲空的格子，也不保证任意错误路线都能恢复。一盘要寻找多件隐藏宝物，清砖得分与完整出土奖励也让非目标砖有价值。四色使用不同符号辅助辨识，预览只展示落锤的公开结果，便于规划下一步。

## 实现

- 路由：`/game/brick-excavation`，入口位于 `/demos` 的“轻松挑战”。
- 规则：`src/components/brickExcavation/engine.ts`，纯函数状态更新；种子分别决定棋盘与宝物位置，相同种子可复现同一局。宝物轮廓以占格掩码表示；合法敲击与无可敲连片的判定共用同一砖群规则。
- 界面：React + CSS Grid。砖块使用原生按钮，支持触屏、鼠标、方向键与 Enter/Space。宝物采用完整透明角色插画覆于异形格的底层，不再把人物逐格裁切。
- 调试：`window.render_game_to_text()` 返回棋盘、宝物进度、分数、剩余锤数、洗牌次数与对局状态。

## 验证

规则与导航测试：`pnpm brick:test`。完整浏览器流程：`pnpm brick:verify`；输入专项：`pnpm brick:controls:verify`。浏览器脚本使用已安装的静音 Chrome，禁用测试语音，支持 `BRICK_EXCAVATION_URL` 与 `BRICK_EXCAVATION_QA_DIR`；交叉检查规则状态、页面、像素与控制台。修改源码后依仓库要求顺序运行 `pnpm run check` 与 `pnpm run build`。

## 触屏预览与连续键盘操作（2026-10-03）

触屏默认“先预览，再落锤”：点砖选择连片，显示清除数量、基础分、是否返还落锤，以及外圈下一色；点击“落锤”才改变棋盘。重复点砖仍只预览，可重新选区或取消。预览仅使用公开的砖色，不提前透露隐藏藏品或奖励。“直接敲击”模式保留一次点击落锤，桌面鼠标默认使用它；预览偏好随本机进度保存，首次游玩才按设备类型选择默认。洗牌、撤销、重开与新地图都会清除旧选区。

键盘 Tab 只停靠一个可敲砖块，再按一次即可离开棋盘；左右方向键按阅读顺序跨行，跳过空格与孤砖，上下键到下一可用行的最近列，Home / End 到首尾可用砖。Enter 或空格直接落锤，之后自动聚焦距离最近的可敲砖，不再丢回页面。没有可敲砖时聚焦洗牌，结束时聚焦撤销；撤销最后一步回到棋盘。砖块名称提供行列、颜色和连片数量，状态区播报操作结果。规则弹层会锁定背景焦点，关闭后回到规则按钮。

## 自动续局（2026-10-03）

自动保存当前矿层、合法落锤/洗牌记录和预览偏好。刷新或离开后返回会继续当前棋盘，得分、宝物进度、剩余资源和完整撤销历史都可恢复；结局也会保留，仍可撤销最后一步。重开、新地图和撤销立即更新本机进度，已有最佳成绩独立保留。

存档使用带规则版本的种子与操作记录，加载时逐步重放并验证合法性，不信任外部棋盘、分数或宝物地址。至多 50 次消除加两次洗牌，限制输入大小并拒绝损坏、未来版本和无法重放的操作；日后改变生成或结算规则时，需保留 v1 重放规则或新增版本迁移，不能直接沿用同版本。

无法读取时保留原存档，允许下载原文，当前页面仍能玩；只有明确点击「保存本局并替换旧进度」才启用覆盖。读取被浏览器拦截时也不自动写入。写入失败提示当前进度尚未保存，旧存档保持不变，点击「重试保存」后可继续。此功能是同浏览器本机续局，不是云存档或多标签页同步；多个标签页操作时以后保存的进度为准。

专项复跑：`pnpm brick:save:verify`，沿用 `BRICK_EXCAVATION_URL` 和 `BRICK_EXCAVATION_QA_DIR`。证据目录 `tmp/brick-save-baseline/`、`tmp/brick-save-dev/`、`tmp/brick-save-production/`。最终验收见 `progress.md`。

本轮验证：18 项规则/导航/恢复测试通过，含 40 个种子逐步恢复和撤销；开发与生产各五组存档专项、原三组输入回归通过。正常公开键盘通关 1030 分 A 级，间歇刷新及结局续局一致；故障注入验证写入失败、损坏原文下载和读取拦截。18 张最终截图均打开目检，DOM/像素/公开状态一致，无页面与控制台错误。ESLint、完整检查及生产构建通过。生产试玩：`http://localhost:3997/game/brick-excavation`。
