# 年关牌局：把「处理任务」改成「经历生活」

日期：2026-09-30。基线：`origin/feature/family-pressure-immersive` 的 `2c1ebbe`。

## 目标

Original prompt: 拉取最新分支完善相亲游戏；下班路上边走边聊，场景动态；微信、朋友圈内容不要反复相同；咖啡厅与其他约会采用第一人称；整体调研、策划和优化，让人感到自己在工作、认识对象和回应父母之间安排生活。

成功标准不是所有消息都回复、所有任务都清空，而是：玩家知道自己为什么暂缓一段对话，下班后还记得回来；对方分享的事有具体内容，上次相处留下的东西会在之后被提起；场景代表自己的位置。

## 调研与取舍

本次阅读以下官方商店介绍，结合仓库中的剧情、规则和实际浏览器流程做设计判断；没有将这些介绍当作亲自通关的证据。

| 参考 | 官方介绍中可核实的设计 | 本项目采用的方向 |

| [Florence](https://store.steampowered.com/app/1102130/) | 从重复的工作、睡眠、社交媒体生活出发，用专门设计的小互动表现关系变化 | 场景与动作承担情绪：下班的行走、把手机拿起来、坐到桌前。小游戏结果应与这次相处有关 |

| [Emily is Away](https://store.steampowered.com/app/417860/) | 用即时通讯、联系人信息、离开状态和对话选择承载跨年份关系 | 手机本身就是叙事界面；回到同一聊天要接得上，不能重新播放开场；延后回复要有真正的后续 |

选择按生活时段结算压力，而非用现实秒数强制扣分。阅读中文、使用辅助技术、切出去工作都不应被暗中惩罚。当前保留「一季的一段代表性生活」，本轮没有把它伪装成按真实分钟推进的完整人生模拟。

## 基线问题

1. 通勤采用按需渲染，镜头、汽车和街边人物全部固定。两家店的巨大正面挡住了前路。
2. 对象只有少量收到消息的变体，发送和回应却固定：猫或音乐也能被接成「我的午饭是黄焖鸡」。
3. 朋友圈四个人各有三四句话；发现爱好后，对象长期重复同一句爱好文案，所有动态都配同一类图片。
4. 「下班再回」点击后立即获得了解值，既不需要回来，也没有承诺状态。
5. 多轮对话存在组件内部，关闭手机后消失。电话开场与刚收到的妈妈消息也可能无关。
6. 约会镜头位于第三人称旁观位置，有一个代表自己的小人，对方是白边立牌；小互动只改文案。

## 本轮实现

### 通勤

五段街区沿行走方向循环，回收位置在镜头后方，远端藏在雾里。店铺位于人行道一侧，另一侧是路灯、树木、车辆与楼宇。步道接缝和盲道形成近处的移动参照，车辆与行人独立移动；雨雪也随场景时钟运动。

只有通勤且处于行走状态时连续渲染。隐藏页面、停步或离开通勤会停止动画；返回后台时限制单帧时间，避免街道突然跳跃。相机与手持手机只有轻微起伏，通知按钮保持稳定。微信和通话不会暂停行走，也不会推进游戏回合。

「停下脚步／继续走」明确可控。「减少动态效果」默认停步，玩家仍可自愿继续；此时取消镜头和手部的步行起伏。手机窄屏保留街景窗口，并收起次要状态栏。到家仍由玩家决定，不强制等待动画走完。

### 内容与连续性

- 16 套生活话题，每套包含收到的消息、匹配的回复、对方回应、追问、详细回答和继续倾听的回应。
- 扩充工作、家长、伴侣和孩子消息；增加七类常见回复的 21 套成对变体。
- 同学、同事、长辈各有 12 条动态。对象的动态使用同一生活话题；上次约会的次季会回忆那次活动和气氛。
- 种子和人物决定洗牌顺序，回合决定取哪张：一轮牌池用完前不重复；同一局重开手机或刷新不重抽，也不消耗规则引擎的随机数。
- 图片只用于适合图片的话题；纯文字动态保持纯文字。新芽、面包和小巷有对应的本地插图，不再共用晚霞图片。
- 多轮聊天按本局、本季、行动方、对象和联系人存储；关闭手机及刷新能接着聊。新开局清除旧会话。
- 给妈妈回电话时优先承接她本时段实际发来的话，避免突然换成另一套催促。

### 注意力取舍

| 行动 | 当下 | 随后 |
| --- | --- | --- |
| 工位上认真接对象的话 | 保留既有了解/关系收益与工作分神代价 | 该条不能反复领取收益 |
| 告诉对方在忙，约好下班聊 | 只发出约定，不提前增加了解或好感 | 通勤重新出现待回复与入口，接话后才结算 |
| 通勤中回复 | 有时间认真聊，不再扣工作精力 | 不直接推进一季 |
| 忘记兑现约定 | 没有阅读倒计时 | 结束这一天时结算失约，区别于已经认真回复 |
| 没处理紧急工作或家长消息 | 保持原有按时段结算规则 | 让工作、关系、亲情之间的取舍保持存在 |

使用旧版 v6 存档继续可玩，约定状态保存在现有周消息记录中。没有添加必须在线调用的语言模型或按刷新改变的内容。

### 第一人称约会

18 个场馆统一从玩家自己的位置观察。用坐姿、站姿与影院侧旁座位三组视角；餐饮桌面在近景，对方在桌子另一侧，不再绘制一个代表玩家的旁观小人。去除约会对象的白边展板与底座，现有头像贴图用半身轮廓呈现。咖啡杯、杯碟和桌面物件强化近景。

竖屏采用独立构图和限高对话面板，保留人物与部分桌面。站立场景补足身体和地面接触，全身素材取上半身构图，火锅蒸汽改为侧向半透明薄雾。这里仍复用原有头像与低模身体，部分素材自带的白底仍可见；不是全角色精细 3D 建模或逐张手绘透明半身立绘。

约会小互动在最终完成约会时只结算一次：体贴增进少量了解，放松缓解少量压力，愉快仅在双方原本愿意靠近时轻微增进关系，小尴尬也能增加了解但有少量压力。不会凭小游戏成绩制造吸引、绕过拒绝，AA 与请客的原有关系规则保持一致。气氛记录进入约会日志供之后回忆。

## 后续内容方向

以下是后续扩展建议，不属于本轮已经实现的系统：

1. 每个对象独有的三至五条连续生活线，例如项目换组、照护家人、搬家或爱好受挫，让同一话题在两三季后自然回访。
2. 从「被打断」到「主动排优先级」的短工作场景，提供可见的交付时点，允许明确协商而不是一味接受或拒绝。
3. 逐角色制作正确肩颈比例的透明半身立绘与表情，使约会人物不再受现有方形头像素材限制。
4. 扩展关系记忆：记得饮品、主动改约、尊重不想聊的话题，与人物边界联动；先做可解释的少量事件，再扩充数量。
