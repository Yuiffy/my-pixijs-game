# 小鸟一百层 / SUI SKYWARD

入口 `/game/jumpone`。保留原有小鸟与无尽攀登、空中冲刺玩法，修复固定画布超出手机屏幕、无触控和暂停、随机平台缺乏可达约束的问题。旧版复现截图与页面尺寸位于 `tmp/jump-improvement/baseline.*`。

视觉方向：奶油纸色与浅绿天空，用原有小鸟、薄云和金色阳光作为主画面。界面先呈现游戏场地与开始操作，再提供高度、平台层数和本机纪录；暂停与结算直接覆盖场地。动作反馈采用只向上跟随的镜头、远处云山视差及短促金色冲刺尾迹；减少动态效果时关闭尾迹和角色倾斜。

## 操作与规则

- `← →` / `A D` 移动；`↑` / `W` / 空格跳跃。跳跃为点按触发，需松开再按；支持离地 0.1 秒起跳宽限与落地前 0.12 秒按键缓冲。
- `Shift` / `K` 沿面朝方向冲刺 0.18 秒，冷却 1 秒。冷却结束后需再次按下，不会按住自动连冲。
- 手机左右、跳跃与冲刺按钮支持同时触按，捕获指针，松开／取消／切后台会清理输入。按钮也支持键盘聚焦后用 Enter 或空格操作。
- `P` 暂停或继续；`Esc` 只暂停，不会意外恢复；`F` 切换全屏。失焦和切到后台自动暂停，需要主动继续。
- 每 10 层用金色平台标记；100 层之后仍可继续攀登。高度取全程最高位置，平台层数取实际落地抵达的最高平台，两者独立。
- 失败可重试同一路线，也可在暂停／结算时换新路线。`?seed=` 保留路线种子，分享和刷新可得到同一路线。刷新从起点开始，不恢复未完成的对局。
- 结算时保存最高高度、最高层数和已结算局数至 `sui-jump.records.v1`；损坏记录会回退，存储受限仍可玩并明确提示。没有云端排行榜。

## 实现与可达性

`src/components/jumpGame/engine.ts` 是纯规则层，固定 120 Hz 积分，下降时按轨迹穿越平台顶面检测单向落地；Phaser 场景仅画图并推进规则，不以渲染帧率决定速度。较大的真实帧间隔限为 50ms，避免返回页面或卡顿时突然坠落。

世界坐标固定 800×600；不同屏幕以等比缩放保持相同路线和视野。镜头只向上移动，落到视野下方 80px 结束。平台随镜头生成和回收，宽度渐进从约 150–170px 缩至 106–126px，垂直间距为 100–145px，相邻中心横向最多相差 165px。普通跳跃初速 600、重力 1000、水平速度 300，路线无需冲刺即可攀登；没有人为安排的不可达断层。实际测试用相同规则驱动移动与跳跃，验证 80 个种子各连续攀登 120 层，不瞬移、不注入特殊平台。

Phaser 使用 `AUTO`。不修改 `preserveDrawingBuffer`；浏览器验收使用安装版 Chrome 全页截图，校验像素、DOM 与 `render_game_to_text()`。后者包含坐标说明、阶段、种子、位置速度、平台、冲刺与输入。`advanceTime(ms)` 仅在测试调用后切换到手动推进，正常玩家走实时循环。

本轮通用开发客户端的画布导出曾得到 800×600 纯黑图，而状态已正常落在第 1 层；此图已拒绝作为证据。测试包装器保留原有动作流程，等待资源完成、使用静音安装版 Chrome，并将画布导出改为全页截图；重新采集的页面和状态一致。后续验证直接使用仓库脚本，避免再次走这条 WebGL 画布导出路径。

## 混合输入修订（2026-10-03）

屏幕操作按钮分别记录 Enter 和空格；两个键同时按住时，松开其中一个仍保持操作。方向键、屏幕按钮按键及每个触点独立持有，释放或取消一处不影响另一处。Tab 离开按钮会取消该按钮的键盘操作；重复按键不会启动新聚焦的按钮，也不会在暂停恢复后重新启动旧方向。需要松开并重新按下。跳跃和冲刺仍需完整释放后再按，不会因另一键松开或重复而连发。

暂停、失焦、隐藏、重开、结束和离开页面时清理输入及指针捕获；右键不会驱动屏幕控制。正常全屏、路线分享、成绩记录及键盘菜单保留。

`pnpm jump:controls:verify` 复跑专项，沿用上述环境变量。覆盖双键、键鼠触混用、真实触摸部分释放/取消、320/390px、Tab、暂停后重复按键、冲刺冷却后再触发，以及不调用快进的真实帧移动和暂停。窗口失焦与文档隐藏分支使用注入事件。原 `pnpm jump:verify` 验证十二层正常攀登、结算清理、全屏、记录及重开等完整流程。证据分别保存于 `tmp/jump-controls-baseline/`、`tmp/jump-controls-dev/`、`tmp/jump-controls-production/`、`tmp/jump-controls-full-dev/`、`tmp/jump-controls-full-production/`、`tmp/jump-controls-shared/`；最终结果见 `progress.md`。
