# 自走棋自动存档

单人远征已有一个自动存档槽，保存在当前网站、当前浏览器的本地存储中。回到标题页点击「继续远征」，或按 Enter，即可续打。不需要手动保存；换设备、换浏览器或清除网站数据不会带走这份存档。

- 整备操作和每回合推进后保存，包括金币、阵容、商店及锁定状态、天赋、回合与随机流。
- 开战时先写入锁定检查点，再进入战斗。中途关闭后继续，会直接进入同一场战斗并暂停；不能返回整备购买、出售、刷新或改阵。选择继续战斗或快速结算即可。
- 恢复战斗从开战点重演，使用相同阵容和随机状态；前台、后台和恢复后的战斗均按固定 60Hz 推进。重开不会重抽战斗结果。
- 结算和天赋选择分别保存，恢复不会重复发放收入或重抽天赋。
- 另启远征覆盖当前存档；重新开始或正式结束远征会清除它。存储不可用时显示保存失败提示。

这是本地断点续玩功能，防止普通关闭／刷新回到备战改阵；不提供对手动修改浏览器数据或多标签页旧状态的服务端防作弊保证。联机房间使用自己的恢复流程。

## 验证

规则：`pnpm run autochess:test`，其中 `scripts/tests/autochess-system.test.mjs` 覆盖存档、读档、固定战斗结果及经济操作锁定。后台不规则计时的回归曾导致同场得分 172 与重演 170 不同，统一步长后结果、得分、随机状态及双方战况一致。

浏览器：先启动项目服务，再设置 `AUTOCHESS_BASE_URL` 并运行 `node scripts/verify-autochess-save.cjs`。使用安装版静音 Chrome、speech stub、整页截图及 PNG sanity；同时记录文本状态、DOM／画布尺寸、控制台／页面／HTTP 错误。截图和报告默认位于 `.tmp/autochess/save/`。截图异常时设置 `AUTOCHESS_HEADED=1` 重跑，并逐张打开目检。
