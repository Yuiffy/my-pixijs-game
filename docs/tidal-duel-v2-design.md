# 潮夜格斗：像素战斗与现代操作

Original prompt: 感觉太粗糙太简陋了，也不像死或生那么性感。要不我们模仿 MUGEN 制作成精品像素风格格斗，人物也可以做得很精致、吸引人，战斗也可以有特色有设计，有平衡性有交互感。当然有别的方式、不做像素也行。调研、策划、实现。

最新方向：默认不用泳装，使用小猫帽原皮岁己和月色旅装栞栞；原先晴海轻装成为可选皮肤，保持同一角色的招式和数值。

2026-10-04：改名「潮夜格斗 · 岁己 vs 栞栞」/ TIDE FIGHTERS，区分「晴海双打」。采用现代五动作键与按后防御，并校准四套衣装的动作身形。

## 调研依据与实际应用

- Elecbyte [AIR](https://www.elecbyte.com/mugendocs-11b1/air.html)：读取官方完整正文。动画元素按时钟推进，Clsn1 与 Clsn2 分离；本项目相应把像素动作阶段和攻击/受击判定独立定义，命中停顿同时冻结动作时钟。归档 `tmp/tidal-duel-v2/research/mugen-air.txt`。
- Elecbyte [CNS](https://www.elecbyte.com/mugendocs-11b1/cns.html) 和 [HitDef / State Controllers](https://www.elecbyte.com/mugendocs-11b1/sctrls.html)：读取状态、起手/有效/恢复、命中与防御硬直、推力和连段规范。应用于引擎状态机、实际判定窗口及训练显示，不复制完整 MUGEN 运行时。
- [Ikemen GO](https://github.com/ikemen-engine/Ikemen-GO)：读取官方 README 和编译器片段，确认角色数据、动画和状态控制分离的扩展方式；保留 Next.js 网页入口，用 TypeScript 固定步长模拟和 Canvas 渲染实现。
- [Infil 格斗术语表](https://glossary.infil.net/)：已获取官方 `https://glossary.infil.net/json/glossary.json`，阅读 Throw Tech、Frame Advantage、Cancel 和 Roman Cancel。拆投应有明确窗口；帧优势比较双方后续可行动时间；取消应真实移除收招，并用命中确认和资源限制其收益。
- Capcom [Street Fighter 6 / Fighting Ground](https://www.streetfighter.com/6/en-us/mode/fightingground.html)：官方介绍现代操作的 Light / Medium / Heavy / Special / Assist、方向加 Special，以及按住 Assist 连按攻击的辅助连招。本项目采用这些入门原则，接入自己的角色技、资源与命中确认路线；不是商业游戏操作的完整复制。页面存档 `tmp/tidal-modern/research/capcom-fighting-ground.html`。

上述研究提供机制边界和术语，不代表本游戏与商业格斗同等规模。没有使用第三方 MUGEN 角色、动作或引擎代码。

## 角色博弈

| 角色 | 实际优势 | 应对和代价 |
| --- | --- | --- |
| 岁己 | 快拳、向前猫步、接触后三段连掌、浮空追击 | 远距短手；落空不能继续连掌；终段恢复 31F，可防后反击 |
| 栞栞 | 长腿牵制、实际移动潮波、消耗能量的升潮对空 | 波起手 13F、同屏限一波；可跳/防/反/侧闪/对波；升击被防后恢复 34F |

默认五动作键为轻、中、重、必杀、辅助，方向后防/下后蹲防。地面中段可蹲防，跳入攻击必须站防，攻击时不自动格挡。单键必杀和下+必杀升击先学，236P / 623K 留作进阶。轻+中投/拆投、重+必杀超杀、辅助+必杀脱身，组合键在尚未生效的起手 70ms 内兼容先后顺序、退还未兑现招式费用，释放不补发普通招。

辅助轻：拳→二段拳→三段拳；辅助中：踢→踢掌→角色必杀；辅助重：拳→二段拳→浮空→满能量超杀。每次后续都需确认上一次真实命中；被防或落空停止，按住攻击不连发。手动猫步连掌仍允许命中或防御接触后接续，普通招手动取消仅允许命中。50 能量侧闪取消限非超杀命中；拆投窗口 0.14 秒，每回合一次 50 能量脱身限指定硬直。护盾、资源、反击高度、起身保护保留博弈。

投技若被飞行道具打断会释放目标；拆投清除追加投，避免意外反投。延迟波绑定招式 serial，不能误确认之后无关的动作；波连段遵循追击上限，回合终止清除未结算抓取与波。训练帧优势取实际命中时的剩余收招和硬直，迟到波不会显示原本起手总时长。

## 视觉与交互

四套服装、160 帧的八张图集覆盖待机、行走、跳、蹲、防、拳、踢、扫腿、角色技、升击、受击、倒地和胜利。动作由招式时钟驱动，非静态立绘移动。640×360 暮色栈道统一选人、对战和结算；像素残影、火花、护盾和超杀切入强化反馈，减少动态效果设置保留核心动作可读性。

实测原皮岁己走路约 156px、防御 151px，而待机约 184px；轻装攻击被最宽扫腿挤到约 151px。改为 448×448 透明容器、[224,440] 支撑锚点，标准身形仍为 184px；按待机、行走、直立防御分别校准条带，屈膝跳跃/蹲下和受击倒地保留共同身体比例，越界不许整体缩小。栞栞原皮待机一帧另有测量修正。编译器与渲染器共用规格，缩放后裁空 alpha 防止一像素悬脚。

近身接触时攻击者后绘制，动作不被另一角色遮住；结算仅绘制一名大胜者。

界面提供独立服装和镜像角色选择、单人三级 AI/同机/练习、优弱项与帧数表。默认指南只展开五动作键与基础防御，进阶组合/帧数折叠。训练栏置于画布下方，窄屏 HUD 独立显示生命、能量、护盾和脱身；触屏第一排四方向、第二排五动作。暂停清除历史、辅助路线和缓存，按住的键/手柄需释放后重新触发。
