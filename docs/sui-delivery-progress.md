## 当前可玩内容

入口 `/game/sui-spring`，新版标题《春日第一单》。首单“阁楼那碗热汤”包含小馆取餐、后院低门、两次可挑起踩踏的面团、屋顶旧招牌、面包支线、下陷反弹的晒饼棚、跨运河的轨道餐车、阁楼交付及交付后的花盆移动与木梯。普通订单不倒计时，反复受伤不损坏食物；已完成后可自由探索、选择五处片段练习或参加 95 秒的可选热气配送，超时照样能送达。

## 工程边界

- `src/components/suiDelivery/content.ts`：首单原始内容、存储 key 和画布基准；`levels.ts` 管理每单世界、建筑、订单交付、检查点、机关和解锁。
- `types.ts` / `engine.ts` / `save.ts`：固定 120Hz 模拟、版本化存档、永久与片段状态；`machinery.ts` 管理卷边烤盘、三阶段烤炉、热弹与闸门，模拟和绘图共用实际阀门/碰撞几何；`market.ts` 管理变高轨道、当前站台恢复、分餐臂窗口与分层传送带。复用旧引擎的基础手感参数，不修改旧四关规则。
- `DeliveryScene.ts`：Phaser.AUTO 画面、人物与托盘状态动画、面团抛起/变形、餐箱、雨棚、轨道餐车和交付场景变化。主角由 `playerAnimation.ts` 按真实模拟状态选择16张独立动作姿态，保留既有极简待机图；托盘、餐箱分层绘制，脚底锚点固定。`BreakfastView.ts` 将三张外墙画放在首单碰撞平台与交互物后方，并沿前三单已有表面绘制石缝、木纹和铺地；切换关卡销毁首单外墙，不增加碰撞面。其他建筑、室内、敌人与居民动作仍需精修。
- `feedback.ts` / `FeedbackView.ts`：接触位置与类型、短暂图形、衰减和有界队列；反馈不写存档、不修改物理。`audio.ts` 为配送专用 WebAudio 合成器，按材质和动作发声，四区使用不同短旋律；手势解锁，暂停/静音/退出即释放声音节点，旧原型沿用自己的声音。
- `DeliveryGame.tsx` / `delivery.module.css`：键盘、多指触控、暂停、失焦输入释放、焦点约束、全屏、整备、辅助与减少动态效果。根据容器调整实际可视范围，用 Phaser FIT 的 `setGameSize` 保持画布宽高比；手机竖屏不会把整个 960px 宽关卡硬缩成小条。
- `scripts/lib/sui-delivery-pilot.cjs`：作者路线规划，只发送公开七种按钮输入。浏览器回放不改位置、生命、无敌、机关或订单状态；重新载入验证使用实际浏览器保存的歇脚点档案。

现在通过显式关卡配置切换内容，首单原输入路线仍保持。`scripts/lib/sui-delivery-campaign-pilot.cjs` 通过七种公开输入连接十二单，无位置/生命/无敌修改。普通重访保留已开的道路；热气重跑与片段练习重新启动对应机关，避免软锁。第六单交付必得蒸汽扣：空中 K / 触屏「冲」短促横向冲刺，每次落地恢复一次；在地面同时按跳跃与冲刺会正常起跳，需离地后重新按冲刺。剧场模块 `theaterLevels.ts` / `theater.ts` / `TheaterView.ts` 分别管理布局、实际载人吊台/交互/冠轮窗口与场景；终章完成由真实入座交互触发。
