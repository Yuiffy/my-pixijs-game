# 平陆运河地理复刻：来源与转换

整理与实现：2026-09-27。目标是基于公开地理数据的可玩区域沙盘，不是工程施工图或某个历史日期的逐米复原。

## 已查阅的工程资料

1. [新华社 / 中国政府网：平陆运河全线通水，西南开辟江海直连通道](https://www.gov.cn/lianbo/202606/content_7071050.htm)，2026-06-03。正文确认全长 134.2 km；北起横州市平塘江口，经灵山县陆屋镇沿钦江进入北部湾；全线约 65 m 水位落差；马道、企石、青年三大梯级枢纽；马道最大上下游水位差 29.6 m；充水来源包含旧州江及西江干流；设计通航 5000 吨级船舶。最大水位差不能直接当作正常运行水位。
2. [中国青年网：分水岭让路，江海相逢](https://news.youth.cn/hotnews_41880/202609/t20260920_16878725.htm)，2026-09-20。正文说明平塘江口位于横州新福镇，北接郁江、南连沙坪河，两水形成 T 形交汇；运河自北向南穿过分水岭。因此不应把原始地形生成为一条从头贯通到尾的弯河。

没有用搜索摘要或无法打开的网页补造各枢纽正常蓄水位。游戏四级水位明确标注为示意值。

## 高程数据

数据服务为 [Mapzen / Tilezen Terrain Tiles](https://github.com/tilezen/joerd)，公开托管于 AWS 的 elevation-tiles-prod。使用 Terrarium PNG，解码公式为 R×256 + G + B/256 − 32768 米。

本次使用 z=10，x=820–822，y=445–448，共 12 张瓦片。每张 URL 保存在 geography-data.json 的 sources.demTiles 中。地理范围：西 108.48°，东 109.18°，南 21.70°，北 22.73°。按经纬度均匀取 48×72 个样点，得到原始范围 −177 至 534 m；海底负高程在游戏里概化为浅水底层，陆地按 5 m 量化。

Terrarium 瓦片已经综合、重采样上游 DEM。它不是原始 30 m 数据直接逐点应用，也不是水下河床精测。取样误差、地形量化、横纵比例和显示高差均应与精确复刻区分。地形不叠加随机正弦山峰，也不人为挖矩形复垦坑。

区域数据来源署名：Mapzen / Tilezen；SRTM、GMTED2010 数据 courtesy of the U.S. Geological Survey；全球 ETOPO1：DOC/NOAA/NESDIS/NCEI。参见 [上游署名说明](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)。本作的重采样、河床概化和游戏修改均不代表这些机构的认可。

## 河网与地名

通过 Overpass 获取公开 OSM 数据。返回的数据时间戳为 **2026-06-01T08:52:28Z**，不宣称为 9 月最新竣工资料。保留 25 条命名自然河流线段（郁江、沙坪河、旧州江、钦江）及 3 条平陆运河参考线段。原始 OSM way ID 保存在数据文件中，可追溯。

自然河流用于原始水系；运河参考线只做可切换的紫色对照，不自动凿通分水岭。OSM 的现状河线不等于精确的开工前历史河网；本版基于仍存在的天然河流与原始地势构造工程起点。

## 游戏化转换

- 地图保持经纬度方向，支持正北俯视和按地名定位。
- 水平格距约 1.6 km。航槽三格宽与船闸 3×5 格显著放大，不能解释为真实河道宽度。
- 13 / 7 / 3 / 0 层水位取总落差 65 m 的简化分级，不是实测水位；水域分区按枢纽所在网格行划分。
- 原始 DEM 的低处保留为自然洼地，回填目标根据邻格高程确定。至少保留一条可开挖通道免受回填封堵。
- 参考航线与实际可玩最短路线不同；后者仍由玩家施工和验收规则决定。

## 数据文件、许可与复现

- 游戏使用 src/components/pingluCanal/geography-data.json。
- 同内容可从 /games/pinglu-canal/geography-data.json 下载，包含原始取样高程、河线、地名坐标、瓦片 URL、OSM 对象 ID 和时间戳。
- 派生地理数据库按 ODbL 1.0 提供，署名 © OpenStreetMap contributors；代码不因数据许可而改变许可。高程保留其上游来源声明。
- 生成命令：node scripts/build-pinglu-geography.mjs。原始下载缓存于 artifacts/pinglu-geography；已有缓存时不重复请求。删除缓存后 OSM 可能返回更新的资料，时间戳随数据记录。
- 规则检查：node scripts/verify-pinglu-geography.cjs。
