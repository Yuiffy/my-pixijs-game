# 嘘，TA还在播 · 3D改造

目标：将整个同居潜行游戏变成第一人称3D，包括现有五晚、随机加班夜、男女身份、拿充电器/送外卖/隔墙语音/亲吻拥抱、声音风险、评分结局、解锁与分享。上一轮已完成2D目标引导，属于实际进展；本轮继续复用规则而改造完整表现与输入。

视觉：温暖奶油色墙面、木地板、鼠尾草沙发和柔和珊瑚色直播间，低多边形但有完整家具、生活物件与角色动作。主视觉是一间真正可走动的小公寓。
内容：全屏公寓与简洁准备界面 → 单一当前目标、准星和瞬时互动提示 → 下播后的双人结局和记录。
动作：第一人称转头、脚步与手持物件轻晃；开门时门板转动；恋人发现玩家时转身对视，亲密互动时伸手与靠近。

技术：Next/React中使用现有React Three Fiber与Three.js。任务、导航与碰撞独立于渲染；单层公寓用圆形身体与静态家具占地做运动学碰撞，同一尺寸构建模型，辅助寻路使用同一碰撞数据。默认无需跳跃或刚体堆叠。程序化几何构建原创房间、人物和道具，纹理在本机生成，无远程模型请求。

输入：WASD走动，鼠标锁定或拖动转头，方向键可转头/前后移动，E长按互动、M闭麦暗号、Q轻步、Shift快跑、P/Esc暂停、F全屏；手机左摇杆移动、右侧滑动转头、靠近后长按互动。提供可选的“跟随目标”辅助步行，不传送。

验收：每个关卡都通过3D视角与真实输入通关；检查家具/门墙碰撞、看向物体且近距离才可互动、声音隔墙与闭麦、亲密动作、手机输入、暂停/失焦/全屏、错误恢复与存档；系统Chrome完整页面截图通过非黑检测并目检，交叉核对文本状态、WebGL renderer与控制台；执行规则测试、ESLint、check，再顺序build。
