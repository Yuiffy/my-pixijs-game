# 加班夜：家里的小事

加班夜按种子分别抽取开场、餐品、家务、亲密动作和下播小故事，不再用种子的奇偶数选择两套固定流程。同一种子可以重玩；准备页的“换一个日常夜晚”和结算后的“再开一个加班夜”会换新种子。

## 每晚的变化

- 开场可能在门外走廊、沙发旁或客厅电脑旁。从外面回来先显示居中的下班提示，在门外完成开锁，再亲手推门、走进屋、关上大门；准备页会写清楚今晚从哪里开始。
- 外卖独立抽取果茶、DQ 冰淇淋、烧烤、炒饭、小龙虾、桶装方便面、米饭或骰子牛。约五分之一的夜晚会请玩家亲手做蛋炒饭或煎骰子牛。
- 喂猫、铲砂、拿充电器、三角洲报点、拥抱或亲吻、沙发休闲按夜晚组合，部分夜晚先做家务。主线五晚保留教学顺序。
- 猫咪会沿客厅可走区域溜达、趴下打盹；可以蹲下摸摸它。空碗任务需要量一勺猫粮，小猫会走过来吃；猫砂任务分三次短按铲起结团、装袋，不需要长按等待。

## 桶装方便面

超市送到玄关的是未开封桶面，不能直接算作送餐完成：

1. 拿桶面到料理台，放下，加水启动电水壶。
2. 水壶用游戏时间 12 秒烧水。玩家双手空出来，可以同时喂猫、铲砂、拿充电器或去沙发放松。
3. 水开后返回料理台，撕盖放调料、倒入热水，盖好盖子。
4. 立即拿起桶面和叉子，放到直播桌餐垫上即完成送餐；不用在厨房等面熟。10 秒焖泡计时会在端送及桌上继续，焖好后主播自己开吃。

目标指引会在烧水时转向其他事情，并保留水壶／泡面状态提示；水开、面熟时都有文字提醒。壶、桶面封盖、汤面、蒸汽和拿放动作都在 3D 场景中显示。暂停会冻结全部计时。

## 主播临时离席

加班夜开始约 30–52 秒后，主播会找一个没有正在拥抱、邀请或弹窗互动的时机，摘耳机、闭麦，沿可走路径去客厅洗手间。占用灯变红，人在门后不可见；短暂等待和洗手后沿路返回，重新坐下说话。

离席期间不会继续传出主播讲话或收到“麦里听见视频”的投诉。亲密任务会让位给其他事情；若还有待完成的亲密任务，可以先看视频或练压枪；若所有任务已完成，沙发优先提供睡觉，不需要等主播回来。入睡后用时间转场接到下播故事，不伪造完成未做的任务。隔音门关闭时主播会开门，避免把门打开到玩家身上；回来后在安全时恢复原先的关门状态。

这是游戏内压缩的生活片段，猫咪及角色为已有低多边形风格的程序化模型。角色名称、造型和称呼继续跟随主播酱／岁己／七海皮肤。

## 验证

- `node --test scripts/tests/hush-live.test.mjs`：旧章节回归、3,000 个种子的分布和确定性、70 个加班夜完整通关、未泡的面不可交付、可并行做家务、暂停冻结、猫咪避障／吃饭和主播洗手间往返。
- `scripts/verify-hush-household.cjs`：隐藏、静音系统 Chrome，准备页连续换夜覆盖三开场与八餐品，泡面／猫粮／铲砂／自制炒饭完整交互，暂停、离席和返回，以及 320px 真触屏互动。
- 正式构建保持 Next.js ESLint 和 TypeScript 检查。
- `scripts/verify-hush-camera.cjs`：在虚拟 Pointer Lock 中注入缓慢转头、异常回中位移和连续快速转头，验证暂停重入、右键拖动、手动接管自动行走和真实触屏。旧版单次 720px 异常样本会转过 103°；新版丢弃单轴超过 256px 的锁定鼠标样本，不限制多次正常采样累计的转角。此测试验证异常输入防护，不代表复现了用户设备的原始鼠标事件。

旧版 v1 存档不变：只保存皮肤、身份和成绩，不保存进行中的半局。此次没有新增存档迁移要求。


## 各做各的小事

- 门锁按种子随机选三种：顺逆交替转锁盘找卡点（轻响与波纹同步）、调铁丝角度并按住扳手试探阻力、抬起三枚弹子让缺口对齐剪切线。失误保留已经完成的部分，全部替代旧左右时机条。
- 两种料理共用真正的 3D 铁锅视图，桌面直接移动鼠标，不用按住鼠标、点按钮或滑条；触屏按住画面滑动。辅助操作默认收起，仍支持键盘。
- 骰子牛是有肉纹的方块牛肉，没有骰子点数。六个面分别受热 1.35 秒，每面有熟度条；上下快速甩锅翻前后面、斜向甩翻左右面，空中不受热，翻回熟面不重复计数，漏接保留已熟进度。六面都熟才出锅。
- 粒粒裹上蛋：鼠标位置控制铁锅倾斜，蛋液和六簇米粒按重力、惯性和锅壁约束在锅内滑动，米粒互相推开。缓缓绕圈让米饭通过蛋液，逐渐变金黄；全部裹蛋才完成，没有空中掉落的鸡蛋。
- 锁盘沿圆周拖动，在可见的绿色卡点区松手记住，容差 ±18°，提示和判定一致。铁丝在锁上方调整角度，直接按住画面下方扳手试转；弹子用相对拖动抬高，对齐金线后松手锁住。

- 电脑旁在没有待报点任务时可按E进入压枪训练；沙发也可切换训练。按住开火，向下拖动或用方向键抵消枪口上抬，24发后显示弹着点和命中数，可重新装填。训练成绩不锁住主线；原三角洲报点小游戏保留。
- 动画读游戏模拟时钟，暂停冻结；释放指针、失焦或暂停清掉扳手/开火状态，恢复不会自动继续。没有新增TTS。
- `scripts/tests/hush-minigames.test.mjs`验证种子组合、正确方向、扳手张力、弹子对齐、六面受热/翻面/接取、锅内滑动裹蛋、甩锅手势防误触和压枪补偿。`scripts/verify-hush-variety.cjs`覆盖桌面与320px真实触屏完成五种随机玩法、甩锅手势、电脑压枪与主播离席时入睡后完整结局。

## 主界面自由练习

主界面的六个入口无需解锁即可选择六面煎骰子牛、粒粒裹上蛋、转锁盘、铁丝探锁芯、弹子锁和压枪训练。练习保留同一套规则与操作，提供暂停、重玩、换玩法和返回；不会推进当前夜晚或写入通关成绩。失焦会暂停并释放按住状态。`scripts/verify-hush-arcade.cjs` 验证桌面/320px触屏逐项通关、甩锅、重玩/退出/存档隔离，以及焖泡中送餐、桌上面熟和暂停计时。
