# 加班夜：家里的小事

加班夜按种子分别抽取开场、餐品、家务、亲密动作和下播小故事，不再用种子的奇偶数选择两套固定流程。同一种子可以重玩；准备页的“换一个日常夜晚”和结算后的“再开一个加班夜”会换新种子。

## 每晚的变化

- 开场可能在玄关、沙发旁或客厅电脑旁。只有从外面回来才需要轻声开锁；准备页会写清楚今晚从哪里开始。
- 外卖独立抽取果茶、DQ 冰淇淋、烧烤、炒饭、小龙虾、桶装方便面或米饭。约五分之一的夜晚会请玩家亲手炒蛋炒饭。
- 喂猫、铲砂、拿充电器、三角洲报点、拥抱或亲吻、沙发休闲按夜晚组合，部分夜晚先做家务。主线五晚保留教学顺序。
- 猫咪会沿客厅可走区域溜达、趴下打盹；可以蹲下摸摸它。空碗任务需要量一勺猫粮，小猫会走过来吃；猫砂任务分三次短按铲起结团、装袋，不需要长按等待。

## 桶装方便面

超市送到玄关的是未开封桶面，不能直接算作送餐完成：

1. 拿桶面到料理台，放下，加水启动电水壶。
2. 水壶用游戏时间 12 秒烧水。玩家双手空出来，可以同时喂猫、铲砂、拿充电器或去沙发放松。
3. 水开后返回料理台，撕盖放调料、倒入热水，盖上焖 10 秒。
4. 泡好后掀盖搅拌，端着桶面和叉子到直播桌餐垫上。

目标指引会在等待时转向其他事情，并保留水壶／泡面状态提示；水开、面熟时都有文字提醒。壶、桶面封盖、汤面、蒸汽和拿放动作都在 3D 场景中显示。暂停会冻结全部计时。

## 主播临时离席

加班夜开始约 30–52 秒后，主播会找一个没有正在拥抱、邀请或弹窗互动的时机，摘耳机、闭麦，沿可走路径去客厅洗手间。占用灯变红，人在门后不可见；短暂等待和洗手后沿路返回，重新坐下说话。

离席期间不会继续传出主播讲话或收到“麦里听见视频”的投诉。亲密任务会让位给其他事情；如果只剩等待，可以去沙发看视频或接星星。隔音门关闭时主播会开门，避免把门打开到玩家身上；回来后在安全时恢复原先的关门状态。

这是游戏内压缩的生活片段，猫咪及角色为已有低多边形风格的程序化模型。角色名称、造型和称呼继续跟随主播酱／岁己／七海皮肤。

## 验证

- `node --test scripts/tests/hush-live.test.mjs`：旧章节回归、3,000 个种子的分布和确定性、70 个加班夜完整通关、未泡的面不可交付、可并行做家务、暂停冻结、猫咪避障／吃饭和主播洗手间往返。
- `scripts/verify-hush-household.cjs`：隐藏、静音系统 Chrome，准备页连续换夜覆盖三开场与七餐品，泡面／猫粮／铲砂／自制炒饭完整交互，暂停、离席和返回，以及 320px 真触屏互动。
- 正式构建保持 Next.js ESLint 和 TypeScript 检查。
- `scripts/verify-hush-camera.cjs`：在虚拟 Pointer Lock 中注入缓慢转头、异常回中位移和连续快速转头，验证暂停重入、右键拖动、手动接管自动行走和真实触屏。旧版单次 720px 异常样本会转过 103°；新版丢弃单轴超过 256px 的锁定鼠标样本，不限制多次正常采样累计的转角。此测试验证异常输入防护，不代表复现了用户设备的原始鼠标事件。

旧版 v1 存档不变：只保存皮肤、身份和成绩，不保存进行中的半局。此次没有新增存档迁移要求。
