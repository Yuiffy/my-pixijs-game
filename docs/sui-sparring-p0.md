# 岁岁过招 · 竹庭篇 P0

2026-09-06，独立单 Boss 原型。入口 `/game/one-more`，本站 `/demos` 已增加游戏入口。没有部署到公网。

## 当前可玩内容

- 小岁与饼师傅，竹庭场景及看台饼干；分层角色具有移动、挥剑、防御、弹反、闪避、受击和胜负动作。
- 试探横挥、三连敲击、举势重击。普通格挡保命，按时重新格挡会弹反，重击有锁定落点并可闪开。
- 三个宣言：“这把拿下”“三招全接”“一滴不掉”。达成需满足真实战斗条件，并记录标准/舒缓区别。
- 5 格生命、气势击破、失败原地重试、暂停、失焦自动暂停、音量与静音、舒缓辅助、本地胜场和宣言印章。
- 初次访问静音，点击声音工具后才开启合成音效。没有播放录播、切片或直播语音。
- 弹反成功有独立金色冲击圈、放射闪光、Boss 后仰、85 ms 打击停顿、成功提示及累计次数；进入招式弹反窗口时显示金色提示。
- 右上角“操作”可查看和调整六项按键，重复绑定会交换按键，修改可保存；“声音与难度”页提供弹反音效试听。弹反使用四层金属敲击声，和普通格挡分开。
- 桌面与手机横竖屏布局，手机支持多点触控按钮；设置与暂停对话框约束键盘焦点。

## 操作

| 输入 | 行为 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| J | 挥剑，可按住 |
| K | 格挡；在命中前重新按下可弹反 |
| Space | 闪避；有方向输入时向该方向，无方向时后撤 |
| Esc | 暂停/继续，或关闭设置 |
| R / Enter | 结算后快速重试 |

所有战斗动作也有可按住的画面按钮。离开页面保存已结束的战报、尝试数和偏好，重新打开回到该 Boss 的战前状态，当前战斗不从中途恢复。

## 结构与素材

规则在 `src/components/oneMoreGame/core.ts`，按 120 Hz 固定步长推进；Phaser 场景负责图形、镜头与事件效果，React 负责 HUD 和菜单。手机取景随双方位置调整，所有判定继续使用同一逻辑坐标。

背景通过内置 ImageGen 生成并转换为约 300 KB WebP；HUD 复用本站岁己图片，战斗角色和 13 类短音效为本原型生成。素材来源和提示词保存在 [ASSET_SOURCES.md](D:/workspace/myrepo/my-pixijs-game/public/games/one-more/ASSET_SOURCES.md)。

调试接口 `window.render_game_to_text()` 返回当前局面和音频状态。`window.advanceTime(ms)` 进入手动计时并推进规则；`window.suiSparring.live()` 恢复真实帧驱动，接口不提供直接修改生命、宣言或战斗结果的入口。

## 验证

```powershell
node --test scripts/tests/one-more.test.mjs
node scripts/verify-one-more.cjs
node scripts/verify-one-more-feedback.cjs
pnpm run check
$env:NEXT_DIST_DIR = '.next-one-more-build'
pnpm run build
```

浏览器脚本默认地址为 `http://127.0.0.1:3821`，可用 `ONE_MORE_URL` 覆盖；优先使用系统 Chrome，整个测试浏览器静音。它会先检查服务响应，再通过页面按钮、真实键盘输入和 CDP 触屏事件验证。没有改写引擎生命值或直接强制胜利。

已验证规则测试 10/10：三个宣言可达成、长按格挡与弹反区别、完整三连、重击与闪避、暂停、刷新恢复、辅助条件、不同帧率、坏存档、打击停顿和按键迁移/交换。浏览器覆盖真实帧推进、失败/胜利、全部招式、音频开关与暂停停声、鼠标/触屏、设置保存及跨视口切换。

浏览器证据保存在本地忽略目录 `artifacts/one-more-qa/`，14 张截图覆盖 1440x900、1440x600、390x844、844x390、320x568，均做非黑屏/非透明检查并逐张目检；另断言战斗状态与招式/弹反提示无重叠。`report.json` 保留各截图的 DOM 尺寸、局面和错误列表。它们不自动进入版本管理。

弹反/操作专项的 10 张截图和音频输出采样在 `artifacts/one-more-feedback/`。专项用实际页面输入验证改键后弹反、旧按键恢复、冻结战斗但推进视觉反馈的停顿、提示消退、暂停停声及四个视口的操作面板。通过 Web Audio 分析节点在浏览器设备静音前采样，普通格挡/弹反的 RMS 约为 0.011 / 0.030，证明声音有实际输出且本次弹反更突出；此数值不等同于设备响度或主观听感测试。

最终全仓 `pnpm run check`、随后独立构建目录的 `pnpm run build` 和 `git diff --check` 通过。生产构建生成 `/game/one-more`，浏览器完整流程的页面错误、控制台错误和失败响应列表为空。开发服务独立运行于 `http://127.0.0.1:3821/game/one-more`，日志位于 `artifacts/one-more-dev.log`。

## P0 边界

目前只有一个 Boss，没有多人联机、弹幕投票、三 Boss 章节或在线排行榜。难度与节奏尚未经过真人样本测试；自动输入在标准模式约 20 余秒无伤过关，只能证明规则可行，不能代表一般玩家完成时间或游戏是否耐玩。

下一轮优先收集首玩者对读招、格挡时机和重试意愿的反馈，再决定扩展 Boss 内容。已有研究与三 Boss 规划保留在 [游戏策划](D:/workspace/myrepo/my-pixijs-game/plans/sui-one-more-game-design.md)。
