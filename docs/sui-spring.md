# 岁己 · 春日第一封信

入口 `/game/sui-spring`，作为可玩原型放在 `/demos`「动作与探索」分类默认顺序的最后。包含四个手工关卡，背景是「初次开播的春日小镇」。本章采用报名、试音、准备、首播的原创童话，不把缺乏来源的情节当成岁己的真实经历。用户试玩反馈是「能玩，但仍明显像 demo」，当前不作为成熟游戏推荐在前排。

## 关卡与节奏

| 关卡 | 地点 | 新内容 | 探索奖励 |
| --- | --- | --- | --- |
| 1-1 一封春天的信 | 春日花田 → 邮局 | 高低跳、加速远跳、巡逻者、可踢出的饼干壳、弹簧 | 三段高处路线 |
| 1-2 风铃与试音室 | 风车坡 → 试音室 | 移动台、先预警的水平弓箭、摆锤、蓄力跳跃敌人 | 越过射线的高路 |
| 1-3 把星光搬进来 | 屋顶花园 → 工作室 | 迫击炮实际碰撞落点预告、落地引信、飞行敌人、延迟塌落的木板 | 弹簧与屋顶上的信物 |
| 1-4 今晚，第一次开播 | 暮色后台 → 首播舞台 | 既有机关组合、封闭场务考验、三次踩头最终战 | 三枚可选信物与章末结局 |

每关有两个补满血的检查点，掉落后约 0.65 秒重生。死亡保留已到达检查点之前的金币和本次信物；检查点之后的收集需要重新取得。无限重试，不消耗生命次数。每关三枚星光不阻挡通关，已通关关卡可随时重玩，存档保留历次取得信物的并集、最高金币和最佳用时。

## 操作与手感

- 方向键 / A、D 移动；空格 / W / ↑ / Z 跳跃；Shift / X 加速；Esc / P 暂停；B 打开图鉴。
- 地面行走 235 px/s，加速 365 px/s，地面加速度 1900 px/s²，空中加速度 1050 px/s²，有落地摩擦和空中轻微阻尼。松开加速而仍按方向时平滑减速，不会瞬间截到步行速度。
- 起跳速度 590 px/s；按住时降低上升重力，松开时截短上升；0.11 秒离台宽限、0.13 秒落地前跳跃缓存；保持按住不会自动连跳。
- 踩怪时按住跳跃可反弹更高。缩壳、踢壳、踩停与壳击败其他敌人均有实际规则。
- 触屏支持同时按方向、加速与跳跃；同时检查 `navigator.maxTouchPoints` 与 pointer 媒体查询，保证混合输入设备与横屏浏览器也显示操作按钮；pointer cancel / lost capture、失焦、后台与面板切换均清理输入。面板会暂停模拟，关闭后恢复键盘焦点。
- 设置可关闭原创合成旋律与音效；轻松模式把受伤保护时间由 1.6 秒延长到 2.8 秒。声音只在用户操作后解锁。

## 角色与美术

主角沿用自走棋岁己的白发、红眼、红帽与披风；新生成一张透明跑步姿态，完整提示词、工具和处理记录见 `sui-spring-art.json`。只裁 alpha 边与等比缩小，没有修改现有自走棋素材；48/64/96px 对照见 `.tmp/sui-spring/sprite-review.png`。

敌人：小松绿（巡逻）、犬绒 Mofu（饼干壳）、恬豆（蓄力跳）、浣熊店员（弓箭）、又一（迫击炮）、羽啾（正弦飞行）、四时小路（最终场务长）。复用 `public/images/autochess/portraits/minimal/`，通过一高一矮的 squash/stretch、蹲伏、蓄力圈、受击闪烁表现状态。图鉴接近即收录，保存图片、角色身份、行为和应对办法。

背景与机关为代码绘制：分层山丘、村屋、云、风车、花树、邮筒、风铃、屋顶、灯串与舞台帷幕；主角、敌人、地图与说明使用同一套暖纸色、绿色和低饱和粉色。UI 支持 reduced-motion，关卡面板有键盘焦点约束。

## 结构

- `src/components/suiPlatformer/content.ts`：关卡、敌人资料和出生点。
- `engine.ts`：独立的固定 120 Hz 模拟，碰撞、跳跃、敌人、弹道、收集、检查点与存档。
- `SpringScene.ts`：Phaser.AUTO 渲染、相机平滑、粒子与素材；不依赖 preserveDrawingBuffer。
- `SpringGame.tsx` / `spring.module.css`：DOM HUD、地图、图鉴、设置、输入、存档及引擎生命周期。
- `audio.ts`：原创小旋律与合成音效，无 TTS。

存档 key 为 `sui-spring-platformer-v1`。存档在当前站点与浏览器中保存解锁、历史信物/纪录、图鉴和设置；刷新不会恢复关卡内瞬时状态。测试控制接口只在 `?test=1` 时注册。`render_game_to_text` 始终可读，便于辅助调试。

## 设计参考

- [Celeste 官方公开 Player.cs](https://github.com/NoelFB/Celeste/blob/master/Source/Player/Player.cs)：参考可变跳跃、离台宽限等容错机制的思路，本作单独实现并调节参数，没有移植其源码。
- [任天堂 Iwata Asks：New Super Mario Bros. Wii 的开场设计访谈](https://iwataasks.nintendo.com/interviews/wii/nsmb/0/3/)：以最初遇见的简单敌人介绍跳跃。本章也先提供无危险跑道、单一巡逻者，再加入缩壳、弹道和摆锤；「介绍—练习—组合—收束」是本章采用的组织方法，并非照搬其地图。
- [Clever Endeavour 官方 Ultimate Chicken Horse 介绍](https://www.cleverendeavourgames.com/uch-press-kit)：机关与平台组合的灵感来源。本作采用固定单人路线，机关都有预告与恢复空隙。

## 验证

`pnpm spring:test`：14 项规则，包括长短跳、惯性/空中反向、宽限与缓存、踩怪/壳、两种弹道、检查点、移动/塌落平台、最终战、暂停与存档；还对四关执行完整正常输入规划，四关均零死亡取得三枚信物并通关。测试只在开始前解锁所测关卡，不修改角色位置、血量、无敌或机关。

`pnpm spring:verify`：安装版静音 Chrome，禁用 speech API；第一次浏览器请求前确认服务端 HTTP 200。通过 DOM 真实点击开始、切换关卡、图鉴与设置，用键盘检查跳跃、移动、暂停与面板关闭后的焦点恢复；完整回放上述正常输入，通过四关与 12 枚信物，再验证刷新后的解锁/图鉴/信物存档。触屏用 CDP 多点触摸检查同时向右与跳跃、touchCancel 后释放输入。

最终生产浏览器证据 `.tmp/sui-spring-release/report.json`，18 张整页截图均经 PNG sanity、画布尺寸、DOM、文本状态与浏览器错误检查，并逐张打开目检；浏览器错误为空。横屏额外确认 54px 触屏按钮完整可见，未被容器最小高度裁掉。验证过程屏蔽第三方广告/统计与本站访问计数，音频与 speech API 在测试浏览器中静音。未使用已知黑图路径、共享 SwiftShader 客户端或 canvas.toDataURL。

最终 `pnpm run check` → `pnpm run build` 顺序通过，保留 Next 构建 ESLint；新代码定向 ESLint 无警告，项目已有 RPG / 武侠未使用变量警告未改动。游戏库 6 项回归通过。本地试玩服务 `http://127.0.0.1:4121/game/sui-spring`。2026-10-23 用户授权将本轮游戏连同分类末尾排序提交并推送，记录见 `progress.md`。自动通关证明路线可达，不等于游戏的趣味性和完成度已达到成熟作品标准。
