# 晴海对决 · 岁己 vs 栞栞

Original prompt: 制作一个新游戏，可以用沙滩排球的引擎和素材，做一个岁己vs栞栞的精致的格斗游戏，对标死或生。以后还支持加入更多角色。

视觉主张：明亮通透的晴海、精细 3D 风格运动角色与克制的电影镜头，拳脚落在真实的沙地空间里。

内容顺序：角色与模式选择 → 回合开场 → 拳脚、投技与反击的对决 → 回合结算 → 三局两胜与重赛。自由练习提供静止木桩、自动防御和实战陪练；开局及重置站位时满气势，必杀正常消耗，可再次重置恢复。

动作主张：预备与恢复让出招可读；命中停顿、沙尘和镜头反馈重量；侧闪的深度位移、浮空追击与必杀特写突出空间和节奏。

## 实现

- `/game/tidal-duel`，游戏大厅入口与独立分享文案。
- 沿用沙滩排球的 Canvas 2D 呈现、海滩、奔跑、起跳和胜利素材，新增两套专用格斗图集。精细 3D 风格的 2.5D 图像表现，非实时骨骼 3D。
- 独立 120 Hz 战斗引擎：300 生命、60 秒、先赢两回合；平局不授胜，继续加局。
- 攻击预备、有效、恢复与命中范围；拳脚压投技、投技破防反、三向反击截对应拳脚。反击窗口短，猜错可被惩罚。
- 上、中、下段，蹲防与跳跃，直线攻击与追踪腿法，侧闪的深度轴，连段预输入、暴击硬直、浮空、最多三次空中追击、倒地与保护起身。
- 岁己快速连掌、栞栞回旋腿法；满气势必杀为「月下猫步」「白昼潮汐」。必杀允许防御，也有起手与恢复。
- 单人三级 AI、同机双人、自由练习；键盘、多指触控与标准手柄。暂停、玩法弹层与后台失焦清空输入并冻结战斗，返回选人需确认。
- 静音偏好与最佳连击保存在浏览器，存储不可用时仍能游玩。音效为原创合成短音，无 TTS。
- `render_game_to_text()` 是可见战斗的公开状态；`advanceTime(ms)` 使用同一引擎。开发环境另有 `tidalDuel` 验证句柄，生产不暴露。

## 操作

| 动作 | 1P | 2P |
| --- | --- | --- |
| 移动 / 跳 / 蹲 | A D / W / S | ← → / ↑ / ↓ |
| 拳 / 踢 / 防御 | J / K / L | 1 / 2 / 3（也可小键盘） |
| 反击 / 投技 / 必杀 | U / I / O | 4 / 5 / 6 |
| 侧闪 | 左 Shift | 右 Shift |

U 反中段，W + U 反上段，S + U 反下段。J J K 浮空，J K 突进，K K 回旋。单人也可用方向键和数字键；同机模式两套按键独立。P / Esc 暂停、F 全屏、Enter 继续回合演出。

## 扩展角色

`src/components/tidalDuel/roster.ts` 的 `FIGHTERS` 是唯一角色目录。新增条目配置身份、颜色、立绘、运动图集、专用格斗图集、移动速度与招式；选择界面、战斗规则、AI 和资源加载自动枚举目录。每个角色的招式配置包含高度、起手/有效/恢复、伤害、距离、追踪、浮空/倒地和后续招式。

可复制现有角色配置后覆盖；`moves` 必须包含 `punch`、`kick`、`lowPunch`、`lowKick`、`airPunch`、`airKick`、`throw`、`super` 等基础入口，以及 `followups` 引用的全部招式 ID。扩展测试注册了第三角色，实际验证其速度、伤害倍率、新连段和必杀，而后恢复原有目录。

专用格斗图集按 0 准备、1 直拳、2 侧踢、3 下段、4 防御、5 反击/投技、6 受击、7 倒地排列。`public/games/tidal-duel/frames.json` 记录实际裁切与站立参考高度；固定参考高度避免倒地角色被放大。生成提示词和素材来源见同目录 `assets.json`。
