# 每晚都在一起

日常是关卡的一部分。准备页只选择夜晚与角色，不再有独立 NEW 模式或选餐入口；晚饭随夜晚种子变化。原 v1 存档、五晚解锁、星级、装备奖励与加班夜沿用。

## 关卡节奏

| 夜晚 | 直播期间 | 收尾 |
| --- | --- | --- |
| 1 借过一下，宝贝 | 拿回充电器，放到沙发右扶手托盘 | 回沙发，完成简短入门 |
| 2 外卖要趁热 | 轻声开门、送晚饭、拿回充电器 | 在沙发小睡、下播故事 |
| 3 隔墙有耳 | 轻声开门、送饭、关门报点、沙发娱乐与微信 | 沙发小睡、下播故事 |
| 4 想吃你做的饭 | 轻声开门、炒蛋炒饭、送饭、偷偷拥抱、沙发娱乐 | 沙发小睡、下播故事 |
| 5 不公开的纪念日 | 轻声开门、送饭、充电器、报点、晚安吻、沙发娱乐 | 沙发小睡、下播故事 |
| 加班夜 | 种子决定做饭或外卖，组合熟悉的活动 | 沙发小睡、下播故事 |

晚饭轮换果茶、DQ冰淇淋、烧烤、炒饭、小龙虾、方便面和米饭。烹饪晚固定为自制蛋炒饭。食物差异体现在模型、名称和对话，不包含温度或饥饿系统。

开门随机使用转锁盘、铁丝探锁芯或抬弹子；做饭随机使用六面煎骰子牛或倾斜铁锅让米饭滑过蛋液。失误保留已完成进度。娱乐可以看猫猫动画或玩压枪训练，也可以走到电脑前开练；实际大声外放触发游戏内微信，回复戴耳机降低音量，安静时不强制投诉。休息累计八秒后可以收起手机。当晚事务全部完成即可对准沙发坐垫小睡，主播暂时去洗手间也不会阻止收尾。

## 空间与引导

- 充电器放置目标独立为 charging：右扶手木托盘。托盘模型和手部放置动画共享 AIM_POINTS.charging，行走终点在托盘前；沙发中心只负责休息/收工。
- 晚饭只在直播桌左侧餐垫及其食物上触发摆放，屏幕、键盘和桌腿不再代表餐垫。射线采用最近一层交互标记。
- 卧室床不提供睡觉动作。玩家全程在客厅沙发休息；下播炒饭发生在厨房，洗澡之后岁己来到客厅沙发旁。对应引导、对话和角色站位一致。
- 每次只提示下一项动作，拿着物品时优先送达；关门挡路时先提示开门，娱乐放在当晚事务完成之后。

## 存档与验证

下播故事完成后记分、记星、解锁下一晚；重玩保留该晚与种子，不会跳回独立模式。暂停冻结所有小游戏与剧情；下播不计直播超时与声音惩罚。没有局内中途存档。

`pnpm hush:test` 覆盖全部关卡合法路线、旧机制回归、七种餐点、自制饭、四结尾、沙发睡觉、充电托盘、微信去重、暂停、旧存档与正常关卡解锁。

`verify-hush-3d.cjs` 从新存档依次完成五晚和加班夜；`verify-hush-daily.cjs` 从正常关卡检验餐点轮换、料理、手机、沙发休息及两种下播场景，包含320px触屏。浏览器使用隐藏系统Chrome，不注入完成状态或位置；自动走路通过游戏内“跟随目标”执行。

`verify-hush-chapters-smoke.cjs` 用真实RAF计时从新档完成入门和第二晚，确认托盘拿放、沙发睡觉、客厅下播互动、解锁与刷新保存，不调用advanceTime。

## 小游戏动画更新

小游戏画布和厨房锅／牛肉读取同一模拟状态，动画不依赖70ms一次的React HUD刷新。暂停冻结物理与剧情，释放输入不会跨暂停保留。桌面料理直接用鼠标移动与甩动，门锁在画面上拖动后松手确认；手机用触屏拖动，方向键和空格及收起的辅助控件仍可使用。六种玩法和专项验证详见 `docs/hush-household.md`。

`verify-hush-timing.cjs` 在隐藏、静音的系统Chrome中对桌面和触屏分别采样5秒，比较指针实际更新比例与判定时钟，验证暂停／继续、三次400ms按住动作、触屏接触及炒饭键盘操作。`HUSH_TIMING_BASELINE=1`用于记录旧版对照；无头浏览器的RAF频率不是玩家设备帧率保证。

从门外回家的夜晚，先在走廊显示“刚下班回到家，悄悄进去…”。解锁、推门、入屋与关门是独立步骤，入屋时相机随身体经过真实大门，开锁前不能穿入房间。
