# 雨夜寻味：主角动作与默认重击

2026-10-04。目标：默认重击改成有重量、能预判、需要承担收招风险的动作；站立、步行与攻击连续衔接。旧的快速重击作为后续武器的特点保留。

## 改动

- 折雨伞、铁骨伞采用沉身、双手提伞、落伞、惯性跟随、带重量收势的时间轴。默认重击 0.72 秒命中，1.42 秒结束，伤害 36、架势 34、耗力 35；此前分别为 0.49 / 0.86 秒、41 / 45 / 31。
- 默认满蓄 0.95 秒自动释放，只释放一次。蓄满追加 17 体力，伤害 57、架势 58；此前为 0.75 秒、追加 12、68 / 78。松手沿已经完成的提伞姿势继续，非武士刀武器至少保留 0.28 秒出手时间。
- 默认重击出手后几乎不能改向；1.20 秒后允许防御类取消，轻击、重击、跳跃必须等 1.42 秒收势完成。后摇不会因重复按键提前结束。疾跑和跳跃重击同样增加收势并降低收益。首领继续抵抗重击中断和架势压制。
- 雨切武士刀保留旧快速重击的时间、攻击范围、消耗和回旋特点，必须通过既有锻造与栞栞解锁条件获得。长枪采用水平直刺；双短刃、巨槌沿各自实际速度播放。
- 玩家使用独立关节模型：腰与胸分开，肩肘、髋膝和脚踝采用两段骨骼求解；脚掌保持接地，头部稍作反向稳定。三种外观、已装备的防具和所有武器继续使用原来的造型。
- 步态按实际移动距离推进，按模拟时间衔接动作；暂停和命中停顿冻结战斗姿势。翻滚继续围绕骨盆，检测可见模型避免穿地。喝水让瓶口朝向嘴部，饭后过场保留进食摆臂。
- 武器拖尾采样实际握持点和武器长度，挥击声音在出手时触发，轻击连段分别发声。锻造面板从真实武器规则读取伤害与耗力。
- `motionVersion: 2` 安全接续旧存档：正在播放旧玩家攻击或蓄力的旧版本回到待机，保留生命、消耗、装备、击杀和探索。新版攻击存读档保留已命中标记。旧敌人的命中时钟迁移只执行一次。

## 验证与复现

`pnpm night:test` 包含动作规则、取消窗口、部分／满蓄连接、一次释放、六种武器的命中姿势和连续性、双手距离、整周期脚踝可达性、存档与音效时机。完整主线、归灯暗线、两岸和副本仍通过普通公开输入完成。测试控制器按实际武器的收招时长选择轻击或重击。

`scripts/verify-night-rain-player-motion.cjs` 使用静音安装版 Chrome、正常输入和合法存档准备位置，拍摄重击各阶段、蓄力松手、步行／跑步／跳跃／翻滚、轻连段、防御、六武器、三外观、喝水、打抛饭过场、真实命中与首领后摇反击、390px 触控和虚拟标准手柄。每张画面检查像素、画布、DOM 与 `render_game_to_text()`，并人工目检。

最终结果：137 / 137 项规则通过；完整检查和随后执行的生产构建通过，构建 ESLint 保持开启。开发与生产各 40 张截图全部通过像素检查并打开目检，页面／控制台错误为空；生产验收覆盖六武器、三外观、实际命中、首领趁重击后摇反击，以及模拟触控／手柄输入。前版地下升降流程与 12 件装备的独立 SVG 插图、空护符槽占位图均保留。

发布沿用用户将新内容提交至 `master` 的授权；只纳入本轮雨夜源码、规则、验收脚本与文档，保留主工作区其他游戏的修改。Git 推送与 Vercel production 状态分别确认，后者通过 API 核对提交 SHA、`READY` 与 `suiji.site` 别名。

这是原创低模关节程序动画，没有引入真人动捕或大型动作资产库。触控／手柄验收使用 Chrome 的设备边界模拟，尚不代表实体手机 GPU、Safari 或所有实体手柄驱动的表现。
