# 自走棋极简素材规范

极简素材首先服务于战场 48–64px 小图识别。生成时必须引用已有极简素材，不能仅在精细立绘 prompt 前添加「极简」「Q 版」；不得把细节版当画风参考。

## 画风参考与优先级

- 主要画风参考：`public/images/autochess/portraits/minimal/sui.png`、`grove_mender.png`。大头、短小身体、粗深色轮廓、大块纯色，优先于服装还原。
- 人物原头像／旧立绘只供身份辨识，必须明确要求删减细节。旧版 komichi 并非最简档，不宜单独作为极简基准。
- 头部约占总高 65%，完整全身，三分之四朝右，手为团块、脚为短靴状，轮廓紧凑。
- 最多六个主要色系（不计肤色与轮廓）；头发只用 3–5 个大色块，内部最多三条分隔线。
- 每眼至多一个白色高光点；无渐变，每个大色块最多一块平涂阴影。
- 先逐张查看原版立绘，列出真实发型、衣装轮廓、主色与标志饰品。不能凭旧 Q 版推断原设；枝堇原版是侧盘发配长直侧发，不能再误画成普通长侧辫。
- 身份标记按角色需要保留，识别点宁大勿碎；不要机械限制两三个标记，以致失去人物特色。可把标志性披肩、花饰、藤蔓概括为大形状，与一个紧凑道具共存。
- 禁止细密蕾丝网格、刺绣纹理、细发丝、细褶皱、复杂瞳孔、材质高光、细小扣带、过多垂挂饰品与漂浮粒子。原设关键蕾丝披肩可以保留为整块白色披肩加少量大扇贝边，花纹可保留为单个大花／藤蔓符号；不能把「删细节」变成删掉整件标志衣装。
- 真正透明 alpha 背景，无地面、投影、文字与场景；512×512，最长可见边 464px，边缘至少 24px。

## 本轮完整 prompt

使用内置 imagegen；每人独立生成。小松绿、羽啾的完整英文 prompt 及参考图顺序保存于 [autochess-minimal-prompts.json](autochess-minimal-prompts.json)。枝堇首版被用户指出过度简化、失去特色，现改用 [枝堇第二版完整 prompt](autochess-sumire-minimal-v2.json)，以原版立绘作为身份及服装依据。旧 JSON 中枝堇 prompt 仅作为历史记录，不再复用。参数 `transparent_background: true`。

参考图顺序固定为：岁己极简（画风）、七海极简（画风）、对应人物旧极简（仅身份）。后续使用本轮新图作为身份参考时应同步更新记录，不能误称仍使用旧图。

## 验收

1. 同时查看新图、已有画风参考以及 48／64／96px 实际尺寸缩略图，不能只看大图。
2. 小图必须能分清脸、发型、主色和道具；不能依赖蕾丝、花纹与高光区分角色。不清晰就进一步删减后重生。
   同时对照原版确认身份未被简化掉；如果只剩「紫发＋书」等泛用组合，应恢复标志性发型、披肩、花饰及植物轮廓，而不是继续删减。
3. 保留生成 alpha，仅允许裁透明边距、等比缩放、居中；不要用程序重绘人物或用去底代替真实透明生成。
4. `minimal/<id>.png` 与默认 `portraits/<id>.png` 同步；细节版不随极简替换。
5. 用仓库 `verify-autochess.cjs` 的安装版静音 Chrome 路径核验商店、图鉴和战场；检查截图非黑图，结合文本状态、DOM、画布尺寸与页面错误，并打开截图目检。

## 旧版问题

2026-10-13 的三人 prompt 同时要求「极简」与人物细碎饰品、克制赛璐璐阴影，并只用相对精细的 komichi 作为参考，未对内部线条、色块、道具复杂度和缩略图作硬性限制。2026-10-17 重生改用 sui／grove_mender 为主要画风参考，并显式删除上述细节。以后不能直接沿用旧文档的「生成提示词组」生成极简档。
