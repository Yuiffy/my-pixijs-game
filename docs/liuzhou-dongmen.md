# 东门城楼：位置、登台与存档

2026-10-23。原模型位于原点以北约65米；本轮移到导入的 OSM historic site 205661090 范围附近，中心约为局部坐标 (-2.8,-2.2)。这个位置没有经过现场测绘。

资料沿用广西新闻网城楼照片，参考青灰台基、红木窗棂、双层重檐和翘角。柳州市政协《城中文史》第十四辑、刘文《东门城楼的建筑艺术、古城与民俗》的索引摘录记载五开间、通面阔16.44米、进深10.41米，模型采用这些比例。原PDF地址：`https://lzzx.liuzhou.gov.cn/liuzhouwenshi/wenshi_xianqu/201611/P020161120354469054024.pdf`。本次取得的是搜索索引摘录，PDF全文下载失败；没有将其当作完整建筑图纸。照片仅留作本地参考，未随游戏发布。

台基28×18.4米、平台高6.2米、3.4米宽拱洞、西侧31级台阶以及栏杆、柱子与檐口细节是玩法近似。城楼目前是程序化简化模型，不能称作测绘复原。实际台阶位置、内部结构、装饰和周边立面仍需核实。

## 可操作部分

可以从地面完整穿过拱洞，沿西侧实际台阶登上平台，从栏杆缺口进入回廊，观察柳江和文惠双桥，再沿原路下楼。平台可以跳跃、暂停、收录地标和刷新续玩。城楼正殿仍封闭。

`dongmen.ts`集中定义台基、拱券、台阶、栏杆、檐口和柱子的实体；Rapier、镜头净空和地面测试导航共用这些几何，显示模型位于`DongmenView.tsx`。步行自动跨阶高度0.26米，车辆关闭自动跨阶。互动检查高度差，避免在台上隔着地板与楼下NPC交谈。

读取存档只恢复有支撑的平台或台阶高度，拒绝任意悬空高度。旧档因模型搬移而落在实体墙内时，保留进度并移动到东侧开阔地；车辆也检查新墙体。镜头可抬头，俯仰范围从原先只能俯视扩展到 -0.65..0.95，贴墙检查包含城楼实体并防止向上观察时镜头穿地下。

## 验证

`scripts/tests/liuzhou-dongmen.test.mjs`覆盖完整拱洞净空、实体墙、相机、台阶、平台入口、旧档避让、支持面恢复及不同高度的互动。与既有柳州规则合计41项通过。

`LIUZHOU_DONGMEN_ONLY=1 node scripts/verify-liuzhou.cjs`使用正常移动输入穿洞、登31级Rapier台阶、跳跃、暂停、刷新和下楼；将实际获得的存档用于手机视口，验证抬头拖动、真实触摸按钮移动和横竖屏地图。不会改写角色坐标完成登台。

所有柳州测试上下文通过`liuzhou-test-browser.cjs`创建，在页面加载前模拟 Pointer Lock，禁用测试语音。安装版Chrome以静音无头模式运行，输入只发送到浏览器文档，正常玩家的原生鼠标锁定保留。虚拟锁定验证生命周期，不冒充系统原生捕获实测。截图用全页PNG，检查像素sanity、DOM、画布、文字状态和错误，采用的截图逐张打开目检。

构建门禁完整`pnpm run check`后顺序`pnpm run build`通过，目录`.next-liuzhou-dongmen-build`，日志`tmp/liuzhou/dongmen-{check,build}-final.log`。保留Next构建ESLint；只有既有其他游戏的unused警告。

最终浏览器报告和具体截图数量在`progress.md`本轮条目记录。自动路线不证明真人趣味、原生鼠标手感或真机性能。
