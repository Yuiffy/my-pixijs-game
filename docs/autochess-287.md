## 羁绊与反制

287 的 2/4 档开战分别提供成员 10/20 能量；成员施法向另一名存活成员传递 8/14 能量，优先最低能量比例，溢出截到上限，不返还给自己。四人额外获得 12 护甲。计数按出场的不同单位 ID 去重，己方／敌方各自计算，阵亡不撤销已激活档位，但阵亡成员不能接力。

小松绿需要队友停在圈内；治疗比例为目标最大生命，落地治疗为施法者攻击 + 最大生命的 6%，持续圈即便施法者倒下仍按已种下的植物完成寿命。只有周期治疗的溢出转盾，上限是目标总普通护盾池的 18%，不会削减已经更大的其他护盾。

枝堇伤害为 2.3/3/4 倍攻击，扣能量 20/25/30，圈寿命 3/3.5/4 秒、减速 55%；离开圈后残留减速只有短刷新窗口。已出手的弹道／引导不会被“屏蔽”取消；这个梗对应扣能量，不是沉默。

羽啾三张各 1.2/1.6/2.1 倍攻击，间隔 0.4 秒、速度 520，末张击退 24/30/38、眩晕 0.45/0.6/0.8 秒；可以被走位躲开。目标死亡才重选，仍受 460 技能距离限制；羽啾倒下则未发出的卡片取消。不同卡有电波／外星人／猫的标记。

新成员直接使用仓库已有公开头像，不额外生成或借用其他角色图。三种画风均解析到本人头像。新羁绊未训练进现有 Go 权重：按特征名投影旧维度，防止新增羁绊挤歪施法类型；新角色使用未知 ID 嵌入与当前属性，实际托管战斗模拟执行全部新规则。不能声称已针对 287 重新训练。
