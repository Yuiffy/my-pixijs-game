# 主播，别嚼了！操作方式

`/game/snack` 的五关玩法、零食噪声与评分保持原有规则。默认「按住操作」，可在零食操作区选择「点按保持」。

- 默认空格说话、K 静音，松开即停止；J 或「吃一口」每次只拿一份，之后自动嚼完。
- 点按保持时，说话/静音按钮或对应快捷键按一次开启，再按一次关闭。两者可以同时开启，但静音时观众听不到说话。按钮显示「已开启」。吃一口仍不会连吃。
- Tab 聚焦任意操作按钮后，空格和 Enter 操作该按钮。它们不会串到说话快捷键；普通按钮与链接保留原生键盘激活。按住模式下，Tab 移出按钮会松开该按钮的键盘操作。
- 不同手指、实体快捷键和聚焦按钮独立持有操作，释放其中一个不影响仍按住的另一个。系统取消触摸会释放对应手指。
- 暂停、失焦、进入后台、切换操作模式和关卡结束会清空按住及保持状态；继续后主动开启。偏好保存在本机，刷新后不会恢复正在说话/静音。存储不可用时本局仍可切换模式。

## 验证

`pnpm snack:controls:test` 包含输入来源组合、重复按键、暂停/模式清理、每按一份，以及原有三款小游戏的规则与存档测试。

`pnpm snack:controls:verify` 使用安装版 Chrome、静音并禁用语音，接受 `MINI_BASE_URL`、`MINI_QA_DIR` 和 `PLAYWRIGHT_MODULE`。覆盖聚焦键盘、五关点按通关和纪录刷新、真实 CDP 多点触摸/取消、键盘与触摸混合、320/390px 与横屏、存储受限，以及共用 MiniGame 的 AGI/Fab 操作。失焦使用注入浏览器事件验证。
