# 晴海双打 · 岁己 × 栞栞

Original prompt: 制作岁己和栞栞在美丽的沙滩上玩沙滩排球的游戏，玩法类似皮卡丘排球小游戏。但是画面要精美，角色最好能像死或生一样逼真性感，不行的话也可以像素风，再不行也可以 poly Q 版。允许生图制作背景和素材，允许用本地 Dreamina CLI 的便宜视频模型制作必杀、胜败与过场动画，允许用变声器制作台词。

## 视觉与交互

视觉主张：以金色沙滩、通透海水与精细的 3D 风格运动角色，呈现轻盈明亮的海岛排球假日。

内容顺序：满屏海滩与标题 → 选择角色和模式 → 可跳过的五秒开场 → 开赛 → 胜负演出与再来一局。菜单只承担选择任务，比赛期间以球场为中心。

动作表现：海水微动和角色呼吸建立空间；起跳、扑救、脚下沙尘反馈运动；必杀定格、全屏特写、粒子和球路拖尾强调击球。胜者欢呼、跳动与落彩，败者垂肩并轻微呼吸摆动。

## 实现约定

- 路由 `/game/beach-volley`，游戏大厅提供入口。
- Canvas 2D 呈现高分辨率生成背景和透明动作图集；属于 2.5D 表现，角色采用精细 3D 风格图像，并非实时 3D 骨骼模型。
- 独立 120 Hz 固定步长物理引擎：横向移动、重力与跳跃、自动接球、定向扣杀、轻吊、扑救与冷却、网碰撞、落地计分。
- 单人对 AI、同机双人、练习；可选岁己或栞栞；三档 AI；7 / 11 分，领先 2 分且加赛最多 4 分。
- 岁己「晴空流星」为高速球，栞栞「潮汐回旋」先飘移再下坠；满能量后发动，触球时扣除能量并进入双方共用的定格演出。
- 开场、得分和必杀演出可跳过；结果页包含胜败动画、统计、重赛和返回菜单。
- 键盘、触屏横屏适配，暂停、重新开始、静音、全屏；隐藏页面自动暂停。
- `render_game_to_text` 与 `advanceTime` 提供真实状态与固定步长验证。
- 用静音 Chrome 验证流程、物理和截图；检查图片非空并人工打开。

## 操作

| 动作 | 1P / 单人 | 同机 2P |
| --- | --- | --- |
| 移动 | A / D；单人也可用方向键 | ← / → |
| 跳跃 | W / 空格 | ↑ |
| 发球 / 击球 | J | 小键盘 1 或 / |
| 扑救 | K | 小键盘 2 或 . |
| 必杀 | L | 小键盘 3 或 , |

自动接球不需要按键；空中击球可扣杀，向前击球打远球，向后击球打轻吊。满能量按必杀后需在一秒内触球。P / Esc 暂停，F 全屏，Enter 跳过场内演出。触屏提供屏幕按钮，横屏视野更完整。

## 2026-10-03 操作修复

每个实体按键和触点独立持有操作。单人同时按 D / →、同机 2P 同时按小键盘 1 / 斜杠时，松开一个不会释放另一个；键鼠/触摸混用遵循相同规则。触屏按钮聚焦后支持 Enter / 空格按住，移走焦点取消该按钮键盘操作。普通按钮保留 Enter / 空格原生激活，修复键盘无法恢复比赛的问题。

暂停、失焦、重新开局清空操作；恢复后必须重新按下，长按键自动重复不会复活动作。开场视频与说明窗口阻止背后比赛推进，视频自然结束时也尊重仍打开的说明。2P 触屏补齐扑救，并在窄屏收缩按钮宽度。
