# 晴海双打 · 岁己 × 栞栞 × 米汀

Original prompt: 制作岁己和栞栞在美丽的沙滩上玩沙滩排球的游戏，玩法类似皮卡丘排球小游戏。但是画面要精美，角色最好能像死或生一样逼真性感，不行的话也可以像素风，再不行也可以 poly Q 版。允许生图制作背景和素材，允许用本地 Dreamina CLI 的便宜视频模型制作必杀、胜败与过场动画，允许用变声器制作台词。

## 视觉与交互

视觉主张：以金色沙滩、通透海水与精细的 3D 风格运动角色，呈现轻盈明亮的海岛排球假日。

内容顺序：满屏海滩与标题 → 选择角色、对手和模式 → 可跳过的出场 → 开赛 → 小分与最终胜败演出 → 再来一局。菜单只承担选择任务，比赛期间以球场为中心。

动作表现：海水微动和角色呼吸建立空间；起跳、扑救、脚下沙尘反馈运动；必杀定格、全屏特写、粒子和球路拖尾强调击球。胜者欢呼、跳动与落彩，败者垂肩并轻微呼吸摆动。

## 实现约定

- 路由 `/game/beach-volley`，游戏大厅提供入口。
- Canvas 2D 呈现高分辨率生成背景和透明动作图集；属于 2.5D 表现，角色采用精细 3D 风格图像，并非实时 3D 骨骼模型。
- 独立 120 Hz 固定步长物理引擎：横向移动、重力与跳跃、自动接球、定向扣杀、轻吊、扑救与冷却、网碰撞、落地计分。
- 单人对 AI、同机双人、练习；岁己、栞栞、米汀自由搭配对阵，也支持同角色镜像；三档 AI；7 / 11 分，领先 2 分且加赛最多 4 分。
- 岁己「晴空流星」为高速球，栞栞「潮汐回旋」先飘移再下坠，米汀「星屑折光」为中高速、过网后加速下坠的球路；满能量后发动，触球时扣除能量并进入特写。
- 开场、得分与结算演出可跳过；必杀完整播放后有 0.8 秒场内蓄力，防守方可操作。结果页包含胜败动画、统计、重赛和返回菜单。
- 键盘、触屏横屏适配，暂停、重新开始、静音、全屏；隐藏页面自动暂停。
- `render_game_to_text` 与 `advanceTime` 提供真实状态与固定步长验证。
- 用静音 Chrome 验证流程、物理和截图；检查图片非空并人工打开。

## 操作

| 动作 | 1P / 单人 | 同机 2P |
| --- | --- | --- |
| 移动 | A / D；单人也可用方向键 | ← / → |
| 跳跃 | W / 空格 | ↑ |
| 高吊瞄准 | I；W / 空格起跳也选高吊 | 小键盘 8；↑ 起跳也选高吊 |
| 下压瞄准 | S；单人也可用 ↓ / 小键盘 5 | ↓ / 小键盘 5 |
| 发球 / 击球 | J | 小键盘 1 或 / |
| 扑救 | K | 小键盘 2 或 . |
| 必杀 | L | 小键盘 3 或 , |

自动接球不需要按键，保留易接球的中性回球。手动击球组合高吊 / 平抽 / 下压与近网 / 中场 / 底线，共九种瞄准；向前击球打底线，向后打近网，不按或同时按左右选中场。下压优先于高吊，普通挥拍缓冲 0.27 秒，必杀需在一秒内触球，按下时锁定方向，随后松开方向也不改变这次球路。2P 的前后方向镜像，发球同样支持瞄准；发球和普通触球时显示实际球路预览。P / Esc 暂停，F 全屏，开场和胜败视频中 Enter / Esc 或跳过按钮跳过整个当前序列。必杀视频不可跳过，Esc / P 只暂停；放完后进入 0.8 秒蓄力和挥击，防守方可移动、跳跃、扑救，蓄力结束才出球。触屏可同时按方向、瞄准与击球，横屏视野更完整。
