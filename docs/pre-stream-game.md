# 岁己：马上就播 · v0.1

2026-09-12：首个可玩版本收尾。按用户要求在此保留版本，后续开发从当前已验证的三晚闯关继续。

Original prompt: 开发新游戏，扮演岁己在开播到正式上播之间进行努力。最终完成时获得开播所花时间（如五分钟01秒）。过程是多个小游戏组合：接水喝、上厕所、准备吃的、打开 VTS / OBS / 声卡、给猫倒猫粮，还会发生各种意外。形式可以是按时长评一至三星的闯关或肉鸽。

## 设计

选择三晚闯关。每晚从放出“马上就播”待机画面开始计时，在温暖的房间里自由安排七项准备，全部完成后手动正式上播，三秒倒计时结束停表。每项准备和整晚分别按耗时评一至三星；第三晚结束显示三晚完成成绩。没有硬性失败倒计时，操作失误损失进度，仍可继续完成。

视觉：奶油色与浅紫的插画房间，岁己与猫是主体，家具是交互入口。画面上方只放标题、时间和暂停，下面只展示当前动作或准备清单。

内容：标题与选晚 → 房间选准备事项 → 动作特写 → 突发小插曲 → 正式上播 → 用时和星级结算。交互以水流、准星、猫咪摆尾、角色动作和完成反馈构成，不依赖远程美术生成服务。

## 操作

- 接水喝水：按住接水，在绿色水位内松开，再按住喝水。
- 洗手间：按方向顺序关门，按住安心解决，完成后洗手返回。
- 准备吃的：光标进入绿色区域时按下，装好三份点心。
- 喂猫：左右移动对准猫碗，按住倒粮。
- 声卡：左右调节旋钮到绿色范围，按住试音。
- VTS：跟住脸部标记，按住校准。
- OBS：依次打开来源，再确认画面。

鼠标、触屏按钮与键盘方向键 / 空格均可操作；F 全屏，P / Esc 暂停。失焦与进入后台会暂停并清除按键。局内保存包含已经完成的准备与当前动作；刷新后暂停续玩。各晚最好用时与星级单独保存，存储不可用也可正常游玩。

喂猫、VTS、声卡和逗猫也支持按住画面直接左右拖动，鼠标或单指就能完成瞄准与操作，不需要同时按键。

## 2026-09-26 · 3D 公寓版

当前 `/game/pre-stream` 已切换到 3D 公寓。上面的 v0.1 设计与验收记录保留为首版历史；新版本使用独立的 `gameplay3d.ts` 规则、`World3D.tsx` 场景和 `PreStream3D.tsx` 界面，存档与纪录采用 v2 键，不把旧版动作状态误当成 3D 存档。

### 空间与流程

- 公寓分为客厅、卧室和洗手间。饮水机与点心台在客厅，保温杯、猫碗、声卡、VTS 和 OBS 在卧室。角色在房间里实际跑动，走近物品才能交互；点击远处站点会自动经过卧室门洞或洗手间门口，不能穿墙直达。猫沿路线穿过两间房，在狭窄门口会短暂挡住角色，之后仍可继续通行。
- 七项准备可自由安排。完成所有事项及意外后仍须回到卧室电脑旁，进入开播交互范围并按 E 或点击电脑，才会开始两秒开播画面转场；界面不提供远程开播按钮。
- 水从桌上保温杯开始：拿杯 → 放在饮水机接水 → 水满后返回取杯 → 回桌边喝下。接水依夜晚耗时 19 / 21.5 / 24 秒，角色离开饮水机、移动或做其他小游戏时继续接；暂停和后台停表时停止。水满后不自动算完成。
- 厕所保留移动准星、按住发射和水花效果；命中移动靶心后必须按下冲水按钮，等 1.8 秒冲水动画结束才完成。点心按餐盘提示配对摆盘；猫粮按住定量倒勺、松手检验份量；声卡分别调三路音量并试音；VTS 按提示捕捉表情；OBS 开关画面来源并确认预览。
- 意外从七种事件中按种子抽取，每晚分别出现 1 / 2 / 3 项：嘉嘉碰洒水、扯松线缆、占键盘、踩到关机键、打碎杯子、留下猫砂，以及岁己自己突然想上大的。对应操作分别是擦水、线缆配对并试音、节奏逗猫、重启电脑后重新配置 VTS 与 OBS、扫四片玻璃、铲三处猫砂结块、在 5×5 肠道格子里挖通水路再放水。嘉嘉的足迹与事故现场会在公寓中显示。
- 每完成约 2 / 4 / 6 项准备会尝试触发下一场意外；关机事件要等 VTS 与 OBS 已完成才触发。意外需要跑到现场处理，未触发的意外站点不接受交互。所有事项与意外解决后才可在 OBS 桌旁进入开播转场。

### 操作与计时

WASD / 方向键移动，E / 空格交互；可点击场景物品、上方未完成目标或站点列表自动走过去。密集地点可在场景上滚轮或按 Q 循环选中附近目标，手机用任务按钮与地点列表直接点选、摇杆移动。小游戏按场景使用点击、拖动、滑杆或按住操作；厕所仍可用方向键调整准星、空格发射。P 暂停；Esc 优先取消自动行走或退出小游戏，否则暂停；F 全屏。失焦、切后台与离开页面会清空输入并暂停。刷新恢复的进行中存档以暂停状态等待玩家继续。

整晚计时包含跑动、小游戏、饮水机等待和最后两秒转场，不叠加虚构罚秒；暂停与后台冻结。新版本门槛如下，超过两星门槛仍能以一星完成：

| 夜晚 | 意外次数 | 三星用时 | 两星用时 |
| --- | --- | --- | --- |
| 不慌不忙 | 1 | ≤1分钟50秒 | ≤2分钟50秒 |
| 猫猫加班 | 2 | ≤2分钟15秒 | ≤3分钟20秒 |
| 今晚一定准时 | 3 | ≤2分钟45秒 | ≤4分钟00秒 |

### WASD 移动流畅度

规则位置本来随动画帧更新，但界面约每 45 毫秒才向 React 发布一次状态；角色根节点的声明式 `position` 又在重绘时覆盖帧内位置，造成约 20 次/秒的可见跳动。现在角色和相机每帧从实时规则状态读取位置，角色位置与朝向平滑追随；初次加载或恢复存档时直接对齐，避免从旧位置滑过去。移动速度、碰撞和计时规则未改。
