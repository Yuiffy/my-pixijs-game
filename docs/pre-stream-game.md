# 岁己：马上就播 · v0.1

2026-09-12：首个可玩版本收尾。按用户要求在此保留版本，后续开发从当前已验证的三晚闯关继续。

Original prompt: 开发新游戏，扮演岁己在开播到正式上播之间进行努力。最终完成时获得开播所花时间（如五分钟01秒）。过程是多个小游戏组合：接水喝、上厕所、准备吃的、打开 VTS / OBS / 声卡、给猫倒猫粮，还会发生各种意外。形式可以是按时长评一至三星的闯关或肉鸽。

## 设计

选择三晚闯关。每晚从放出“马上就播”待机画面开始计时，在温暖的房间里自由安排七项准备，全部完成后手动正式上播，三秒倒计时结束停表。每项准备和整晚分别按耗时评一至三星；第三晚结束显示三晚完成成绩。没有硬性失败倒计时，操作失误损失进度，仍可继续完成。

视觉：奶油色与浅紫的插画房间，岁己与猫是主体，家具是交互入口。画面上方只放标题、时间和暂停，下面只展示当前动作或准备清单。

内容：标题与选晚 → 房间选准备事项 → 动作特写 → 突发小插曲 → 正式上播 → 用时和星级结算。交互以水流、准星、猫咪摆尾、角色动作和完成反馈构成，不依赖远程美术生成服务。

## 操作

- 接水喝水：按住接水，在绿色水位内松开，再按住喝水。
- 洗手间：按方向顺序关门，按住安心解决，完成后洗手返回。
- 准备吃的：光标进入绿色区域时按下，装好三份点心。
- 喂猫：左右移动对准猫碗，按住倒粮。
- 声卡：左右调节旋钮到绿色范围，按住试音。
- VTS：跟住脸部标记，按住校准。
- OBS：依次打开来源，再确认画面。

鼠标、触屏按钮与键盘方向键 / 空格均可操作；F 全屏，P / Esc 暂停。失焦与进入后台会暂停并清除按键。局内保存包含已经完成的准备与当前动作；刷新后暂停续玩。各晚最好用时与星级单独保存，存储不可用也可正常游玩。

喂猫、VTS、声卡和逗猫也支持按住画面直接左右拖动，鼠标或单指就能完成瞄准与操作，不需要同时按键。

## 验收

入口为 `/game/pre-stream`，实验室 `/demos` 增加紧凑游戏入口。实现分为 `engine.ts` 确定性规则、`scene.ts` 原创 Canvas 2D 场景、`PreStreamGame.tsx` 输入/存档/界面，以及独立的 CSS Module；与其他游戏不共享存档键。

| 不慌不忙 | 1 | ≤1分钟15秒 | ≤2分钟00秒 |
