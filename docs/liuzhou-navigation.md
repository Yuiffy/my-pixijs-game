# 柳州街区导航

2026-10-23。此前地图仅画玩家到目标的直线，南岸任务指引会穿过柳江。本轮增加实际场景内可行走的导航线、小地图剩余路程、偏离后的重算，以及地图上的五个地标入口。选择“跟随任务”恢复任务导航，任务模式优先指向正在进行的送餐，再指向第一章或第二章的下一目标。地标选择是临时状态，不覆盖章节存档；“柳江北岸”指向岸上净空点，不把河道中心当作可达地点。

`navigation.ts` 在三米网格上做 A*，使用当前 OSM 道路骨架作为路径成本偏好，绕开建筑轮廓、城楼地面实体及街边家具。步行和骑行半径 0.65 米，汽车 1.55 米；对相邻格之间也采样检查，防止从细柜台、靠背或角落穿过。终点如果稍微落入实体，可停在四米交互范围内的净空处。台上不显示地面路线，提示先沿石阶返回街面。路线进度裁去已走部分，离开原路线六米或被静态实体隔开后重新计算。

`navigation.worker.ts` 负责寻路，避免在输入/渲染线程上同步执行首次几百毫秒的跨江计算。步行、骑行、汽车各自缓存网格。请求带版本号，快速切换目的地、到达、取消或改换交通方式时，迟到的结果会被丢弃。地图与 `render_game_to_text().navigation` 使用同一结果；工作线程尚在计算时显示规划中，不画直线假装可达。

UI 在原有小地图下显示路线距离及目的地，地图面板可选择东门城楼、文惠桥、柳江北岸、曙光东路和金沙角。手机保留目的地名称；横屏把导航文字放到小地图旁，缩小任务标题间距以免重叠。

这是游戏场景导航，不代表柳州当前道路通行权限、单行线或交通法规。它只考虑静态几何；车辆、路人、停车及动态拥堵需要玩家现场绕行，也不提供自动驾驶、转弯语音或真实道路导航。路线可走过空地，汽车路径尚未按转弯半径作曲线优化。不同楼层的室内/阶梯导航尚未实现。真实地图与建筑还存在此前文档记录的近似，不能把可玩场景当作完整城市复刻。
