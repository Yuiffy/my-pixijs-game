# 三款新游戏

用户目标：AI 厂商训练、营销、发布、蒸馏、自我提升，与对手竞速 AGI，并因治理方式得到不同结局；晶圆厂在降价与 AI 涨价周期决定报价、库存和扩产，最终比较财富；虚拟主播在保持说话的同时完成不同零食组合，避免被发现。

实现：独立 `/game/agi`、`/game/fab`、`/game/snack`，共用轻量 React / Canvas 2D 展示与本机存档基础。两个经营游戏为确定性回合制，偷吃为固定步长实时游戏。无需账户或真实 AI 服务。

视觉方向：奶油纸色的经营桌面配墨绿色重点，以会随经营变化的等距实验室/工厂作为视觉中心；直播间可选暖粉原创主播或淡紫岁己 SUI 皮肤。结构为顶栏、关键资源、主场景、行动区、对手/战报，结束后显示本局结果与重玩入口。交互通过机器运行、工厂建设和角色表情表现结果，按钮按下反馈与数值条过渡帮助理解操作；尊重减少动画设置。

验收要求：
- AI：三种公司特长、有限季度行动、六项核心研发/经营动作、发布产品持续收益、会成长与发布的竞争者、率先 AGI 和多个可到达结局、破产/落后失败。
- 晶圆：完整 24 季周期、报价弹性与有限需求、生产/库存/仓储成本、建设延迟、研发良率、借款利息、竞争者与最终清算排名。
- 偷吃：五关各异零食、说话/吃/静音键盘与触摸控制、噪声与掩护时机、冷场与怀疑双失败条件、计时、暂停/失焦、重试/续关与评分。
- 三者：新手规则、即时可用性原因、可刷新存档、同种子重玩、响应式布局、小游戏列表入口、文本状态与时间推进接口。
- 验证：引擎完整局测试、真实浏览器操作与桌面/手机截图目检、目标 ESLint、全仓 check 后顺序 build。

当前状态：三个完整可玩版本均已实现并通过验收（2026-09-11）。

## 入口与操作

- 智能纪元：`/game/agi`。选择三种公司特长，以每季 3 个不重复行动进行训练、算力扩建、蒸馏、营销、发布、融资、对齐和递归研究。开放政策、社区、安全与融资次数决定四种 AGI 结局。经营记录与竞速排名用于复盘。
- 晶圆周期：`/game/fab`。选择存储、HBM 或灵活代工路线，经历两轮寒冬 → 复苏 → AI 爆发 → 过剩。产量、报价和库存策略与有限需求竞争，制程与延迟投产改变成本。停机公司的清算资金在退出时冻结，避免继续享受后续行情。
- 主播，别嚼了！：`/game/snack`。按住空格说话、按一下 J 吃一份、按住 K 静音、1–4 选零食、P/Esc 暂停、F 全屏。入口后松手自动嚼完，长按不会连拿，嚼时点击也不排队下一份；手机轻点「吃一口」即可。嘴里有食物时仍可含糊接话，以较低效率恢复气氛，代价是嚼得更慢、增加怀疑。五关共四种零食，记录每关最高分；刷新从暂停点恢复原来的一口。

音乐掩护期间咀嚼噪声降至 12%；场景上方整条提示变为深色，显示剩余秒数、节拍和进度条，画面同时亮起边框与音符，最后 1 秒变成赭色预警。未掩护时显示下一段倒计时；暂停冻结计时。静音依然完全阻止咀嚼噪声，但无法说话且气氛下降更快。

三个入口已加入 `/demos`。存档分别使用 `mini-agi-v1`、`mini-fab-v1`、`mini-snack-v1`，不会互相覆盖。无法使用本地存储时仍可玩当前局。角色与主场景采用 Canvas 2D 绘制，列表封面来自对应场景，无额外字体或图片生成服务依赖。

偷吃游戏在开播前、暂停和结算时可通过画面下方的「主播皮肤」选择原创主播或岁己 SUI，立即预览。岁己版参照站内小猫帽立绘绘制，保留说话、咀嚼、眨眼和吃零食动作。选择单独保存在 `mini-snack-skin-v1`，刷新、重试、下一关和重开均保留，不影响关卡进度或评分；无偏好或偏好损坏时使用原创主播。

## 本地运行与复验

`pnpm dev --port 3845`，打开上述三个入口。需要隔离构建目录时，在 PowerShell 中先设置 `$env:NEXT_DIST_DIR = '.next-mini-games-dev'`。

- `pnpm run mini:test`：纯引擎与存档回归。
- `pnpm run mini:simulate`：比较三种报价策略在多公司、多种子下的六年结果。
- `pnpm run mini:verify`：系统 Chrome 完整浏览器验收。默认地址 `http://127.0.0.1:3845`，可通过 `MINI_BASE_URL` 指定；需要可解析的 `playwright`，也可以用 `PLAYWRIGHT_MODULE` 指向现有安装。本机使用 `C:/Users/yuiffy/.codex/skills/develop-web-game/node_modules/playwright`。
- `node scripts/verify-snack-skins.cjs`：系统 Chrome 皮肤专项，验证画面、切换、刷新、进度保留与手机操作，沿用上述服务和 Playwright 配置。
- `node scripts/verify-snack-controls.cjs`：系统 Chrome 操控专项，验证单口输入、自动咀嚼、含糊接话、音乐窗口、键盘与触屏操作及暂停续局。
- 顺序执行 `pnpm run check`、`pnpm run build`。不要并行运行 TypeScript 和 Next 构建。

三个游戏通过 `/demos#games` 的紧凑快捷入口进入，桌面一排三个，手机按行排列。竞争者由游戏规则驱动，存档保存在浏览器。发布沿用主分支连接的 Vercel 项目 `my-pixijs-game`，正式入口为 `https://my-pixijs-game.vercel.app/demos#games`。
