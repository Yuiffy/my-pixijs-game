## 验证

专项 `scripts/verify-night-rain-characters.cjs` 使用合法存档准备和公开菜单操作，依次核对 11 个首领／客人模型与三个旅人外观，拍摄游戏中的首领、重击／翻滚和 390px 图鉴。测试使用静音安装版 Chrome、虚拟指针锁定与 TTS stub，交叉核对公开状态、DOM、画布尺寸、截图像素与页面错误。前后图与原型图逐张目检。

```powershell
$env:NIGHT_RAIN_BASE_URL='http://127.0.0.1:3966'
$env:NIGHT_RAIN_QA_DIR='tmp/night-character-browser'
node scripts/verify-night-rain-characters.cjs
```

修改前 14 张、开发版 31 张与改进场景镜头后的 8 张截图均已逐张打开对比。图鉴原来会裁掉头顶与帽饰，现使用与场景一致的角色尺寸配置相机，完整显示头饰和双脚；瑞娅的霜环维持原蓝色，避免服装金边改变读招颜色。

基于 `6e4daa5` 的 137 项雨夜规则、修改源码 ESLint、完整 `pnpm run check` 后顺序 `pnpm run build` 均通过，保留 Next 构建 ESLint。生产包角色专项 31 张截图和地下／装备回归 24 张截图全部通过像素 sanity、状态／DOM／画布交叉检查并逐张打开目检；页面与控制台错误为空。地下测试覆盖双入口、发现字幕、连续下行／回升、途中读档、暂停和区域地图；装备菜单及锻造菜单覆盖 1440px／320px、12 件独立 SVG 装备图与空护符槽、更换双苇短刃和风苇披风。通用客户端静音冒烟 1 张亦已打开目检，轻击与蓄力后状态、敌人受伤和模型显示一致。
