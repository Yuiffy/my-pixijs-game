# 维阿弹棋

`/game/flick-chess` 使用 React Three Fiber 和 Rapier。双方各 16 枚棋子，以拖动方向与距离决定弹射角度、力度；停稳后换手，对方棋子全部出界即获胜。支持 AI 与本地双人，已有角色贴图、不同质量和出界回收动画。

## 暂停与对局保护（2026-10-03）

- 暂停按钮、P 或 Esc 暂停对局；继续按钮、P 或 Esc 恢复。棋子位置、速度、轮次和回收动画停在原处，AI 等待继续后才重新计时出手。
- 打开规则或重开确认时同样暂停。弹窗限制键盘焦点，关闭后回到原按钮。正在拖动的瞄准会取消并释放指针捕获，不会在继续或松手时补发弹射；系统取消触摸也取消瞄准。
- 页面失去焦点或进入后台后保持暂停，返回不会自动开始。若离开时打开了规则，关闭规则后仍需继续对局。
- 尚未结束且已弹射的对局，重开或切换模式须确认；“保留本局”或 Esc 返回原棋盘。初盘及结算后重开不再确认。
- 这些保护只覆盖当前打开的页面，不是存档；刷新或离开路由仍会重新开局。

## 验证

`pnpm flick:test` 覆盖真实物理、出界胜负/平局、AI 连续合法回合与重置。`pnpm flick:verify` 覆盖鼠标/真实触摸拖动、AI/本地换手与重开。`pnpm flick:session:verify` 验证暂停中物理与 AI 不前进、恢复只出手一次、重开取消不改棋盘、失焦/可见性事件处理、拖动取消、回收动画暂停/恢复，以及 320/390px 和横屏布局。生命周期分支以注入浏览器事件验证，触摸使用 Chrome CDP 输入。

浏览器脚本使用安装版 Chrome、静音并禁用语音，支持 `FLICK_BASE_URL` 和 `FLICK_QA_DIR`。截图使用全页捕获，并与像素、画布尺寸、公开状态和页面错误交叉验证。每张用于验收的截图须打开目检。重开会重新创建 WebGL 场景，捕获前须等待首帧。
