# 2026-10-24：人行落点与桥梁分层导航

人物落点使用 `pedestrian-layout.ts` 的统一数据。米汀改到罗池路东侧，七海改到荣军路与东侧支路之间的地面会面区；五位居民分别沿文惠路东侧、曙光东路步行段、曙光东路北侧和滨江东路金沙角侧的人行空间往返。路径依据仓库中的 OSM 道路轴线和路幅确定，具体停留位置、居民日程及会面铺装属于游戏设计，不是实测商户入口。街区填充保留这些点及连续路线的公共通道。

`pedestrianClear` 同时检查机动车道、建筑、城楼和街边家具。移动避障和旧存档恢复均使用此规则，因此车流暂时为空也不能把车道当作闲站位置。恢复旧路线时还须位于新路线附近；不符合的新坐标回到正常出生点，章节及送餐存档不因此清空。市民移动和恢复后使用统一地形高度。

`navigation.ts` 的三米网格有地面、桥面两层。同一个平面坐标可以同时存在桥下道路与桥面节点；两层只在引桥与地面衔接处连接，不从投影相交处换层。低矮引桥下方不提供穿透通路，有足够净空的滨江东路下穿段仍可通行。路线点和工作线程请求携带高度，地图到达判定检查楼层，城台的限制不再误套用到桥上或普通高程较高的街道。

步行成本优先人行侧带和步行街，允许过街但避免长距离沿车行道行走。路线高度来自 DEM 地形或桥梁纵断面；接地点允许的小误差避免把地面插值误认成桥面。人物移动、场景碰撞和视觉最终仍由主模拟共享同一套高度。
