# 雨夜寻味 · 第二关「雾河回响」

2026-10-03。入口：`/game/night-rain`。第二关是连接[第一关「长夜归灯」](night-rain-first-chapter.md)的河谷箱庭，王寺和河谷位于同一个三维世界，可直接步行往返。保留角色、战斗、资源、敌人和存档，不进行换关重置。

## 进入与主线

完成第一关、敲响归夜钟后，选择继续探索，走到钟台东侧，按 E 推开王寺后山门。沿钟后崖廊、雾河望乡台和归猿下山阶到渡村。已完成第一关的旧存档可直接继续；地图里的雨灯行旅可以先回到已经点亮的王寺雨灯。

渡村的两岸可以任选顺序，两路在上游引水桥相连：

| 路线 | 区域与首领 | 推进动作 |
| --- | --- | --- |
| 西岸 | 萤火水栈 → 水上盐市 → 沉舟水车院；沉舟摆渡 · 缚流 | 击败缚流后，亲手转动西岸水闸；东侧渡埠可以修复系缆 |
| 东岸 | 竹影山口 → 青竹长阶 → 风铃竹关 → 无声寺百阶 → 无声山寺；无声住持 · 听澜 | 击败听澜后，亲手转动东岸水闸 |
| 河心 | 双流汇灯台 → 双闸锁桥 → 那伽沉殿；那伽守愿 · 千流 | 两闸开启后解除锁桥，击败千流，到殿后放出归水灯 |

击败守闸者不会自动转动水闸，需要靠近机关按 E。第二关结局后可以继续探索两岸、回旧城补支线。

新增 35 段可行走地面、21 名敌人（含三位首领），世界合计 103 段地面、55 名敌人。地面分段是碰撞与路网单元，不代表独立关卡数量。王寺入口高度 24 米，渡村 2 米，竹寺 18 米，汇灯台与沉殿 8 米。

## 回环与跨关往返

- 王寺后山门、崖廊和山阶始终可以双向步行，通关后已实际走回第一关钟台。
- 从竹关侧下行，开启采茶人归门，形成竹关与渡村之间的近路。
- 从汇灯台沿河心回阶南下，开启芦苇归径，形成上游与渡村之间的近路。
- 击败缚流后，在水车院东侧渡埠修好系缆，即可在渡村 ↔ 水车院、渡村 ↔ 第一关摆渡庵之间乘船。靠近对应渡牌按 E，战斗中不能乘船。
- 已点亮雨灯之间继续支持地图行旅，覆盖两关。需要站在安全的已点亮雨灯旁，目标雨灯也必须已经点亮。

渡船保留生命、体力、药瓶、敌人状态及原复活点，靠岸后立即存档；雨灯行旅保留资源与敌人状态，但把归灯设为目的地。补给需要另行与雨灯交互，休息才会恢复资源并重生普通敌人。

两条步行近路使用相同寻路器、人物半径和起终点进行对比，终点均为渡村雨灯，单位为米：

| 近路 | 关闭时 | 开启后 |
| --- | ---: | ---: |
| 采茶人归门 | 116.7 | 36.1 |
| 芦苇归径 | 286.1 | 37.1 |

加上第一关七条近路和渡船修复，HUD 近路总数为十。后山入口和最终锁桥属于推进门，不计入近路。所有已开门、已修系缆、已转水闸在休息、死亡与刷新后保留。

## 战斗、补给与指路

新增钩镰客、行脚僧以及三位两阶段首领。缚流使用船桨，听澜使用环杖，千流使用长兵器并带有五首那伽轮廓。首领都有突刺、延迟攻击和不可弹反的横扫；半血进入第二式。红色横扫需要跳跃、闪避或脱离范围。继续使用原有破架、处决、蓄力、空中攻击和喝药打断规则。

新增渡村、竹寺和汇流三盏雨灯，全世界共七盏。初次点火记录复活点，下一次交互免费休息。可选奖励包括旧盐仓银匣、无声寺经匣、灵露竹园的灵竹露（每瓶恢复 +30）和听瀑莲亭的露瓶（容量 +1）。收齐两关全部增强后，可带六瓶，每瓶恢复 110 生命；行装上限提高到十五级，到顶后不再扣钱。

地图新增「雾河渡村与双岸」「山寺与河心沉殿」视图，显示两闸和渡船状态。宝宝模式根据所在岸及完成进度引向活着的守闸者、对应机关、汇灯台和最终愿灯。没有完成第一关时，河谷目标不会提前加入引导列表。

## 实现与存档

`valley.ts` 统一新增地形、门、敌人、地标、建筑和渡船落点；碰撞、寻路、地图、渲染和存档验证共享这些数据。`ValleyView.tsx` 使用实例化植被和批量建筑装饰，补充水车、水闸指示、河面、渡船、竹林、崖壁及通关后河灯。原有战斗模拟仍在引擎中运行，React 负责场景和 DOM 界面。

世界版本升级为 `worldVersion: 6`，存档格式 `version: 1` 和 localStorage 键保持不变。v1–v5 依次迁移；真实 v5 通关存档已验证旧角色、资源、库存、灯和原有敌人逐项保持一致，仅补入新区敌人与字段。新进度使用 `valleyGates`、`valleyComplete`、`collected` 和持久首领记录。

加载器校验后山入口依赖第一关通关，水闸／系缆依赖各自首领，锁桥依赖两闸，最终首领依赖开桥，结局依赖千流和归水灯。拒绝缺少前置条件、重复或未知机关，以及互相矛盾的完成状态。仍为浏览器本机存档，不是账号云存档。

## 表现边界

汇灯台静止渲染采样：1440×900、RTX 5080、安装版无头 Chrome，最终补验 120 帧的 RAF 间隔中位数约 6.5ms、P95 约 7.0ms，每帧中位数 348 次绘制（含阴影）。此前同场景样本 P95 为 13.1ms，说明结果会随系统负载变化。采样冻结战斗，只用于观察这一场景的渲染负担，不代表整关性能或实体手机帧率。

当前采用程序化低多边形建筑、植被和原有角色动作框架。三位首领有不同战斗参数、节奏和外观部件，尚未制作独立骨骼动作或高精度角色素材。渡船以靠岸地点即时转移表现，没有完整航行过场；水闸推进体现在机关、指示和门禁，未模拟动态水位。后续可优先迭代河谷建筑细节、首领专属动作、渡船过场及实体手机／手柄体验。
