# 平陆运河存档恢复

2026-10-03，针对 `/game/pinglu-canal` 的真实地理沙盘。

## 问题与行为

旧版会把损坏的 JSON 自动覆盖为新地图；工程局名称等嵌套字段未校验，错误类型可以触发 React 页面崩溃。现在读取前校验工程局、地形、土方来源、施工记录、轮次和船闸归属。合法 v3 存档原样恢复，仍兼容缺少可选 `order` / `fillTarget` / `naturalWater` 的旧存档。此校验保证运行时结构可用，不重演历史交易，也不承担防作弊职责。

主档不可读取时暂停自动保存与施工，显示独立恢复窗口。玩家可下载原始文件，恢复上一份有效进度，或进入新工程设置；取消设置会回到恢复窗口，不会写盘。下载保留原文，不声称损坏文件可直接重新导入。

每次有变化的保存先备份上一份有效主档，随后写入当前状态。刷新时若内容未变，不轮换备份。确认替换不可读主档前，先把原始内容保存至独立槽位；备份或原文保留失败时不写主档。写入失败保留页面内进度，提示玩家保持页面打开并提供重试按钮。读写均受限时仍可在本页游玩。

| 本机键 | 内容 |
| --- | --- |
| `pinglu-geography-v3` | 当前工程 |
| `pinglu-geography-v3-backup` | 上一份有效主档 |
| `pinglu-geography-v3-unreadable` | 最近一次经玩家确认替换的不可读主档原文 |

备份只保留一份，按保存变化轮换，并非永久历史或跨设备备份。浏览器清除站点数据会一并删除这些槽位；多标签页仍沿用最后写入者的工程。本次没有改变施工规则、AI 或地理数据。
