# 岁岁过招：混合输入与键盘操作

2026-10-03，`/game/one-more`。

旧生产版同时按 D 和右方向键，松开右方向键后仍按着 D，角色却停止移动；战斗按钮聚焦后按 Enter 也不会行动。证据位于 `tmp/one-more-controls-baseline/`。

现在每个物理按键或触点独立持有操作，直到它松开或取消；同一动作只有第一个按下触发起手，只有最后一个释放取消按住。第二根手指不会延长弹反窗口，也不会重复花费闪避体力。取消触摸和丢失捕获只释放对应触点，键盘输入继续有效。暂停、后台、改键、重开和结算清空所有持有状态，按键重复事件不会重新启动已取消的动作。

五个战斗按钮支持 Tab 聚焦，Enter 或空格按住、松开释放，焦点离开会取消按钮的键盘操作。菜单按钮保留原生激活；即使把暂停绑定到 Enter，焦点在「继续过招」时 Enter 仍能继续。全局按键不会截获输入框、下拉框或按钮的操作，松键始终释放此前的动作。

320px 窄屏标题使用单行紧凑字号，避免换行后压住角色血量。

Phaser 继续绘制战斗，但关闭其未使用的键盘、鼠标和触摸监听；输入由原有页面控件负责。战斗规则、难度、伤害、体力、存档和挑战内容版本均保持原有语义。

`pnpm one-more:controls:test` 运行原 26 项战斗规则和 7 项输入回归。`pnpm one-more:controls:verify` 使用静音安装版 Chrome，`ONE_MORE_URL` 指向开发或生产服务根地址，`ONE_MORE_CONTROLS_OUTPUT` 指定证据目录。浏览器验收涵盖双键、键鼠、真实多点触摸与取消、焦点变化、改键、暂停、失焦、320/390px 与矮横屏；用公开输入自然完成三庭通关、键盘续关和重赛、刷新记录、失败后重试，并单独检查真实动画帧下移动与暂停。每张截图核对像素、画布、DOM 和公开状态，并逐张打开目检。

本轮开发证据：`tmp/one-more-controls-dev/`；生产证据：`tmp/one-more-controls-production/`。开发与生产全部九组验收通过，无页面或控制台错误；各 9 张截图及 `tmp/one-more-controls-shared/` 的通用客户端截图均逐张打开目检。33 项规则/输入测试、修改文件 ESLint、完整 `pnpm run check` 和随后顺序执行的 `pnpm run build` 通过。
