# 雨夜旧城 · 潮汐港

## 设计约束

保留同一个连续世界，旧城与潮汐港以摆渡庵东侧潮桥连接。中庭仍是唯一雨灯，新增归灯长桥从港内开绞盘后缩短重试路线。任何皮肤都使用相同数值、碰撞和战斗动作。

主线：运河侧廊 → 摆渡庵 → 潮桥 → 灯市 → 听潮长阶（0–6m）→ 七重潮门（七海）→ 晨钟台阶（6–10m）→ 黎明钟。进入时可望见高处铜钟；暖灯、路宽与朝向引导主线，地图和宝宝模式提供明确解释。

南支路：灯市 → 晒网坡 → 晒网高廊（4m）→ 风铃屋顶木匣 → 断栏落回灯市。落点从上方可见；直接走下约4m会掉血，不能逆向攀回。可不跳并沿坡退回。

东支路：灯市 → 苔灯支阶（3m）→ 苔灯戏台（阿梓）→ 戏匣 → 落雨檐 → 回潮低埠（0m）→ 灯市。三米自然走下无伤；低码头能看到主路灯火。绿灯/帷幕与主路石阶区分。

## 跳跃、坠落

地面行走与空中移动分离。可见72cm矮栏阻挡行走，但跳跃高度足够时可以越过；3.3m关闭铁门仍阻挡。无支撑则按重力下落，使用扫过的高度检测地面，按最高点到落地的落差计伤：3.5m以内无伤，之后每米14伤害，10m致命。水下-8m判定死亡。坠落不受翻滚无敌保护。坠水钱袋留在最后可靠落脚点，可取回；空中存档保留轨迹，不刷新补血。

角色皮肤在标题/暂停面板选择，保存设置；精灵造型仍独立。

七海 · 七重潮声：参考项目七海图的棕发、金眼、耳机、深色外套与蓝结。持十字镐，破浪镐击、长蓄力沉镐、不可弹反但可跳过的返潮环扫；半血加速镐击与扫浪。长重击后收招允许治疗/反击。
阿梓 · 苔灯夜曲：紫发金眼、青色蛙帽斗篷、双侧发辫，蛙铃杖。短切分、故意延迟的休止符重击、蛙鸣圆舞；半血延长迟落拍，要求看释放动作，不能背固定拍子。击败后两者都不因休息重生。

黎明钟只在七海战胜后可响，奖励只领取一次；不强制切结局，世界持续开放。v3存档升级v4时仅加入新区初始敌人，旧战斗、资源、探索和复活点保留。

## 入口与脱困

夜市东侧 → 运河侧廊 → 摆渡庵向东 → 潮桥 → 潮汐港。庵堂东墙改为两根立柱间的敞口，沿途有指向潮汐港的路牌和暖灯。通关第一幕后，宝宝模式可直接让精灵带去入口；C 交谈或 M 地图也能选择。普通模式保留环境路标与诗性纸条，不展示攻略路线。

暂停菜单与 M 地图均提供「脱离卡死」。回到已经记录的中庭雨灯，未点灯则回旅馆；清除坠落、攻击与锁定状态，保留当前生命、药瓶、金钱、钱袋、击败与探索进度，不补给也不重置敌人。操作后立即保存。

## 建筑碰撞

architecture.ts 共用房屋的世界位置、朝向、坡顶和檐口尺寸，渲染与碰撞使用同一组实体。水平移动检查身体体积；落地按屋顶实际斜面高度判定；上跳检测楼板和屋檐底面。庵堂顶、立柱、旅馆基座和港区高台基座也进入实体碰撞，镜头使用相同建筑数据。合法屋顶落点支持存档重载；屋顶与回廊之间的空隙仍需跳过。

专项规则：scripts/tests/night-rain-architecture.test.mjs，比对 Three.js 实际旋转屋顶的射线交点、屋顶跳落与读档、墙体/头顶阻挡、旧城连续走到新入口、脱困保留资源。专项浏览器：scripts/verify-night-rain-rescue.cjs，全程静音无头系统 Chrome 与虚拟输入，不占用系统鼠标。
