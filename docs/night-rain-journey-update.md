# 雨夜寻味 · 行旅、声音与遗物

本次更新修复开口语音卡顿，完善手柄菜单与设备提示，加入三个 CC0 音乐场景和合成动作音效。常用提示与目的地引导在开发时离线生成，本地旁白播放不再访问浏览器系统 TTS；音乐和旁白均异步流式播放。音乐、音效、旁白有独立音量及静音开关。浏览器首次播放需要一次点击或按键。

雨灯交互打开休息、强化、锻造、更换装备和传送菜单。首次点灯只记复活点，再次休息才补给。未点灯是冷蓝符光且无火焰，点灯是暖金火焰；地图列出已开雨灯，在安全雨灯旁可以传送。所有菜单支持十字键／摇杆选择、确认、返回、选项和音量调节，Xbox、PlayStation、Nintendo 标准映射按物理按钮位置提示。未映射的手柄仍需浏览器的标准 Gamepad 映射。

打抛饭、王寺钟与河心放灯使用实时过场和对白，不再显示重开或通关统计；真正的归灯暗线结局保留结算。蓄力在 0.75 秒蓄满后自动释放，一直持有不会重复出招。首领普通受击不被重击打断，重击架势伤害在攻击中按 38%、收招中按 62%计；弹反架势收益保留。

近战普通敌人依次使用游击短棍、架盾迟落、拔刀突进、长枪拒马、钩镰和扫堂杖。远程只放在预先选定的固定守位，使用可见的箭矢和投石，提前固定方向，遮挡会拦住弹道，近身迫使改用短刃；不同支路留有侧向接近和掩体。

旧寺残钟旁可进「弃灯墓地」，包含箭廊与绕行侧廊，露缇约为旅人 2.5 倍高。雾河渡村可进「风息洞窟」，有晶苇支路和约三倍高的沐石。两处都有雨灯与退出石门，不占主线任务进度。独特战利品：藏骨轻甲、守灯长枪、刻名石印、风苇披风、双苇短刃、听岩巨槌与潮息结。主线伞／铁伞／武士刀和副本三件武器具有不同距离、速度、体力、破架与防御；防具和一枚护符可更换，卸下生命护符不会免费治疗。

拾取物分白光普通、紫光稀有、金光珍贵，光柱高度与粒子数量也不同。任务纸条有紫色高光柱，普通指路纸条只有小白光；读过之后熄灭。水车院修缆机关有青绿色高光柱，花礼败后精灵会提示修缆，激活渡埠出现青色环。

五个旅人档位分别保存外观、探索、装备与图鉴；旧单档只复制到空的第一档，不覆盖已有档位。暂停菜单「保存并返回标题」切换档位。击败敌人收录图鉴，可查看与场景一致的模型和读招介绍。所有改动以完整旧城／双岸／暗线和副本规则回归、静音系统 Chrome 交互和截图、拾取与旁白长任务检查验证。

## 使用与复跑

标题展开「选择旅人」切换档位；暂停选择「保存并返回标题」后切换。暂停菜单进入「雨夜图鉴」，击败后收录；岩苔巨躯拥有独立的大型模型条目。雨灯的「更换行装」更换三类装备，M 地图列出已开雨灯。墓地从残钟雨寺入口进入，洞窟需先完成王寺钟声。

规则：`pnpm run night:test`。浏览器：设置 `NIGHT_RAIN_BASE_URL` 和 `NIGHT_RAIN_QA_DIR` 后运行 `node scripts/verify-night-rain-journey-update.cjs`、`node scripts/verify-night-rain-devices.cjs`；拾取用 `node scripts/verify-night-rain-pickup.cjs`。测试使用安装版 Chrome、静音扬声器、抛错的系统 speech stub，实际本地音频与 analyser 仍工作。特殊姿势画面使用校验过的存档夹具；游戏内操作使用公开输入，未提供运行时状态修改。菜单手柄为标准 Gamepad API 模拟设备，未做实体手柄验收。

旁白离线生成 `node scripts/prepare-night-rain-voices.mjs` 和 `scripts/bake-night-rain-voices.ps1`。Windows PowerShell 5.1 应以 UTF-8 显式读取脚本后用 ScriptBlock.Create 执行，防止中文被本机代码页误读；SAPI 只输出文件，未播放到扬声器。音乐来源、CC0 授权和 SHA256 在 `public/games/night-rain/audio/CREDITS.md` 与 `sources.json`，本地旁白共 569 条。

表现沿用原创低模和程序动作；副本使用开顶石室、墓龛与石隙，镜头可看见开顶外部。暂无新的视频资源或实体手机 GPU 测试。保存格式 v9 兼容旧版，图鉴只记已击败种类，不提前解锁。传送、卸下生命护符和入口石门都不提供免费治疗。
