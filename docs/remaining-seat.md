# 余席 / The Remaining Seat

2026-10-26 发布前集成：已同步最新 master `a27fa7c`，目录入口放在“故事与抉择”最后。8 项游戏规则和 6 项目录测试通过，系统 Chrome 三幕、双结局与触屏回归通过，11 张截图完成像素检查及目检。全项目 check、build 顺序通过；正式构建另验证分类排序、封面加载、正常键盘移动、读信、390px 布局及生产模式不暴露测试定位接口。验收浏览器静音、禁用语音并隔离 Pointer Lock。线上发布状态以部署平台及正式域名验收为准。

一部发生在雨夜老房子里的第一人称心理恐怖短篇。年轻人下班回家，发现一桌留给自己的饭。等他把碗筷摆齐，门外又传来自己的脚步声。

本文是叙事与制作规范；当前剧情源为 `src/components/remainingSeat/engine.ts`，完成情况以实现及验收记录为准。首个切片预期 8–15 分钟，取决于探索速度；这不是已经测得的游玩时长。

## 创作边界

- 压力通过物件、空间、重复的动作和未兑现的承诺表达。不给场景贴社会议题标签，不用解释性独白替玩家下结论。
- 长辈有过自己的愿望，也没有学会另一种关心方式。他们会伤害人，但不是供玩家击败的怪物。
- 家庭、工作、住房和身体被同一套“再等一阵”串起。角色不因婚姻、生育、性别或身体状况被判定为失败者。
- 恐怖来自日常秩序多出一格：多一副碗筷、晚一秒的反光、看似更近的门。避免依靠血腥、突响、突然贴脸或强制镜头晃动。
- 《还愿》只作为日常空间能承载心理恐怖的类型参考。人物、房间结构、意象组合、剧情、对白、美术和声音均原创，不复用其宗教仪式、家庭悲剧或标志性画面。

## 角色与空间

主角“小满”，27 岁，刚开始习惯独立生活，又被许多尚未发生的身份预先叫住。第一人称不锁定性别；人物资产采用中性呈现。不要用外貌“诊断”角色，用湿鞋、皱袖、一个未发出的句号交代疲惫。

母亲没有实体敌人形象。她通过留饭、修改过的字条和年轻时的愿望存在。门后含混的说话声可以像亲人的声音，也可以像主角自己的记忆。

切片只用一间旧公寓：东西约 10 米、南北约 14 米（原型坐标 `x = -5…5`，`z = -7…7`）。一张饭桌、一处狭窄工位、一张空摇篮、一扇雨窗和回到同处的门。家具保持可信的生活尺度，重复的是时间与用途，而非随机拼贴。

色彩以潮湿米黄、脏灰绿和深褐木色为基底；红只用于线、少量旧标签和第三章的视觉连接。红线是传递义务的材料，不是邪教标志。黑暗仍要能看清走路和交互目标。

## 三章结构

| 章节 | 可感知的变化 | 叙事推进 | 玩家行动 |
| --- | --- | --- | --- |
| 一 · 留一双筷子 | 暖灯、雨声、正常尺度；五把椅子，六只碗 | “有人等我”逐渐变成“有人在等我成为另一个人” | 记下家书、合照与空碗；再推开里屋的门 |
| 二 · 再等一个明天 | 餐桌被工位冷光照亮；椅背出现工号，钟里塞满打卡纸 | 上班和回家开始执行同一种考核；承诺要先于能力到来 | 记下工位、挂钟与餐桌；再推开里屋的门 |
| 三 · 空着也可以 | 旧红线串起桌、工位和摇篮；母亲未寄出的信与半张车票浮现 | 关心也可能继承恐惧；上一代并非从未想过离开 | 记下摇篮、合照与家书；回到餐桌或走向雨窗，作出当晚的选择 |

目标节奏是每章约 2–4 分钟，自由观察另留 2–3 分钟。没有倒计时、跑酷或失败惩罚。每章三个关键观察解锁下一步，次要物件可自由阅读；不需要反复盲试密码。关键变化应有光、构图或文字中的至少两种提示，避免玩家把场景重复误认成程序卡死。

## 可检查物件的文案库

以下摘录与当前引擎对应，用于内容验收；完整文案以引擎为准。观察面板可关闭，只有主动选择“记住”或相应物件动作才推进记录。

| 物件 | 留一双筷子 | 再等一个明天 | 空着也可以 |
| --- | --- | --- | --- |
| 家书 | 末尾的“不急”被反复描过，纸背都快破了。 | 你的名字，填满了每一个空白。 | 有时候，又把自己的怕，说成了你的应该。 |
| 餐桌 | 五把椅子，六只碗。 | 椅背上贴着工号。和你胸前那个一样。 | 只要把那只空碗往前推一点，今晚就可以和昨晚一样。 |
| 挂钟 | 秒针每走一下，分针就往回退一点。 | 每张纸都把“明天”留在最后一栏，没有一张填过。 | 你没有再替它上弦。 |
| 工位 | 正在等待下一项安排。 | 请确认你可以长期稳定地承担。 | 你没有把所有事做完。屋子也没有因此倒下来。 |
| 摇篮 | 没有名字的标签上，只有一句：以后总用得着。 | 旧册子写着每个年龄应当完成的事。最后一页没有留白。 | 顶针旁的小纸条写着：我那时也怕。 |
| 合照 | 大人的手搭在肩上，像扶着，也像按着。 | 相框里多出了一排椅子。每一把上面都搭着相同的外套。 | 照片背后，夹着母亲年轻时的半张车票。目的地靠海。 |
| 门 | 门后应是卧室，却传来碗筷声。 | 里面又有人摆好了饭。 | 门后的声音和屋里的声音是同一个声音。 |
| 窗 | 招聘栏被水汽洇成一片，看不清日期。 | 玻璃上映着你身后的空椅子。 | 这张桌子，今晚可以不用坐满。 |

母亲的车票写着“下次吧”，背面仍然空白。主角不指责这句话，也不宣布自己已治愈；只把车票放回她的照片旁。

## 两个结尾

**给明天留白 / `air`**：第三章关键观察完成后，在窗边选择“打开窗，给自己留一点空气”。主角把空碗收进柜子，给自己盛半碗汤，写下“今天先睡。海，可以慢慢去”。天仍没亮，工作、账单和关系没有被神奇解决。这个选择只是在当下划出一小块能够呼吸的地方。

**饭还温着 / `seat`**：第三章关键观察完成后，在餐桌选择“把空碗摆正，坐回去”。有人松了一口气，声音很像自己；门边再次响起钥匙声，桌上又多出一只碗，仍差十三分到明天。不使用坏结局羞辱、道德评分或训诫；承认暂时顺从可能是人在压力下能做到的事。允许从头重玩探索另一个选择。

## 声音与舒适度

雨、冰箱压缩机、荧光灯、钟表与键盘声可构成后续声音层，不需要突然放大。亲属对白应保持零碎、普通、不含直接政治口号；首个切片无配音也能成立。当前原型使用程序合成的低频与滤波噪声，环境声默认关闭，可在标题或暂停菜单开启；观察物件、暂停和结尾时淡出。

避免高频闪烁；紧张感用缓慢光色、雾与家具变化表达。游戏必须可以暂停，观察文字时不移动角色。自动测试浏览器静音并禁用语音合成，不改变真实玩家的声音偏好。

## 美术生产与 Meshy 接口

首个切片的场景可以使用程序化几何，优先验证空间、阅读顺序与两个选择。人物是后续可替换资源，不是完成核心流程的阻塞项。模型交付规范、三个独立视图提示词、来源记录要求见 [模型目录说明](../public/models/remaining-seat/README.md)。

参考：[Meshy Multi-Image to 3D API](https://docs.meshy.ai/en/api/multi-image-to-3d)、[官方多视图指南](https://www.meshy.ai/tutorials/multi-view-image-to-3d)。正式提交时重新确认版本、价格和授权条款，不把指南中的效果描述作为验收保证。

## 运行与验收

- 游戏入口：`/game/remaining-seat`，游戏大厅“故事与抉择”也提供入口。
- 启动：`pnpm exec next dev --hostname 127.0.0.1 --port 3896`。并行开发时可将 `NEXT_DIST_DIR` 设为 `.next-remaining-seat-dev`，隔离开发缓存。
- 规则回归：`pnpm remaining-seat:test`。
- Chrome 验收：服务响应后运行 `pnpm remaining-seat:verify`；可通过 `REMAINING_SEAT_BASE_URL` 改服务地址、`PLAYWRIGHT_MODULE` 指定已有的 Playwright 安装。脚本使用系统 Chrome、静音并禁用语音合成，证据输出到 `tmp/remaining-seat`。
- 验收专用定位接口仅在开发模式且 URL 含 `?qa=1` 时启用。脚本用其定位物件，通过真实按键和界面按钮推进；另检查真实键鼠/触屏移动、松手停止、模态暂停、保存恢复、两个结局和窄屏布局。
- `window.render_game_to_text()` 提供章节、目标、观察记录、视角位置和暂停状态；截图另核对画布尺寸、实际渲染统计、像素分布和页面错误。所有证据截图均需打开目检。
- 完整门禁按顺序运行 `pnpm run check`、`pnpm run build`。不关闭构建中的 ESLint，不并行运行 TypeScript 与构建。

当前场景为原创程序化几何与画布纹理，声音为浏览器合成，无外部模型下载。未加入人物动画、追逐 AI、配音或正式发行资源；这些属于后续内容制作。
