## 已实现

- 视觉：奶油白、深青手术布、香槟金器械；大幅原创矢量绘制角色、侧边细长仪表、实体器械托盘。
- 内容：直接看到操作台；右侧选择难度并开始；资料和原话放进可暂停阅读的来源抽屉。
- 动效：器械带惯性跟手、蓄力针阵与射频波纹、角色随疼痛变表情、栓剂用遮挡帘演出。
- 技术：现有 Next.js + React，Phaser 驱动单 canvas，纯 TypeScript 规则独立；用 Canvas 渲染适合此 2D 绘制场景，不需要新依赖。
- 玩法：清洁 → 敷麻 → 擦除 → 微针操作 → 冷敷；覆盖全部目标，按住稳定后在金色时机窗松开，过久、偏位和重复施打会增加疼痛与风险；三种难度、结算、重开、记录。
- 栓剂：玩家主动选择，单局一次，虚构减痛效果，帘幕后完成；未选择也能通关，无真实给药剂量或方法。
- 验证：规则测试、静音系统 Chrome 的桌面/移动端完整操作、截图与状态对照、完整 lint/typecheck 和构建。测试浏览器统一 `--mute-audio` 并 stub speechSynthesis。通用客户端不能注入这些静音设置，使用仓库本地验收脚本。

## 当前状态

已完成调研、独立页面 `/game/golden-needle` 和 `/demos` 实景预览入口。三档难度分别有 12 / 15 / 18 个目标；高难度需要调整探头角度。四种工具带惯性跟手、手套和线缆，疼痛会引起手抖与表情变化，探头过热需要冷却。支持成功结算、中止、重开、切换难度与本机最佳记录。

栓剂是单局一次的可选道具，短暂拉帘后生效，在 90 秒游戏时间内降低疼痛增长；不使用也能完成所有难度。清洁、敷麻、擦除、操作和最后逐点冷敷都需要亲手完成。

操作：鼠标或触屏移动器械，按住目标，在金色区间松开；`1`–`4` 换工具，`Q` / `E` 调整角度，`P` 暂停，`F` 全屏。页面隐藏时自动暂停，失焦取消按压；帮助和灵感档案打开时暂停游戏。支持 390px 和 320px 窄屏。
