# AI 厂商、社区梗与游戏机制映射

检索日期：2026-09-12。目标是让《智能纪元》的公司做出可辨认的经营行为，保留幽默与行业感。下面的模型名称是核查到的代表产品，不是“所有厂商最新版本”榜单，也不把不同测试的分数混成能力排名。

检索方式：分别检索 DeepSeek 社区形象、投资者交流报道、Anthropic 反蒸馏与地区限制、Codex 重置原帖、Grok 创意模式争议、GLM 后训练与 MiniMax 视频开源；实际打开相关原文，再核对 Qwen、Wan、Kimi、Llama 官方仓库和 OpenRouter 文档。Google 的 AI 摘要仅作线索，未作为事实依据。部分浏览器页面正文为空时，另用网页原始响应读取可见文章文本。

## 厂商与代表模型

| 现实原型 | 核查的特点 | 游戏公司与实际效果 |
| --- | --- | --- |
| DeepSeek：V 系列、R1、Harness | 研究主线、成本效率、开放生态、鲸鱼娘社区二创 | 深海求索：研究优先训练额外 +2；“开饭，继续研究”改善社区与可靠性；有三条独有事件。 |
| Anthropic：Claude、Claude Code | 企业编码、地区准入限制、反蒸馏与安全立场 | 宪章智能：企业方向收入 +20%；防线升级限制数据合作并降低同行追赶收益；竞速与安全存在真实取舍。 |
| OpenAI：GPT、ChatGPT、Codex | 订阅产品、开发者关系、额度重置 | 明日智能：用户产品收入 +15%；付费重置带来一次性的社区与收入提升。 |
| xAI：Grok、Imagine | 创意娱乐、话题流量、内容边界争议与收紧 | 野火实验室：创意收入 +20%；午夜频道吸引用户，但付出安全余量和两季审核开销。 |
| 智谱 / Z.ai：GLM-5.2、GLM-5.3 | 同基座后训练、复杂编码、长程可执行任务环境 | 智序科技：后训练比其他厂商多获得可靠性 +8、能力 +2；高预期与低交付存在反噬。 |
| MiniMax：M 系列、Hailuo、H3 | 不只做视频，也有语言/Agent/语音路线；H3 音视频一体化与开放权重 | 海螺映像：视频研发 +28、创意收入 +30%，独有音画同步动作与视频开放事件。 |
| Google DeepMind：Gemini、Gemma | Gemini 模型卡支持原生多模态、百万上下文与 TPU；Gemma 是另一开放模型产品线，不能等同于 Gemini 开源 | 双子云图：算力扩建便宜 5 M，视频研发兼顾通用能力，长上下文工作台改善任务交付。 |
| 阿里：Qwen、Wan | 多尺寸、思考/非思考路线、工具生态；Qwen3 权重 Apache 2.0；Wan2.1 较早开放视频模型 | 千问工坊：开放发布与“全家桶”带动生态，生态产生额外收入；消费者硬件适配与旗舰研发可取舍。 |
| 月之暗面：Kimi、K2 | K2 官方仓库明确 MoE、Muon/MuonClip、面向工具和自主任务的 Agent 能力 | 月面工作室：自我提升成本低 6 M，递归研究额外能力 +2，长程工具任务强化可靠性。 |
| Meta：Llama | 可下载的模型权重、社区许可证、开发者部署生态；不笼统说成无限制开源 | 羊驼联盟：社区许可与发布显著提升生态，下游影响力转化为收入。 |
| 多模型聚合平台 | 路由、回退、上游成本、数据/蒸馏许可不是同一概念 | 百模中转站：上游调用更便宜，但“租来的能力”不能用于宣布自己的 AGI；学习需要许可、样本与行动。 |

这些是游戏化权衡，不是现实厂商定量评估。厂商在现实中都有多条业务线，游戏只突出最可辨认的一组机制。无需给每个现实版本都单独创建一个阵营。

## 实现和验收

新增 `agiIndustry.ts` 管理 11 家公司、18 个两选一事件、17 条来源索引。`agiEngine.ts` 的 v2 存档加入经营方向、可靠性、视频、生态、预期、审核、防线、上游与授权样本；旧 v1 的现金、能力、季度等进度迁移保留，旧三家对手的进度作为新同行阵容的初始进度。

玩家和十家同行都拥有可识别的路线；游戏有来源折叠区，事件显示“现实路线改编 / 社区梗改编 / 虚构行业事件”。宣传、实际交付、自研能力和对外服务能力分别计算。

验收完成：20/20 逻辑测试通过，包括 11 家公司 × 2 个种子的可靠 AGI 通关、来源与事件覆盖、算力分配锁定、低资金事件暂缓、授权数据链、反蒸馏与旧存档迁移。

系统 Chrome 验证 11 个厂商选择与专长、事件结算/刷新、视频开放、路由与样本学习，以及四个 AGI 结局：共同富裕 Q8、商业霸主 Q8、守望者协议 Q10、失控的黎明 Q6。8 张桌面/390px 完整页面截图完成像素检查与逐张目检，无页面或控制台错误。报告：`tmp/agi-industry-verify/report.json`。共享 web-game 客户端也完成开局动作与一张已目检的非黑截图。

本任务代码在独立检出中顺序通过 `pnpm run check` 与 `pnpm run build`，构建保留 ESLint，生成 45 页。共享工作区同期还有开发中的主播/RPG 模块；首次全仓检查的两条 Set 迭代错误位于这些无关模块，因此独立检出用于验证本轮 AGI 改动，不声称同期所有未提交工作均已通过检查。

发布入口：`https://my-pixijs-game.vercel.app/game/agi`。页面顶部标识为「V2 · 11 家厂商 · 18 个行业事件」。已有存档自动续玩并展示行业面板；选择「新开一局」才能重新挑选 11 家厂商。此前研究完成时这些改动仅在本地，2026-09-12 按用户反馈补入正式发布流程。


## V2.2 呈现与玩法修订

研究表中的历史称呼保留用于解释调研过程；当前游戏统一使用晴空智能、蓝湾研究所、灯塔实验室、野火实验室、星序科技、流光影业、天穹计算、积木工坊、远帆工作室、原野联盟、百模中转站。真实原型/模型名仅放在折叠的灵感来源里，默认选项以玩法说明替代品牌标签。

前四个推荐选项为晴空智能、蓝湾研究所、流光影业、野火实验室。蒸馏从「自身压缩提效」改为「选择另一家已发布模型追近差距」；自身优化独立保留。用户运营决策集中到事件→行动的同一区域，顶部资源与底部季度结算持续可见。
