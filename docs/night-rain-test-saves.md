# 旅居之魂测试存档

本地试玩服务运行时，打开 `/games/night-rain/test-saves/index.html`。

- 「载入第三关测试档」：前两关完成，从第二关终点向东进入天镜原。
- 「载入第四关测试档」：前三关完成，从天镜原归航台向北进入沉钟修道院。

选择后自动写入首个空的旅人档位并打开游戏，点击「继续雨夜旅程 →」。两档均为岁己、行装 +8、铁骨伞 +2、满生命与药瓶；后续章节保持未完成。可下载 JSON 备份；当前游戏没有通用 JSON 导入按钮，使用页面按钮即可安装。

已有档位不会覆盖；旧版单档存在时预留第一档供迁移。五档全满会停止写入。存档只在同一浏览器、同一网址来源下共享；其他游戏标签页请先保存并返回标题。

重新生成：`node scripts/create-night-rain-test-saves.mjs`。生成器读取章节测试基线，用真正的 `saveGame` / `loadGame` 校验；游戏存档版本变化后应重新生成并验证。

验证：`node scripts/verify-night-rain-test-saves.cjs`。默认服务 `http://127.0.0.1:4127`，可用 `NIGHT_RAIN_BASE_URL` 覆盖。使用静音安装版 Chrome、独立浏览器上下文，检查两档安装/续玩/刷新、原档保护、旧档迁移、满档保护、下载与 320px 布局，截图和报告在 `tmp/night-test-saves/`。

Next 生产服务在启动时扫描 public 文件；新增这些文件后需重启当前服务，不需重新构建游戏。
