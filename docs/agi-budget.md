# 智能纪元：季度收支预估

2026-10-03，`/game/agi`。

旧界面的「预计收入」使用收入基数，未应用当前市场与监管倍率，也未列出宣传过度导致的 8 M 退款。旧生产存档复现：采购热潮显示 16.9 M，结算收入实际 23.7 M；安全审视下显示同样基数，但实际收入 8.5 M，扣除运营和退款后现金变为 −8.5 M。

结束季度旁现在显示「已知结算后」资金，点击「查看本季收支」可见收入基数、市场倍率、监管折扣、实际预计收入，以及基础运营、算力维护、服务方针、上游调用、训练许可与样本、审查、反蒸馏防线七项费用。退款单列，注明市场预期超过可靠性 15 点的条件。负资金给出风险提示，保留直接结算选择。

预估按当前公开状态计算，不消耗行动或随机数；已经支付的行动费用不重复扣除。尚未回应的行业事件和后续行动都会更新预估。对手可能购买闭源模型训练许可带来的收入不预先承诺，实际余额可能因此更高；也不预测谁会率先启动 AGI。合作按本季设置计费，上游限制可能在结算时停止调用或样本供应，沿用原规则。

移动端使用原生模态弹窗，内容可滚动、关闭按钮固定可达；支持键盘 Enter 打开、Escape 关闭及焦点返回，触屏可打开、滚动和关闭。查看预估不写入存档，新旧存档均从当前状态计算。顶部原「季度收入」改为「收入基数」，避免与结算收入混淆。

`pnpm agi:budget:test` 验证基线金额、七类费用、监管与退款精确边界、只读与随机独立性、660 组市场/公司/方针/门槛组合、行动支付与后训练、递归结算先后顺序和零现金边界。原 `pnpm mini:test` 覆盖完整经营路线、AI 竞争和结局、存档兼容及共用小游戏规则。

`pnpm agi:budget:verify` 在静音安装版 Chrome 中运行；`MINI_BASE_URL` 指定服务根地址，`AGI_BUDGET_OUTPUT` 指定输出目录。覆盖恢复测试存档的采购/监管/退款、破产、后训练与刷新、合作成本，320/390px/横屏真实触摸与滚动，以及正常开局后的完整 AGI 路线，逐季核对预估与实际结算。截图检查像素、DOM、画布和公开状态后逐张目检。
