# 岁己舰礼档案

页面：`/liver/sui/gifts`。入口位于直播成员目录及岁己直播页导航。首批人工整理日期：2026-10-02。

## 范围与事实边界

- 日历覆盖 2022-09 至 2026-10，共 50 个月；33 个月有条目，其余 17 个月明确留空。
- 31 个月有录播字幕依据；2023-12、2025-10 目前只有网络或弹幕线索。**不声称已收齐任何月份的全部身份、领取条件和最终成品。**
- 15 张展示图来自本地录播的礼单、样品或插画画面。没有用生成图片补造商品，没有把主播头像当作商品照片。图片保留“直播展示／非实物照片／示意图”标注。
- 舰长、提督、总督独立记录。除非原公告另有明确说明，不从高档身份自动推定包含所有低档礼物。
- 按礼物所属月归档，不按发货月或回顾直播日期。例如 2026-01-13 的三周年 T 恤回顾归入 2025-09。
- 2026-09 的 150 舰画框立牌、200 舰应援棒、25 提督纪念 T 恤等保留门槛，不作为无条件赠品。
- 自动字幕存在同音错字和幻觉，原文摘录与归一后的商品名分开。`recorded` 仅表示有录播字幕依据，不表示逐字人工听写、实物验收或最终发货确认。

## 检索过程

只读搜索了当前 DDTV 录播盘与归档盘中岁己房间（25788785）的日期目录：1,646 份字幕、2,210 份弹幕 XML。跳过 `.speaker.srt` 和递归生成的剪辑/缓存目录。153 份 XML 无法完整解析；这些文件不能视为已完整检索。根目录路径只保留在本地忽略目录，不进入前端数据。

2024-01 至 2026-09 的本地字幕较连续；2025-07 只有一份字幕。2022、2023 年仅少量资料，2026-10 截至整理日也没有足够明确的礼单。未找到可靠依据的月份保留“资料待补”，不写成“没有礼物”。

## 数据与补档

- `src/data/gifts/sui.json`：人工维护的可移植档案。每条礼物都指向该月 `sources` 的稳定 ID；每张图片保存源文件引用、录播偏移、裁剪坐标、宽高和说明。
- `public/images/sui-gifts/`：经检查的 WebP 裁剪图，总体积约 1.2 MB；图片文字可能因原直播滚动或遮挡不完整，支持打开原尺寸核对。
- `src/components/gifts/catalog.ts`：筛选、查询参数及类型。关键词与身份联合匹配，避免搜到另一个身份的礼物。多个关键词按空格求交集。
- `scripts/research-sui-gifts.py`：只读候选发现工具。传入一个或多个 `--root`，输出到忽略目录。它不写前端数据，不把扫描命中自动发布成事实。

补档步骤：

1. 扫描字幕和弹幕，找到候选后读取前后文，确认“这个月／上个月”指代、归属身份与是否已决定。
2. 为条目添加源文件名、实际录播日期、偏移范围及原文摘录。跨午夜录制使用文件内的录制日期，不机械使用父目录日期。
3. 网络来源记录原始 URL、实际读到的内容与检索日期。只有索引或观众发言的设为 `lead`。
4. 用与字幕**文件主名完全一致**的录播提取画面，避免误选同目录另一分段。裁去无关聊天和用户信息，保留礼物上下文；检查每一张图后转 WebP。
5. 修改 `sui.json`，保留条件与缺项。不要把活动当天规则自动扩成全月，不把“考虑做”改成已公布。
6. 运行以下检查。数据与图片随站点构建，不依赖外部请求才能浏览；页面未新增领取、购买或发货功能。

## 页面设计与交互

视觉采用暖白纸面、深色文字和单一莓红强调色；按年导航、按月编排，真实展示图与礼单并列。以查询为主工作区，不添加营销海报或统计卡片墙。内容次序为页面说明、筛选、月份条目、出处与图片细节。标题轻量入场、年份导航固定、图片 hover 放大和原生模态预览提供操作反馈；尊重减少动态效果偏好。

支持年份、月份、身份、关键词、资料类型、缺失月份筛选与分页。筛选写入 URL，刷新及浏览器前进后退会恢复。图片对话框支持 Escape、焦点约束和返回触发按钮。字幕可展开，外链使用新页并附 `noreferrer`。
