# 同居3D互动改进

用户顺序：先提交并推送当前可玩3D版本，再优化互动。稳定版已推送8e98a53。

痛点是不同动作都套用长按进度：拿东西/递饭/语音报点没有动作区别，等待时缺少反馈。改为三种交互：

- 轻按：拿外卖0.35秒、拿充电器0.4秒，自动完成伸手拿取动画；把食物放在直播桌左侧，自动摆好饭盒与饮料。门、收好充电器、收工也采用轻按。
- 瞄准：电脑报点进入点击移动小球的短小游戏。完成8个报点；目标超时或点空会失误，3次失误后可重试。每次报点仍会发声，门/音乐/低声模式仍影响风险。
- 持续：拥抱3秒、亲吻1.4秒，保留可松手的主动亲密互动；中央进度环加深底色、增粗实色进度并显示百分比。

角色在未闭麦时有讲话口型，平常主要面对直播屏幕、间或偷看玩家。摆餐后可能起身走近；这是可选亲密邀请，玩家可以继续办事。所有动画、报点时限、邀请倒计时都随游戏暂停，不受截图或实际帧率影响。

验证重点：短按松开仍完成一次拿取、按住不连触发、物品连续移动且只出现一份、桌上摆餐不必对准人物、报点不能按住E跳过、点击/超时/点空/暂停/重试/噪声、男女角色说话与闭麦口型、邀请可以接受或忽略、手机触屏与高对比长按圈、完整五晚/随机夜与存档。


已实现并验证：21项规则测试、全关卡通关、3D操作专项、新互动专项、35张系统Chrome截图目检与像素检查、check/build。生产版实时时钟下按键轻点拿取与8次移动小球命中通过，零失误、无页面错误。新版本地试玩沿用http://127.0.0.1:3879/game/hush-live。用户已授权提交推送本轮体验优化。
