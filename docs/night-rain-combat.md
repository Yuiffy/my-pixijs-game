# 雨夜寻味：动作与克制叙事

2026-09-26。空格跳跃；Shift 短按松开闪避，持续按住 0.2 秒后疾跑，长按后松手不翻滚。鼠标左键轻击，右键重击／长按蓄力，F 轻按弹反／按住防御。手柄 A 跳跃、B 闪避／疾跑、RB 轻击、RT 蓄力重击、Y 交互、LT 精灵；菜单仍为 A 确认、B 返回。

## 设计依据

- [Bandai Namco《Elden Ring》官方入门指南](https://en.bandainamcoent.eu/elden-ring/news/elden-ring-starter-guide-tips-know-playing-the-game)：B 翻滚／按住疾跑，A 跳跃，疾跑及空中攻击、蓄力攻击有不同用途。采用动作上下文和跳跃／闪避独立按键。
- [Capcom《Monster Hunter Wilds》Focus Mode](https://www.monsterhunter.com/wilds/en-uk/hunting/focus-mode/)：攻击／防御可朝镜头方向瞄准。本项目允许起手修正方向，出手后降低转速；具体角度与时长为本项目调校，并非官方参数。
- [GDKeys：Anatomy of an Attack](https://gdkeys.com/keys-to-combat-design-1-anatomy-of-an-attack/)：以起手、攻击、收招划分节奏，动作需要全身轮廓、明确命中瞬间与取消窗口；避免为区分按住／点击而拖延全部动作。重击按下立即进入蓄力姿势，短按累计时间抵扣部分起手。

## 实现

三段轻击依次横斩、返斩、踏步挑斩；普通重击举伞下劈，蓄满重击加深下压；疾跑轻击突刺、疾跑重击回旋；空中轻击横斩、空中重击下砸落地。九种招式各有全身关键姿势、体力消耗、前移距离、命中时点、收招和颜色，统一时间轴驱动规则与渲染。武器轨迹采样同一组动作，命中有短暂顿帧，挥空不顿帧。

地面蓄力 0.75 秒满蓄、1.5 秒自动释放；完整重击合计消耗 43 体力。仅保存一次 0.22 秒的输入缓冲，在招式允许的时点衔接。起手转速较快，命中后明显收紧，且总转角受招式上限约束；方向输入优先，其次锁定目标，再其次镜头方向。攻击前移接受实际碰撞，不能自由滑步。

跳跃独立模拟垂直高度和重力，限制空中转向；每跳最多一次空中攻击。跳跃可越过首领低扫，但普通上身攻击仍会命中。当前跳跃用于战斗，不跨越栏杆、关闭的门或无地表的缺口，不是平台跳跃系统。暂停、Alt 释放或失焦取消蓄力与待执行动作，恢复后不突然出招。旧版存档缺失的新字段使用兼容默认值。

## 叙事与字幕

关闭宝宝模式：不显示路线攻略、战斗教学、常驻按键条与小精灵字幕／语音；主动阅读纸条才出现世界文字。屋顶便签为“伞下无归客。逐水向东，归人自解旧闩。”宝箱只显示“旧铜钱 ×35”，机关只显示“门闩落下”。保留必要的交互按键、数值和可主动查看的操作手记。

开启宝宝模式：精灵解释谜语、道具用途与返回路线，保留原有遗漏提醒、带路、战斗建议与可选语音。重复阅读同一纸条也重新解读。世界文字与精灵字幕分开显示在中下方，移动端避让动作区；出招和跳跃时不显示交互按钮。地图普通模式只标闭门，不解释开启路线。

## 验证

41 项规则测试覆盖跳跃、闪避／疾跑、连段、蓄力、转向、空中落地命中、碰撞、取消、存档、顿帧和旧第一幕。后台系统 Chrome 使用虚拟 Pointer Lock 和 Gamepad API 边界，不捕获系统鼠标、不打开前台测试窗口，也不刷新用户的 3871 标签页。

- `tmp/night-rain-combat/report.json`：九种动作、键鼠、Alt 取消、手机跳跃／蓄力／快速闪避、两种模式字幕。
- `tmp/night-rain-combat-devices/report.json`：键鼠组合输入、手柄摇杆／动作／菜单／重连、A 跳跃、B 短按与长按、RT 满蓄。
- `tmp/night-rain-combat-journey/report.json`：合法输入通关、两处宝箱、纸条正常／宝宝解读、捷径、首领及结尾存档。
- `tmp/night-rain-combat-assistance/report.json`：语音启停、关闭模式静默、触屏双指、持久化、异常恢复。
- `tmp/night-rain-combat-controls/report.json`：键盘、镜头、暂停／地图、手机横竖屏。

这是现有低多边形角色的程序化动作，不是外购骨骼动画；自动测试证明规则、设备处理和画面状态，真实手柄硬件与主观手感仍需真人体验。

## 弹反、防御与翻滚修订

弹反按下立刻生效，保留 0.25 秒窗口；持续按住 F／LB 则衔接架伞，松手立刻失去格挡判定，0.16 秒放下武器。弹反用收伞准备、转体拨开、回到架势三段全身动作，成功时有金色火花和短顿帧；防御用前倾架伞，格挡时向后压身，蓝色火花区分成功弹反。

格挡只覆盖正面约 132 度；每次消耗 `10 + 伤害 × 0.9` 体力，承受 15% 伤害（向上取整）。体力不足时破防 0.9 秒并承受 60% 伤害，不能以暂停取消硬直。背击与红色横扫绕过防御。举伞慢走 1.45 米／秒、回体 7／秒；受击最初 0.12 秒后可转攻击、翻滚等动作。挨打／破防恢复后必须松开重按，不能一直按住自动重新防御。

翻滚围绕腰腹旋转，压低重心、收腿抱伞、翻越与落脚起身连续过渡；只对可见模型计算贴地修正，隐藏特效不参与，避免倒置角色或武器穿地。模拟位移、0.64 秒总长与原无敌窗口不变。动作只影响渲染，不把视觉抬升误算成跳跃或跨越障碍。
