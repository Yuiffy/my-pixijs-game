# 平陆运河：合龙

建设主题的承包商桌游，1–4 人，可独自挑战、与 AI 竞争或同机交接。入口：/game/pinglu-canal。当前版本专注建设，工程合龙即结算，没有货运阶段。

灵感来自用户提供的[平陆运河影片](https://www.bilibili.com/video/BV1fYes6xEmq/)及其提到的切山、裁弯取直、土方转移、省水、动物通道和鱼道。地图、预算、工程量均为游戏抽象，不还原真实地理或工程参数。

## 一条航道，多处开工

12×9 的立体地形中有一条预定公共航道，分为 A–H 八个标段。所有未完工工地从开局即可施工，无须从起点逐格推进。山体、裁弯、回填、船闸与桥下连接段有不同成本、产出和验收条件。裁弯在本版是固定建设项目，不提供额外支线选路。

3D 沙盘随进度显示切开的山体、水道、闸室、闸门、桥面、阶梯鱼道和省水池。点击标牌选工地，拖动旋转、滚轮缩放；也可用下拉框或工地清单操作。手机采用地图与操作区纵向布局。

## 每轮三步，共同结算

最多十轮，每家公司安排三项行动，可以组成连续计划。比如山体切方取得两份土，下一步运到低地回填，第三步调度资金或建设配套。界面预览每一步的费用、土方、水量和贡献。撤回某一步时连同后续步骤一起撤回，以避免依赖失效。

公司各自拥有资金、土方、试验水、设备和营地；轮初地图公开。各方封存计划后才同时结算，AI 不读取真人已封存的计划。同机多人有交接遮挡。建设款在轮末到账，不能在计划里预支。

多人同轮合建同一工地，全部投入都计入贡献。超过剩余工程量时，工程进度封顶，固定建设款与奖励按总贡献比例分配。拥挤会稀释奖励，但不会因为后提交而失去行动。多人同时验收同一标段时平分验收奖励，各自支付自己的用水与费用。

## 工程与经营

| 行动 | 作用 |
| --- | --- |
| 普通施工 | 增加工作量和贡献，山体工程每份贡献产两份土 |
| 运土回填 | 从自己的指定堆土场取两份土，花 ¥1 换最多两份回填贡献；运输设备可提高到三份 |
| 试水验收 | 主航段完工后另需验收；基础奖励 ¥3、4 分，多人同时验收平分 |
| 投资设备 | 掘进设备提高切方与河道施工效率，运输设备提高回填效率，测量设备减少验收现金与用水 |
| 工区营地 | 参与该区施工后可投资；每级减少本区普通施工费用 ¥1，并增加两点影响力，最多两级 |
| 后勤维护／补水 | 维护立即获得 ¥4；补水增加三份试验水，上限五份 |

B 山岭段必须先建动物通道；D 船闸段需要鱼道；F 桥下段需要交通桥。配套设施完工即验收，主航段需单独试水。省水池让船闸基础试水从三份降至一份；测量设备进一步减一。每轮各公司公平获得天气对应的补水。

施工每份贡献立即增加一分工程声望。工程完工发放固定建设款（所需工作量×3+3）及该项目的奖励分，均按总贡献分配。三片工区按贡献和营地计算影响力：普通贡献每份一点，已验收项目每份两点，营地每级两点。

## 结束与计分

八个主标段全部验收后提前结束，否则第十轮结束。工程总量达到阈值不等于合龙，必须逐段验收。

- 工程声望向下取整。
- 剩余资金每 ¥3 换一分，向下取整。
- 达成公司专业目标加八分：工程、生态或土方专业。
- 每区领先者获八分，并列均分后向下取整；无人贡献则不发分。
- 全线合龙，各公司加五分。

多人比较个人总分，平分共同获胜；工程品质另行显示。合龙为 B，额外完成省水池或湿地之一为 A，两者都完成为 S。单人目标为合龙并达到 180 分。单人和多人共用规则，工程量随人数缩放。
