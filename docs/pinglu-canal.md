# 平陆运河：造山移海

当前入口：/game/pinglu-canal。当前为真实地理沙盘版；标段桌游与最初的随机河谷原型见设计历史。

## 地图依据

采用公开高程数据与 OpenStreetMap 河网，覆盖东经 108.48–109.18°、北纬 21.70–22.73°，按上北下南采样为 **48×72，共 3,456 格**。地图不随种子随机改变。

路线原型是平塘江口的郁江 / 西津库区 → 沙坪河 → 分水岭新挖段 → 旧州江 → 陆屋 / 钦江 → 青年枢纽 → 钦州城区 → 茅尾海 / 北部湾。分水岭两侧原本没有连续河道。三级枢纽自北向南为马道、企石、青年，位置取自 OSM。地形呈现内陆丘陵、谷地与南部滨海低地。

[资料、坐标、数据来源与简化范围](pinglu-geography-sources.md)记录了可复现的生成过程。游戏“真实地理”页提供来源链接、地理数据下载和紫色实际运河参考线；参考线仅显示已获取的 OSM 航段，不预挖地形，也不限定玩家最终方案。

## 比例与水位

水平格距约 1.6 km，原始 DEM 按约 5 m 一层量化，保留高低山势；镜头竖向夸张显示。船闸和航槽宽度为操作可读性放大。这里的“3 格宽、3 层水深、3 格半径”是游戏通航规则，不能当作真实工程尺度；土方以抽象施工批次计量，不换算成立方米。

公开资料说明全线水位总落差约 65 m。游戏使用 13 → 7 → 3 → 0 四个示意水级，**不是三座真实枢纽的运行水位表**。自然河流在本河段内向低地进水，三个分级边界由船闸连接。为简化水动力，分区按枢纽所在行划分。天然河宽、河床深度与海湾水深经过概化，因为这套 DEM 不是河道水下测量数据。

## 工程操作

- 爆破：本河段水面以上地块最多削低三层。
- 开挖：逐格削低一层。
- 疏浚：本河段水面以下地块最多削低两层，停止于当地水面以下三层。
- 运土：选择有库存的工地，沿干地把土运到天然低地，补齐当地田面后出现田垄。仅运土时用绿色提示可回填地块。
- 船闸：先把 3×5 格闸室基坑挖到各格设计底层，再花 ¥30 和一队建设枢纽。三座均须建成。
- 外运弃土：¥8 清走最多 64 单位土；拨款：消耗一队领取 ¥55。

单队最多施工 16 格，支持单点、两点拉线与 1 / 3 格笔刷。土方分来源保存在各公司工地，总容量 240。每次施工显示费用、土方、标高变化；爆破、运输与船舶通行有动画。

天然洼地由邻近 DEM 高差确定，保持初始地貌，不是人工预留矩形坑。复垦不能堵住闸址，也保留一条可开挖通道，避免填土后整个地图无解；此保留只限制回填，绝不提前挖出航道。

“定位航线施工缺口”选择建议航线中的待施工地块并拉近镜头。橙红斜纹表示待施工，青色粗框与十字表示当前选区。自然洼地默认不加警示描边。地段导航可直接飞到分水岭、枢纽、陆屋、钦州或海湾，点击“全图”恢复总览。

## 通航与计分

寻路分成四个不同水位的航段，以三座船闸为连接点。各段采用八航向、经过曲率采样的直线与弯道模板，沿船身扫掠范围检查所有地块。任意一座船闸未建成、基坑未挖到位、航槽不够宽或水深不足，都不能验收。船闸段的船舶动画在示意水级间升降。

最终采用最短合格航线：其中每单位实际开挖归施工者 3 分；来自这条航线、运入已整平且未淹没农田的土，归运输者额外 2 分；采用的船闸归建设者每座 40 分。未采用支线、未完成复垦、弃土均无分。相同分数以总支出较少者领先。

每人每轮三队，往返顺序轮流施工，每轮拨款 ¥24。初始资金 ¥360，单人最多 100 轮，多人最多 72 轮。首次贯通后进入最后两轮改线期；单人可立即交付，或继续优化。自由工程限单人，不限工期、资金与库存。

支持 1–4 家真人 / AI 工程局，同机交接；没有在线房间。

## 存档与实现

真实地理版存档键为 pinglu-geography-v3，旧版 pinglu-terrain-v2 不覆盖。未开工的地理版存档可更新到当前地图生成规则；已经施工的地形和进度保持原样。单人保留最近 12 次施工撤销。

terrainEngine 拥有地形、水位、施工、土层归属、物流、路径和计分。geography 提供静态数据与地理映射。TerrainScene 只负责 R3F 实例化地块、镜头、动画与输入，HUD 使用 DOM。

## 验证

scripts/verify-pinglu-geography.cjs 覆盖：DEM 格数、固定地理、枢纽南北顺序、分水岭初始干地、逐次合法付费施工、三闸必经、水位与通航水域、存档往返、全体可选洼地回填后仍有可施工路线。当前完整示例在第 31 轮、92 次行动后交付约 129.2 km 的游戏航线；该长度是压缩网格方案，不代表实际运河的测量里程。

浏览器已查看整体地形与分水岭近景，操作马道基坑定位、爆破、撤销及资料页；资金和土方随施工变化，撤销后恢复。画布为非空地形，页面日志无警告或错误。完整多人战略平衡仍需后续试玩。

本轮变更文件 ESLint、全库 pnpm run check 与 pnpm run build 顺序执行通过。生产构建使用独立输出目录，Next.js lint 保持启用；仅有其他游戏已有的未使用导入警告及浏览器数据更新提示。
