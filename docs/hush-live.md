# 嘘，TA还在播 · 第一人称3D

原始需求：扮演虚拟主播中之人的男友或女友，同居生活中在直播时拿东西、递外卖、隔壁玩三角洲并语音，也会被恋人索要亲亲抱抱，避免被观众听见。后续用户明确要求转为3D。

## 当前玩法

第一人称走进一套温暖的卡通公寓。五个固定夜晚逐步引入拿充电器、递外卖、隔墙语音、拥抱与亲吻；通关解锁种子随机加班夜，支持评分、多结局、解锁道具和成绩分享。

- WASD移动，鼠标点击画面锁定视角，或右键拖动转头；方向键也能前后走和左右转头。
- 靠近且看向物品/恋人才出现互动。拿取/摆放/开门轻按E（或屏幕按钮）即自动完成动作。拥抱3秒、亲吻1.4秒使用长按，松开可停。
- Q轻步/快走，Shift奔跑，M在恋人身边打闭麦暗号，P/Esc暂停，F全屏。
- 手机使用左摇杆移动，滑动画面转头，轻点拿取、长按亲密互动；支持同时移动和转头。
- 顶部只显示当前目标。金色标记和方向/距离帮助寻找目标；可选“跟随目标”沿实际可走路线步行，仍要自己完成操作。
- 门墙和家具具有碰撞；关门、音乐和闭麦降低观众听见的声音。房间声音带方向，关门后声音会变闷。
- 第一晚明确为拿到充电器、带回沙发放好、收工三个步骤。三星只要求最高怀疑低于25%，不要求额外抱抱。
- 第二晚后解锁棉拖鞋，第四晚后解锁隔音门条。后续夜晚三星要求最高怀疑低于25%、甜蜜至少25。

## 数据与资源

进度沿用本机 `hush-live-v1`，保留已有章节/装备解锁、身份和最佳成绩；进行中的半局不保存。分享通过复制文字与随机种子链接完成，不包含在线排行榜。

渲染使用React Three Fiber/Three.js；游戏规则、运动、碰撞与导航独立。公寓、家具、人物、手持道具由本机程序化几何构建，屏幕和木纹为本机纹理，没有外部模型依赖。角色有男女外观、转身对视、眨眼、伸手与亲密动作；下播后展示双人沙发结局。三角洲电脑屏幕显示动态报点场景。

## 运行与验证

游戏位于 `/game/hush-live`，`/demos` 有3D预览入口。

- `pnpm hush:test`：26项规则/导航/第一人称输入测试，包括多个种子的全部夜晚、家具碰撞、不穿墙与注视距离限制。
- `pnpm hush:verify`：使用系统Chrome依次运行完整3D通关、操作专项和新互动专项。默认服务 `http://127.0.0.1:3877`，用 `HUSH_BASE_URL` 覆盖；外部Playwright模块可通过 `PLAYWRIGHT_MODULE` 指定。
- `scripts/verify-hush-live.cjs` 保留为3D主验证入口的兼容别名。
- 顺序执行 `pnpm run check`、`pnpm run build`，保留Next构建内的ESLint与TypeScript检查。

3D设计与验收范围见 `docs/hush-live-3d.md`。


## 快速互动与小队报点

拿外卖0.35秒、拿充电器0.4秒，轻按一下即自动伸手拿取；放充电器0.45秒。晚饭改为放在直播桌左侧餐垫上，1秒内摆好饭盒、饮料与筷子，无需对准恋人。拿取与摆放有连续物品/手臂动画。

TA通常朝向直播屏幕，一边讲话一边偶尔偷看玩家；闭麦时讲话口型停止。送餐后部分夜晚TA会起身走近并张开手，可选择抱一下，也可继续办事。

电脑报点改为点击移动小球：低声每次+1，大声每次+2但噪声更大，达到8点完成；点空或目标超时算失误，3次失误可重试。鼠标自动释放，手机可直接点击小球，暂停会同时冻结目标和直播计时。关门、音乐、闭麦继续影响实际噪声。

长按进度使用72px深色底、实色金色环、浅色描边和百分比；拿取类动作不再要求盯着进度圈等待。专项脚本为`scripts/verify-hush-interactions.cjs`。


## 椅子与虚拟形象同步

直播椅与人物坐姿共用朝向：朝屏幕坐时椅背在身后，坐着转身时椅子一起转；起身后椅子留在桌前。屏幕形象读取实际显示的人物姿态，同步朝向、头部倾斜、嘴部开合和眨眼；转离直播摄像头时显示侧面或背面。闭麦、暂停、起身与回座均保持同步，静止时不重复绘制贴图。专项：`scripts/verify-hush-tracking.cjs`。


开关门会检查人物是否占据门板即将停留的位置；被挡住时门保持原状，并提示退到门的一侧。旧的门板重叠状态允许向外走出，仍禁止穿门、穿墙。专项验证：`scripts/verify-hush-door.cjs`。

报点小球按下即判定命中，松手不重复计分；按下样式保持中心点不变，避免通用按钮样式引起小球偏移。键盘Enter/Space仍可逐球操作。专项：`scripts/verify-hush-delta-press.cjs`。
