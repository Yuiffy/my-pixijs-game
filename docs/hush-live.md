# 嘘，TA还在播

原始需求：扮演虚拟主播中之人的男友或女友，同居生活中在直播时拿东西、递外卖、隔壁玩三角洲并语音，也会被恋人索要亲亲抱抱，避免被观众听见。设计游戏类型并实现。

选择：五晚手工设计的潜行小关卡 + 通关后种子随机加班夜。固定关卡能安排有趣的声音与亲密时机，随机夜提供分数挑战。原创成年恋人，可选择玩家和恋人的性别。没有现实主播身份设定。

视觉：奶油纸、鼠尾草家具、珊瑚红直播灯的温暖俯视小公寓。房间作为主视觉，状态简明，恋爱对白与弹幕承担叙事。
内容：标题与夜晚选择 → 公寓与操作 → 本晚任务和弹幕 → 结局、分享、本机解锁。
动效：轻盈角色步伐、传到麦克风的声音波纹、直播音乐节拍与亲密爱心。

技术：沿用仓库轻量小游戏的 Canvas2D + React DOM 控件；纯 TypeScript 模拟独立于绘制，确定性时间接口用于测试。无需新增引擎或远程资源。

规则：点击地点自动走路，WASD/方向键手动走。Q 切换轻步，Shift 奔跑。靠近目标按住 E 做事；松开暂停。音乐窗口、隔墙与关门减弱声音；直播间地板会响。靠近恋人按 M 眼神暗号临时闭麦，冷却期间不能重复。亲密互动必须自己按住确认。任务完成后回沙发收工。怀疑到 100 或计时结束失败，可重试。

五晚：拿回充电器；外卖到了；隔壁三角洲；直播中的抱抱；所有事项的纪念日。第二晚后解锁棉拖鞋，第四晚后解锁隔音门条。每晚保存最佳分数/星数；随机夜保存最佳分数，能复制带种子的挑战文案和链接。

验收：合法输入完成五晚与多个随机种子；失败/重试/暂停/后台停表；墙碰撞与门衰减；音乐和闭麦的因果对比；亲吻/拥抱与两组性别；键盘/点击/触屏；刷新进度、坏档、无法存储降级；结局分享；桌面和手机截图、文本状态和控制台交叉核对；ESLint、check、build。

## 运行与验证

- 游戏路由：`/game/hush-live`，小游戏实验室 `/demos` 有入口。
- `pnpm hush:test`：规则测试，包括4种子×6夜的合法操作通关。
- `pnpm hush:verify`：使用安装的 Chrome 验证完整流程。默认服务 `http://127.0.0.1:3877`，可用 `HUSH_BASE_URL` 覆盖。Playwright 不在项目依赖中时，用 `PLAYWRIGHT_MODULE` 指定本机模块路径。
- `pnpm run check` 后顺序执行 `pnpm run build`，保留 Next 内的 ESLint 与 TypeScript 检查。
- 存档只保存已完成夜晚的解锁、最佳成绩和身份选择，不保存进行中的半局。分数分享是复制文字与挑战链接，不是在线排行榜。
- 加班夜的种子控制任务组合、音乐相位和时间预算。相同种子可重玩；下一夜会改变种子。
