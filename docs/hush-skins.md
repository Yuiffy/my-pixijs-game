# 主播皮肤

准备页的“今晚和谁一起？”提供主播酱、岁己、七海三套外观。默认主播酱保留原本的她／他选择；两套角色皮肤使用“她”。选择立即保存，重玩、下一晚和刷新继续沿用。

## 造型

- 主播酱：暖棕发、玫瑰毛衣、浅色耳机。
- 岁己：银色分节双马尾、猫耳帽、细金色光环、红瞳与紫色外套。参考仓库 `public/images/materials/岁己SUI小猫帽带饼干岁紫色外套双马尾.png` 和 `public/images/wiki/sui_charactor_half_body.png`。
- 七海：棕色长发、金瞳、双金发夹与交叉发夹、深色鲨鱼元素外套和蓝色领结。参考仓库 `public/images/livers/nana7mi.png`。

这是适配当前低多边形公寓风格的程序化Q版服装，不是原版Live2D或写实模型。配饰挂在已有头部与身体动画节点；继续复用转身、讲话、眨眼、坐下、起身和拥抱，不新增动画时钟或模型下载。

直播屏幕的虚拟形象共享皮肤配色和标志性配饰，继续跟随角色朝向、嘴型和眨眼。游戏目标、开门、微信发送者、下播剧情、结果回忆与直播间名称读取统一皮肤配置；只有岁己皮肤显示岁己名称。微信状态用partner角色标记，不存硬编码昵称。

## 存档与验证

v1存档增加skin字段。旧档缺失或未知值回退host，不清空关卡、分数或奖励；已有三种合法值正常恢复。

`pnpm hush:test` 覆盖存档兼容以及三皮肤四剧情结尾的称呼一致性。`scripts/verify-hush-skins.cjs` 在隐藏静音系统Chrome中验证选择、旧档分数保留、刷新、模型和屏幕、嘴型／眨眼同步、整晚通关、重玩及320px触屏入口。
