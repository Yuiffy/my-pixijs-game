## 关卡结构

旧旅馆、中庭、金塔屋脊、铁伞与晚餐构成第一段。吃饭后的界面改为「夜市小憩」，继续探索进入北部主线。只有吃过晚餐、击败长夜司灯并主动敲响王寺归夜钟，才完成第一关；随后仍能自由探索。

北部主线：夜市北口 → 香料水街 → 织坊下城 → 染布长廊 → 双象门楼 → 西城垛道 → 金雨高墙 → 雨声藏经院 → 千灯朝圣桥 → 王寺天阶 → 雨冠大殿 → 归夜钟。

- 下城以榕树和暖灯为安全落脚处；街道、染布、檐棚与高处门楼区分各段。
- 双象卫长掉落象纹铜印，打开藏经院的铜门。高墙西侧的蓄水院是可选回环，藏有第二次药瓶容量提升。
- 藏经院提供屋顶、书架与柱廊的室内段，朝圣桥把王寺作为远景目标；末段上升到 24 米的大殿。
- 兰花院、风雨望楼和经院钱匣提供支路奖励；西寺、潮汐港与七海／阿梓支线继续开放。

新增 34 段可行走地面和 21 名敌人，全世界合计 68 段地面、34 名敌人。地面分段是碰撞和路网单元，不代表 68 个独立区域。自动通关路径包含北部支路、开门和补给折返，北部寻路折线累计约 1.26 公里；这是脚本路径长度，不能换算为普通玩家的首通时长。

四条新增近路必须从内部开启，死亡、休息和刷新均保留。以下使用同一寻路器、同一人物半径和相同起终点对比，单位为米：

藏经院铜门属于持印推进门，不算近路。加上旧侧门、西寺水门与港区长桥，HUD 共计七条近路。

新增榕树、经院、王寺三处雨灯，总计四处。第一次点火只记录归灯，下一次交互免费补给并重生普通敌人；首领保持已击败。地图中的「雨灯行旅」只能从安全、已点亮的灯旁出发，目的地必须已经点亮，保留血量、体力、药瓶和敌人状态。脱离卡死同样不提供免费补给。

基础药瓶为三瓶，西寺刻露瓶和水院莲纹露瓶可按任意顺序取得，最终上限五瓶；行装强化上限提高到十级。

## 战斗与引导

长枪客用窄角突刺与迟刺强调侧移和释放时机。双象卫长有突刺、延迟重砸和不可弹反的横扫。最终首领「长夜司灯 · 雨冠」有两阶段：半血后突刺和横扫加快，落灯重击反而延迟；横扫可跳过或闪避，不能弹反。已有蓄力、空中攻击、破架处决、防御、治疗打断与丢钱机制继续使用。

宝宝模式按下城雨灯、染布留言、卫长、铜门、经院雨灯、王寺、最终首领和钟台更新目标；已读留言不会反复成为主线终点。地图提供全城、旧城与潮港、织坊与高墙、藏经院与王寺四个视图及「定位自己」，标出方向、灯、门与遗落钱袋。

世界存档升级到 v5，v1–v4 按原顺序迁移后补入新区敌人和进度，保留旧生命、剩余药瓶与击杀；`chapterGates`、新归灯和章节结局进入验证。铜门依赖卫长击败记录，结局依赖雨冠与晚餐；拒绝未知机关、重复机关和伪造的完成状态。仍使用浏览器 localStorage，不是账号云存档。
