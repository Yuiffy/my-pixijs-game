# 平陆运河：合龙——改版决策

2026-09-27，已实现。完整玩法见 [玩法说明](pinglu-canal.md)。旧版留档提交：d1405d3。

## 核心体验

各家公司在不同工地同时开工，把不连续的施工成果合成一条公共运河。每家公司都想从工程中赚取更多收益，又必须面对其他公司的投入改变工地价值、区域优势与结束时机。

本版按用户决定取消货运阶段，把资源、设备和地图建设做成完整的一局。建设回报、资金效率和区域竞争承担主要得分动机。

## 对旧版反馈的回应

| 反馈 | 当前处理 |
| --- | --- |
| 行动空间少，顺位决定收益 | 每轮三个连续行动，共同结算；普通工地没有先到先得的名额；合建和共同验收均按公开规则分配 |
| 格子少，地图关系弱 | 108 格地形承载八个主标段和五项配套；切方土来自具体工地，回填有具体去处，三区争承包影响力 |
| 每人挖一条支线不合理 | 固定一条主航道，任何未完成标段都可同时开工，最终逐段验收合龙 |
| 单纯点建设缺少组合 | 切方→运土、设备→高效施工、施工→营地→降本、配套→验收均可在三步计划中衔接 |
| 生态只是装饰 | 动物通道、鱼道、交通桥是相应标段验收前置；省水池改变试水需求，湿地与省水影响联合评级 |
| 希望看到精致建设过程 | 使用真实 3D 地形、船闸、桥梁、施工机械与阶段性几何变化，可旋转缩放 |

区域竞争采用施工贡献与营地影响力。没有攻击或拆除，每区八分只是建设之外的一条竞争线。三类设备和专业目标提供不同经营方向；AI 从公开局面搜索三步组合，使用相同规则与资源。

## 有意控制的范围

地图目前固定，裁弯是预设工程，不支持自由画航线。108 格用于表达地形与设施，实际决策单位是工程项目，避免把增加格子变成重复点击。多人当前是同机交接，未实现网络房间。

当前版本没有后续航运收益。省水只影响建设试水，区域优势只在终局计分；若未来独立做运输游戏，可以继承合龙结果，但不向本版追加新的运营阶段。

## 下一轮试玩要回答的问题

1. 同时合建的回报稀释是否足以促使玩家分工，还是容易反复扎堆。
2. 设备与营地能否在剩余工期内回本，不同人数下是否都值得投资。
3. 玩家能否从预览和结算报告理解自己的得分，而不靠阅读规则公式。
4. 最后一两轮是否有有趣的合龙时机选择，或只剩重复验收与后勤。
5. 工程、生态、土方专业的机会是否足够接近；单人 180 分目标是否适合新玩家。

规则与浏览器验证已经通过；战略平衡仍应由真人试玩继续调整。


## 2026-09-27 第二次重做：从标段投资到地形争线

试玩反馈是标段计数仍缺少直观操作和空间策略。因此当前页面已经改为“造山移海”，上文记录的合龙版仅作设计历史。

新版让每次动作真的改变地形，把策略问题放到可见的空间里：沿已有河湾更省工程量，切山的短线能使旧投资落空；疏浚和拓宽影响真实船身通过；土必须从具体工地装车、经陆路运到沟壑。先完成一条长线的人可以启动结束倒计时，逼迫修短线的人权衡是否赶得上。

最终只采用最短合格航线，贡献按实际使用的土层归属计分，不再给所有开挖发保底工程分。复垦奖励追溯来源，来源没被采用也不计分。以此约束无关乱挖和独自刷农田。

工程即时落地，用往返顺序和开放地块缓解顺位影响；保留同机、AI 和单人，并额外提供自由工程。主要范围取舍：固定同一水位、限制回填在天然沟壑，暂不加入船闸水位与堵河破坏。规则和实现以 [当前说明](pinglu-canal.md) 为准。


### 地形反馈：让填壑造田成为可见的改造

去掉两片规则的平底矩形坑，用同一连续高度场生成峰丛、坡脚和扭曲边缘的天然洼地。天然谷底保留高差和植被，运土逐格补齐到当地田面后才出现规则田垄。不同谷地可以采用不同田面高度，运输、AI 和计分共用该目标。旧存档仍沿用原地形和原目标，新地图使用新生成器。

橙红斜纹表示建议航线上的施工缺口，青色粗框与十字表示选区。天然洼地不默认描边，只在运土时提供绿色可填提示，避免把自然地貌说成不达标工程。


### 第三次地形重做：真实区域地理

2026-09-27 依据新华社、中国青年网与公开 DEM / OSM 数据，把同水位随机河谷替换成 48×72 格的真实区域沙盘。保持郁江、沙坪河、分水岭、旧州江、钦江和海湾的空间关系；按坐标放置马道、企石、青年枢纽，并把分级水位、闸室基坑和建闸纳入通航判定。航槽宽度与水位做明确的游戏化概化，数据与资料可从游戏内查看。详见 [地理来源](pinglu-geography-sources.md)。
