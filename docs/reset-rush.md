# RESET / 开蹬！

一个关于「趁重置之前，把额度变成作品」的开发者德式跑分桌游。路由 `/game/reset-rush`。1 名真人与 3 位不同策略 AI，42 天标准局或 21 天快速局。游戏内的美元、模型、会员、tibo 台词和概率都是虚构设定，不涉及真实账号或支付。

## 核心体验

不是赌到免费额度就赢，而是把不可储存的行动、按账号独立刷新的额度、会过期的银行券，转换成能够留下来的作品。事件先给公共信号，玩家有一天时间反应，夜间揭晓；惊喜直送则在早晨立刻发生，没有事后反悔窗口。

每个游戏日：自然重置/过期处理 → 早间事件 → 每人轮流做三次行动 → 夜间赠礼判定 → 每周收入。每天轮换先手。公共项目池即时补牌，不出现同名项目，每天最旧一张离场换新，避免冷门合同长期堵塞项目池。AI 在每次玩家行动后行动，不能偷看随机数或未来牌序。没有实时倒计时，随时可离开，刷新保留同一随机结果。

## 经济与账号

所有人有 $500 启动资金。真人可以从 $100 单号、$200 双号或 $20 单号开局；购买后留下余额。每个初始账号各赠 1 张 D31 过期银行券，新购账号不赠券。最多 3 账号、2 个在制项目。

| 套餐 | 游戏内价格 | 每周额度 |
| --- | ---: | ---: |
| Plus | $20 | 24 |
| Pro 100 | $100 | 90 |
| Pro 200 | $200 | 180 |

- 新号的自然重置日在购买日 +7，此后每隔 7 天。订阅有效 30 天，到期禁用付费模型、赠礼和自然补额；Luna 不受影响。
- 到期后原价续费，花 1 行动，获得 30 天订阅和满额，重开 7 天周期。有效期内不可用续费反复刷额度。
- 升级收差价，只增加新旧容量之差，不改变两个日期。
- 直接 reset：所有有效账号补满；旧余额不叠加；自然重置日不变。
- Banked reset：每个有效账号增加 1 张券，绑定账号，发券日 +30 的早晨过期，上限 3 张，溢出丢弃。
- 用券不消耗行动，但必须在自己的行动阶段，每个账号每天限 1 张。使用最早到期券，补满而不叠加，不改变自然重置日；满额时禁止误用。
- 现金来源：手写外包每行动 +$25，每周固定工资 $35，发布公司合同的回款，个人项目每个每周 +$15。

双账号可以在不同日期买入，构成错开的 7 天时钟。先用临近自然重置的号，或者集中耗空离自然恢复还远的号并用券，都是有效策略。重置收益按实际补回额度记录；银行券和直接 reset 同日相撞会在夜间明确提示，不凭空扣分。

## 行动与开发

开发、测试、接单、开通/升级/续费、外包、放弃项目各用 1 行动。选择账号、项目和模型免费。发布自动发生：进度达到要求且 bug 为零。

| 模型 | 额度 | 进度 | Bug |
| --- | ---: | ---: | ---: |
| Luna | 0 | 2 | 0 |
| Sol | 4 | 6 | 0 |
| Astra | 9 | 11 | 0 |
| Ultra | 24 | 20 | 0 |
| Ultra + Turbo | 48 | 38 | +1 |

测试不花额度，修复 2 bug、补 2 进度。开源加成只加付费模型的产出，最多 +3，Luna 始终弱但保证可继续游玩。Turbo 快但低效，接近 reset 时可以先写满，再在缺额度的日子测试。Turbo 快乐日消耗降到 36。

四类项目：碉游高声望；个人项目建立收入；开源项目建立效率；公司项目高现金低声望，接单日起 8 天交付，到期撤单 −3 VP。主动放弃 −2 VP 与 1 行动，不能无成本清空坏合同。

## 消息与随机性

开局前四天固定教学节奏：45% 谜语、100% 预告、平静、早晨发银行券。之后从 12 张事件牌洗牌抽取，用完重洗。显示的概率就是规则概率，无暗改保底或按玩家状态动态出牌。

夜间先按消息概率判断送不送，再从「4 张直接 reset +2 张银行券」牌堆抽取，不放回，抽空重洗。界面显示剩余构成。消息说必送，也未必直接补额，这给了「先狂蹬，再用银行券」的风险。早晨突发 reset 不额外消耗夜间重置牌。

## 跑分

总分 = 发布声望（含奖项）+ 多样性 + 现金 + 使用额度。

- 首个发布碉游 +5，首个发布三类作品 +6，首个消耗 500 额度 +5。
- 发布四类作品 +12；三类 +5；不累加。
- 每 $100 现金 +1，最多 10；每用 120 额度 +1，最多 10。
- 在制作品不计分，同分共享名次。资源分封顶，防止刷额度取代开发。

## 实现与验证

规则在 `src/components/resetRush/engine.ts`，DOM 卡牌与 SVG 作品插图在 `ResetRush.tsx`，局部 CSS 不污染其他游戏。文字密集的桌游选用 DOM 便于键盘和手机操作，没有引入额外引擎依赖。`render_game_to_text()` 暴露公共状态；`advanceTime()` 不推进离散回合。存档键 `reset-rush-v1`。

- 规则：`node --test scripts/tests/reset-rush.test.mjs`。
- 浏览器：`node scripts/verify-reset-rush.cjs`，可用 `RESET_BASE_URL` 指定服务。
- 源码：`pnpm exec eslint src/components/resetRush/engine.ts src/components/resetRush/ResetRush.tsx src/app/game/reset-rush/page.tsx`。
- 全仓门禁：顺序运行 `pnpm run check`、`pnpm run build`，保持构建 ESLint 开启。

后续扩展可考虑真人热座、自选公共赛季目标和更长的赛事模式。首版保留确定规则，先据真人试玩检验局长、套餐与模型取舍，再扩展。

最终验证：规则 15/15（72 局、3024 次夜间结算）；系统 Chrome 真实按钮完成 42 天、390/320 触屏、正常/银行赠礼、续费、三账号/升级/弃单/外包、零额 Luna、刷新/坏档/禁存储及全部计分。截图逐张目检，控制台/页面错误为空。隔离副本顺序 `check` 与生产 `build` 通过，主目录对应源文件 SHA256 一致。预览 `http://127.0.0.1:3888/game/reset-rush`。
