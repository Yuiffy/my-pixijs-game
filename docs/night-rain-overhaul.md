# 雨夜寻味 · 角色、战斗与立体箱庭大型更新

2026-10-13。八项功能已实现并完成本轮验收；证据和限制见文末。

## 范围与实现

沿用原有连续世界、章节推进和战斗模拟，完成首领重排、差异化机制、地形预警、近路、粉丝小兵、角色领地、角色装备和立体支路。本轮改动与第三关一起纳入用户授权的阶段 commit；未推送。早期设计中的“双跃袭／二阶段换唱段”未纳入本次：栞栞采用单次真实跃袭，阿梓采用可打断的治疗与扇形火弹唱段；不把设计草案冒充已交付机制。

## 调研与取舍

已于 2026-10-13 实际读取的公开来源（摘录保存在 `tmp/night-overhaul-research/`）：

- [《艾尔登法环》官方入门指南](https://en.bandainamcoent.eu/elden-ring/news/elden-ring-starter-guide-tips-know-playing-the-game)：跳跃／蓄力攻击、防御反击、赐福指引和地图移动。应用：明确主路灯光、可以跳过的低位招式、重击与防御的不同回报。
- [《艾尔登法环》及黄金树幽影介绍](https://www.playstation.com/en-us/games/elden-ring/)：探索、不同武器与技能、地下城和各自有动机的人物。应用：支路奖励改变打法，领地环境说明守门理由。
- [《只狼》官方商店介绍](https://www.playstation.com/en-us/games/sekiro-shadows-die-twice/)：相连世界、立体移动、潜入、独特敌人和支路探索。应用：从高处提前观察敌人、跳跃／侧闪／弹反分工；不给每个危险招都套同一个跳跃答案。
- [《匹诺曹的谎言》官方介绍](https://www.playstation.com/en-us/games/lies-of-p/)：刀身／握柄与 Legion Arms 的不同能力、叙事选择。应用：角色武器明确速度、距离、破架代价与独有机制；不为凑系统新增大规模组合制造菜单。

上述来源支持方向，不代表它们给出了本项目的精确关卡参数。下面的时长、近路收益和出招机制是本次设计，必须通过游戏测试确认。未将玩家直播传闻当作新调查事实；七海最近玩 MC 来自用户提供的背景，作为方块建造领地的创作依据。

本站能力依据为 `src/components/autoChessGame/core/data/units.ts`；角色身份由 `bossRoster.ts` 与地点／存档 ID 分离。关卡血量和任务职责留在原地点，避免把后期数值搬给首战。

新增 `bossCombat.ts`／`bossFields.ts`／`BossFieldView.tsx`。持续技能具备明确的警告、有效期、主人和取消条件；死亡、休息、旅行与脱战清理。弹体保存发射时的弹反／跳跃属性，不随施法者换招而变化。时停不会阻止自己的结束时钟；跃袭改变实际位置并有空中近战高度判断。普通攻击仍保留刺、挥、重击，不要求每一刀都变成特效技能。效果使用轻量几何模型，龙息仍为着色弹体，并非新增骨骼龙动画。

## 预警与视觉

`GroundWarningView.tsx`／`groundWarning.ts` 逐段采样可达楼层并裁切悬空边缘、实体障碍和不相干楼层；补采样三角形内部桥阶交界、共享顶点抬升，楼梯预留 0.22m 净空。区域和扩张环复用该地形网格。保留正常深度遮挡，人物和墙体仍可遮挡部分区域；不启用 `preserveDrawingBuffer` 或穿墙预警。

缓冲预分配，渲染器有界复用，弹体上限 24。技能图形与实际危险形状区分；射线在身体高度，低扫／震波才允许跳跃。原有未使用的 `BossSignatures.tsx` 保留为旧文件，实际世界不再挂载它。

## 近路与立体支路

七个已有门改用靠近抵达路径的远程绞盘：夜市侧门、港口归灯门、织工门、档案门、王庭门、断崖门、苇桥门。原门的位置、通行碰撞和门内手闩仍可使用；机关必须从合法一侧打开。其余机关门保留原任务／谜题锁，未用全部自动开门替代探索。

导航路径测得额外开机关往返：夜市 70.3m → 7.0m，港口 41.6m → 1.0m。其余五处验证开门、保存、死亡后状态，未伪称逐门测得相同的节约数值。

七海庭院新增浅色／金色方块屋、阶梯立面、十字镐架、脆鲨与暖灯主路。地面正路通水闸；施工图、宝光与侧方路牌提示可选屋顶路。路线为 2m 地面 → 5m 前檐 → 冲刺跨过 2m 缺口到 5.8m 上檐 → 4.2m 落台 → 2m 地面；成功获得试作矿镐，失败可回下层重试。增加镐庭雨灯，首次点亮不暗中补给。浏览器实测后将挡住落点的路牌移到屋顶侧边。

修复走落边缘时水平空中速度被清零的问题，让连续下落能正常离开台沿。导航不会直接把地面玩家引向不可步行到达的屋顶奖励；引向施工图说明分支。回灯路径沿院边转过房屋，非穿墙直线。
