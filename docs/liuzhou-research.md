# 柳州GTA · 初始街区研究

入口 `/game/liuzhou`。用户目标是以柳州真实世界为地图、可步行乱逛/骑车/驾车/与路人互动的开放式 3D 游戏，主要角色包括岁己、栞栞、米汀、七海。这仍是持续开发目标；当前两章提供核心交通与街区叙事，不能视作完整 GTA 规模游戏或精确实景复刻。

## 地理资料与取舍（2026-10-23）

- **OpenStreetMap API 实际下载**：`https://api.openstreetmap.org/api/0.6/map?bbox=109.408,24.307,109.418,24.318`。原始 XML 留在本机 `tmp/liuzhou/map.osm`，导入脚本 `scripts/import-liuzhou-map.ps1`。保留159条ways的OSM ID、名称、道路/建筑/桥梁类型及完整节点折线，不使用远程瓦片或商业地图截图。
- 模拟原点 WGS84 `(109.41225,24.31415)`，x 向东、z 向南，单位米。固定纬度局部投影。文惠桥 OSM ways `195918702`、`583908579` 分别约587m、592m，独立渲染；道路包括滨江东路、曙光东路、罗池路、文惠路、荣军路等。封闭可玩区域约990×1180m，包含两岸及连接桥梁。
- **广西新闻网/柳州1号航拍**：`https://v.gxnews.com.cn/a/21886253`，查看图 `https://static.gxrb.com.cn/image/uploadpic/20251221/2cde8cc4c35e94565e638bee122fc623.jpeg`，用来确认并行桥面、三跨红色拱肋、青绿河水和远山层次。图片只作本地参考，未放进游戏或宣传图。
- **广西新闻网/柳州1号城楼照片**：`https://v.gxnews.com.cn/a/21963841`，查看图 `https://static.gxrb.com.cn/image/uploadpic/20260630/79629a7058ece8c01d93522e381b430a.jpg`。参考双层重檐、灰瓦翘角、红木构架、青砖台基和拱券；当前模型为程序化简化重建，未追求测绘精度。
- **广西新闻网旧桥与新桥工程报道**：`https://gxxwfb.gxnews.com.cn/article.v2019.php?id=6997772`，核对桥梁北接文惠路、南接荣军路，以及并行姐妹桥和约587米长度。历史报道只用于结构参考，不用于声称当前施工或通行状态。
- OSM 的道路中心线和已绘建筑轮廓是真实数据。建筑高度、缺失沿街体量、店铺、岸线（水系中心线约153m半宽）、山体、树木和街道设施均为近似或虚构填充。当前162栋建筑体量不代表162栋逐一实测建筑。城楼参考《城中文史》第十四辑索引摘录中的五开间、面阔16.44米和进深10.41米；台基、拱高、台阶及具体位置仍是近似，没有工程级校核。来源与限制见 `docs/liuzhou-dongmen.md`。
- 没有搬运街景照片、商业地图瓦片或他人建筑模型。程序化纹理、模型和合成环境音由本项目生成。角色参考沿用站内 `public/images/livers/{sui,shiori,nagisa,nana7mi}.png`，已逐一查看原图后保留帽形、发色、辫子、猫耳/耳机和服装配色。

## 当前可玩内容

- React Three Fiber/Three.js 场景；固定60Hz独立模拟；Rapier角色/建筑碰撞；相机跟随、捕获鼠标后自由转动、缩放、贴墙收近。Esc释放鼠标并暂停，Alt临时显示鼠标；触屏与捕获失败时保留拖动方式。
- 东门城楼移回导入历史地块附近，可穿过真实拱洞、沿西侧31级台阶登平台观景、跳跃并刷新续玩。模型与碰撞、镜头和存档恢复共用实体定义，仍是近似简化重建。
- WASD/方向键步行；Shift跑步；空格跳跃。骑车/开车时W/S油门倒车、A/D转向、空格刹车；停稳E上下车。H车铃/鸣笛，附近NPC回头。桥边沿护栏滑动，避免落水及硬卡死。
- 1–4四角色；9位NPC（3位伙伴、粉店阿姨及5位市民），部分巡游、近距离交谈。
- 第一章六步骤：栞栞约定→骑车取粉→交给米汀→开车往南岸找七海装音箱→北岸步行采样→东门会合结局。剧情推进依赖真实累计骑行/驾车里程。完成后可继续自由逛街。
- M地图，J手账，P地标收录，C镜头归正，Esc暂停；触屏方向键、互动、跳跃/刹车、拖动视角。任务、角色、停车位置、手账及里程自动存本机，失焦暂停。
- 本地合成流水、脚步、发动机、车铃/喇叭音；右上角♪静音。不使用TTS。
- 七辆街区车辆沿三条闭合路线行驶，覆盖罗池路/中山东路/培新路/曙光东路和文惠双桥—南岸。按道路几何偏移车道、转弯减速、车距排队、路口优先和行人/停放车辆让行；障碍移开后继续行驶，暂停及交谈时冻结。地图显示车流位置。车流是游戏编排，不代表实际单行方向、交通管制或实测车况；这些车辆目前不能接管驾驶。
- 自行车车轮与踏步、汽车车轮和前轮转向由实际行驶距离/转向驱动，刹车灯随制动亮起。读取旧存档时保留玩家与停车位置，环境车流避开恢复位置重新生成，不在游玩中传送车辆。
- 已绘建筑按原始多边形挤出，凹形建筑保留庭院，碰撞按三角棱柱分解；不再让轴对齐包围盒侵入街道。建筑高度和填充建筑仍然近似。镜头沿建筑轮廓和挑檐收近，避免穿过实体立面。
- 主线取餐后，回曙光东路找阿姨可接「邻里送餐」：叔叔、游客、买菜居民轮流点餐。每单 ¥12，普通餐篮在90秒活跃游戏时间内送到另加 ¥6；没有失败倒计时，凉了仍有基础报酬。¥32买保温餐篮后永久延长至150秒，正在送的订单也生效。步行、骑车、驾车都能送；收餐人是青色餐盒标记，最后下车交谈。可在粉店取消，无报酬。餐盒随身/载具携带，升级后变为青绿色。
- 对话最后一页点击或按数字选接单/购买/取消；E只继续或收起，避免连按E误花钱。交谈和暂停冻结热气。手账显示送餐单数、保温篮与最近收据；接单、购买、取消和收餐结算立即保存。
- 主线取餐费与章末奖励在对话读完时同任务阶段一起保存，修复中途重载重复扣款/领奖。送餐报酬、完成计数、收据和订单清除同次保存；旧v1存档补入空活动记录，不重算或回收旧余额。活动时间只计前台有效模拟，刷新恢复；本地存档不提供跨标签页或手改存储的服务端防作弊保证。
- 镜头使用实际墙体和挑檐高度检查，不把挑檐下方的整片空间当成墙。自由视角遇障碍只沿指定方向收近，清障后平滑拉远，保持输入yaw不变；修复旧相邻开阔视角搜索导致首次遮挡自动转向的问题。详见 `docs/liuzhou-camera.md`。
- 首章后找栞栞开启第二章「把今天留给明天」，在粉店外、文惠桥北侧空地和金沙角附近任意顺序取得三段声音片段。下车站稳六秒录好；移动重新采样、近处行车声暂缓但保留进度、走远收起，录好的片段立即保存。不申请麦克风，不录真实音频。
- 集齐找米汀选择街巷/江水先开口的两种编排，再请七海启动28秒江边放映。东门场景新增幕布、灯架、音箱、放映机、四段程序绘制插画、伙伴动作与字幕；原创合成短旋律通过音箱HRTF定位，听者为实际镜头。可暂停、暂离、刷新后续看或完成后重看，首次+¥28与完成标记同时保存，重看不重复发放。观演期间冻结送餐热气。详见 `docs/liuzhou-evening.md`。

## 验证与后续

规则：`node --test scripts/tests/liuzhou.test.mjs`。安装版静音Chrome：`node scripts/verify-liuzhou.cjs`；可设置 `LIUZHOU_BASE_URL`、`LIUZHOU_QA_DIR`。默认无头运行，全部测试上下文在加载前模拟Pointer Lock，禁止原生系统捕获或移动用户鼠标；桌面和手机分支共用隔离入口。`LIUZHOU_SMOKE=1`仅启动检查。浏览器测试路线规划器只发出正常步行、转向、油门、刹车及E操作，不改坐标、里程或任务阶段。测试钩子只在 `?test=1`提供；文字状态随时可通过 `window.render_game_to_text()`检查。

车流与建筑专项：`node --test scripts/tests/liuzhou-traffic.test.mjs`；`node scripts/verify-liuzhou-traffic.cjs`。包含逐米检查路线与建筑/河道、多车八分钟连续行驶、行人刹停/恢复、暂停、旧档生成避让，以及普通输入步行进入凹形庭院、接近实体墙、驾驶刹车灯与骑行动作。测试导航在车辆阻挡时会用正常倒车输入退让再规划，不修改位置或车流。

送餐/结算/镜头规则：`node --test scripts/tests/liuzhou-life.test.mjs`。设 `LIUZHOU_LIFE=1` 后运行 `node scripts/verify-liuzhou.cjs`，在普通输入完整主线后继续三单、保温篮、迟到、取消、主线及收餐对话中途重载、手机横竖屏接单/取消；手机恢复的是通过正常输入获得的存档。测试等待使用固定步进推进，未修改订单或位置。`scripts/lib/liuzhou-life-playtest.cjs`只是测试流程；规则仍在独立的 `simulation.ts`、`life.ts`、`camera.ts`。

第二章规则：`node --test scripts/tests/liuzhou-evening.test.mjs`；设置 `LIUZHOU_EVENING=1` 后运行相同浏览器脚本，先正常完成首章再验证采样/编排/放映/续看/奖励幂等与手机字幕。`LIUZHOU_LIFE=1` 可同时回归三单送餐。新流程和证据要求见 `docs/liuzhou-evening.md`。

继续工作：提高真实街巷与地标建模精度、补真实建筑高度/立面、丰富载具和人物动画、扩展交通路网与NPC日程、让运送与采样成为更有变化的系统、延伸主线及自由活动。当前没有室内、警察/追逐、战斗、机动车损坏或成熟交通系统；简单优先/排队不等于完整信号灯、交通法规与绕障寻路。道路被玩家停车堵住时会排队，需要移车或绕行。手机验证是Chrome设备模拟，仍需真机试玩和帧率测量。
