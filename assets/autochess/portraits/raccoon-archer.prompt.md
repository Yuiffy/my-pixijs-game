# 浣熊射手：原创头像生成规范

## 角色定位

- 单位 ID：`gale_archer`
- 公开名：浣熊射手
- 类型：风元素远程输出、拟兽化巡林者
- 目标：自走棋内可在 22–74 px 显示的独立透明角色精灵。

## 提交给图片模型的提示词

```text
Original chibi hand-drawn game character sprite for a tactical auto-battler: an anthropomorphic raccoon ranger archer, moss-green short cloak with warm ivory lining, teal wind-energy short bow, fluffy ringed tail, three-quarter facing pose, alert friendly expression, compact readable silhouette, clean cel-shaded brushwork, tactical fantasy color palette, isolated centered character with a fully transparent background. The full body and bow must fit within the canvas with 8–12% transparent padding on every side. No text, logo, watermark, decorative frame, circle, UI, scenery, or ground shadow. Create an entirely original design; do not depict, reference, imitate, or resemble any real person, streamer, VTuber, existing anime/game character, recognizable outfit, hairstyle, insignia, or copyrighted character.
```

## 审核清单

在把候选图交给处理脚本前，人工逐项确认：

1. 没有真人、主播、VTuber 或已有角色的可识别脸部、发型、服装、徽记或道具。
2. 没有文字、水印、签名、边框、圆框、场景背景或地面阴影。
3. 弓、浣熊耳朵和环纹尾巴在缩小图中仍构成清晰轮廓。
4. 主体完整位于画布内，四周保留透明安全边距。
5. 调色与本单位的苔绿（`#245e4e`）和青绿（`#7ef0bb`）相容，但不依赖原角色的配色或服装。
