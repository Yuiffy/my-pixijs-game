These SIL Open Font License fonts match the typefaces used by
https://ikura1.github.io/uwaki-hantei/ and are served locally to avoid runtime
dependencies on Google Fonts.

- Dela Gothic One 400: Google Fonts text subset for the Chinese headings.
- Archivo 800 and 900: Google Fonts text subsets for numbers and progress labels.
- Zen Maru Gothic 500, 700 and 900: Google Fonts text subsets for this questionnaire.

Characters absent from the original Japanese typefaces use system Chinese fallbacks.
When adding copy, extend the subsets or preserve those fallbacks.
Sources: https://github.com/google/fonts/tree/main/ofl/delagothicone,
https://github.com/google/fonts/tree/main/ofl/archivo,
https://github.com/google/fonts/tree/main/ofl/zenmarugothic.
