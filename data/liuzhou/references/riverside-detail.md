# 柳堤沿江步道细节与后续梯道构建

2026-10-25，本批沿用项目已归档的 OSM 原件，没有使用申请中的三维资料。真实来源为柳堤游园 relation **21015274** 和河岸人行道 way **1524324802**，轴线与原始标签完整保留在 `riverside-detail-layout.json` 的 `sourcePath` 中；生成器同时保存上游公园布局和城市底图 SHA-256。坐标换算、高程基准与原件归档方式沿用 `data/liuzhou/README.md`。

新增栏杆、休息点、长椅、垃圾桶和铺装都是**明确标注的估算设施**，不是实测现状，也不是东门城楼、文惠桥折返梯道或金沙角船形平台的复原。源轴线没有挪动，未改动 DEM、河岸边界和现有道路标高。

## 本批规则

- 在源步道 chainage 284–1156 米段，临江侧退让约 3.2 米，生成192段候选短栏杆；运行时跳过湿地、无真实干地支撑、或两端/中点高差超过0.52米的段，当前呈现185段。
- 在陆侧生成8处休息点，每处约6.8×4.4米，并用2.8米宽短通路接源步道。区域限制在源公园内，避开现有源建筑、其他道路/梯道、河道及已有候选树。实际铺装继续按干地三角形裁切，不在岸边盖悬空平板。
- 座面和靠背保持水平，仅绕竖轴旋转。每条支腿单独计算长度，下端入土8厘米，上端接水平座面底；支撑区域高差上限0.5米，当前8处实测游戏地形差为0.12–0.462米。这里的“实测”仅指运行时网格测量，不代表现实测绘标高。
- 栏杆和长椅使用与显示相同的 StreetBox 数据接入共享碰撞、相机遮挡和存档恢复。细节合并为一个 instancedMesh，铺装合并为一个网格。

岸线裁切格不能直接使用 `terrainTriangleHeight` 的中心点回退值来安放细小物件：本批发现个别点与真实干地面相差约25厘米。`riversideGroundHeight` 读取共享 `terrainSurface` 的实际干地三角形并做重心插值；未找到支撑则跳过。所有实际显示栏杆端点均用独立 Rapier 地形射线核验，并检查座面、支腿的接合关系。

## 梯道连接已取得的依据

`riverside-connections.json` 由归档 OSM 的**同一源节点 ID**推导，避免只凭距离猜连接：

| 梯道 way | 桥侧连接 | 陆侧连接 |
| --- | --- | --- |
| 1378654366 | 1275168863，龙城路/柳江大桥，bridge=yes、layer=1 | 1531307805，滨江西路 |
| 1378654367 | 195910349，龙城路/柳江大桥，bridge=yes、layer=1 | 1531307805，滨江西路 |
| 1449382842 | 649497457 与1449382839，红光大桥，bridge=yes、layer=1 | 205519385匝道与1531307805滨江西路 |

这些连接能够说明平面上的桥、折返梯道、滨江路关系；资料中没有梯道的 `ele`、`incline`、踏步数或平台标高。不能把约30米DEM落在桥上的地面值当成桥面标高。当前可步行 `BRIDGE_SECTIONS` 主要覆盖文惠桥与广雅桥，柳江大桥与红光大桥仍需先建立统一的桥面、引桥、梯道标高与物理，再构建完整梯道。尤其1449382842沿轴线的DEM采样先降后升，不适合直接拉出整条台阶。

后续优先取得柳江/红光桥桥面断面、梯道平台高度、现场照片和公共空间范围；保持源节点端点，并让梯道顶端接桥面、底端接滨江路，显示、碰撞、存档统一使用同一表面。东门、金沙角仍需分别搜集资料，不能把这些西侧桥梯道冒充它们。

## 复现与检查

```powershell
python scripts/prepare-liuzhou-riverside-detail.py
python scripts/audit-liuzhou-riverside-connections.py
python scripts/tests/liuzhou-riverside-detail-geometry.py
node --test scripts/tests/liuzhou-riverside-detail.test.mjs
node scripts/verify-liuzhou-riverside-detail.cjs
```

独立几何检查覆盖公园包含、轴线保留、建筑/河道/交叉道路排斥、休息点入口及树木避让。物理检查覆盖185段栏杆支撑、8个休息点普通步行往返及原来源步道连通；原 `liuzhou-riverside.test.mjs` 的长距离双向巡览也保持通过。浏览器报告与逐张检查的截图保存在 `.tmp/liuzhou-riverside-detail-dev/`（临时验证证据，不是长期资料）。
