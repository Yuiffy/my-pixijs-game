# 直播同步脚本 (sync_streams.mjs)

## 功能概述

此脚本用于从源目录同步直播文件到目标目录，生成 `streams.json` 供前端使用。主要功能包括：

1. 扫描源目录中的直播文件（XML、SRT、封面图等）
2. 根据文件名提取直播时间、标题等信息
3. 智能分配相关图片到对应的直播
4. 生成结构化的 JSON 数据供前端展示

## 使用模式

脚本支持两种处理模式：

### 1. 增量处理（默认）
只处理从最新已同步直播之后的数据，适用于日常更新，提高处理效率。这是默认模式。

```bash
node sync_streams.mjs
```

### 2. 全量处理
处理所有历史数据，适用于首次运行或需要重新处理所有数据的情况。

```bash
node sync_streams.mjs --full
```

### 可选参数
- `--full`: 启用全量处理模式
- `--force`: 强制重新处理所有数据（在全量模式下有效）

## 工作原理

### 增量处理（默认）
1. 读取现有的 `streams.json` 获取最新直播时间
2. 只处理时间晚于最新直播的文件
3. 合并新数据到现有数据
4. 更新 `streams.json`

### 全量处理
1. 扫描所有源目录中的直播文件
2. 按时间分组和去重
3. 智能分配图片
4. 生成完整的 `streams.json`

## 文件命名规范

脚本识别两种文件命名格式：

### DDTV5 格式
```
YYYY_MM_DD_HH_mm_ss_标题_DDTV5_*.xml
示例：2026_01_12_20_03_10_找你有事！速来_DDTV5_1.xml
```

### 录制格式
```
录制-房间号-YYYYMMDD-HHmmss-毫秒-标题.扩展名
示例：录制-25788785-20260112-200309-610-找你有事！速来.xml
```

## 图片分配策略

脚本会智能分配图片到直播：
1. **文件名匹配**：图片文件名包含直播ID或标题关键词
2. **关键词匹配**：根据"午台"、"晚台"等关键词匹配时间段
3. **时间窗口**：根据修改时间分配到最近的直播
4. **平衡分配**：同一天多个直播间公平分配图片资源

## 使用建议

1. **日常更新**：使用默认的增量模式快速同步新直播（推荐）
   ```bash
   node sync_streams.mjs
   ```

2. **重新处理**：当图片分配策略变更或需要重新处理所有数据时
   ```bash
   node sync_streams.mjs --full --force
   ```

3. **首次运行**：如果还没有 `streams.json` 文件，增量模式会自动回退到全量处理
   ```bash
   node sync_streams.mjs
   ```
   或者显式使用全量模式：
   ```bash
   node sync_streams.mjs --full
   ```

## 注意事项

1. 源目录路径在脚本中硬编码，如需修改请编辑 `SOURCE_BASE_DIRS` 数组
2. 增量处理依赖于现有的 `streams.json`，如果文件损坏或不存在，会自动回退到全量处理
3. 图片分配算法会尽量保证公平性，但复杂情况下可能需要手动调整
